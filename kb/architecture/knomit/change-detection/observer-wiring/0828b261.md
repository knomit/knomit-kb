# Observer wiring: store.Service → observe.Observer → repos.Hub → SSE

Current wiring (deviates from the original design doc in several ways):

**Layers:**
- `store.Service.SetOnCommit(fn func(branch, hash string))` registers the callback (`internal/store/service.go:155`). Stored at `rh.onCommit` on the repo handler.
- `branch_commit.go:61` invokes the callback after each commit, after internal locks are released.
- `internal/repos/builder.go:251` wires `onCommit = func(_, hash string) { obs.Notify(hash) }` and saves it on the `repoInstance`.
- `internal/repos/swapstore.go:50,94` re-applies `SetOnCommit` after every `SwapStore` — the callback must survive store swaps, so repos owns the wiring, not main.
- `internal/observe/observe.go` is its own package (not project-root `observe.go` as the doc proposed). 50ms debounce; calls `fn(hash)` once per quiet period.
- The observer's callback typically calls `idx.Sync(gs)` then `hub.BroadcastStatus(hash)`.
- `repos.Hub.BroadcastStatus(head string)` publishes `repos.StatusEvent{Head: head}` via the `goob.Observable` (`internal/repos/hub.go:185`). NOT on `web.TaskHub` as the doc said — the hub moved into repos.
- SSE handler at `internal/web/handlers_events.go:65` has a 30s keepalive ticker (sends `: keepalive\n\n` SSE comment, not data) and a type switch handling `TaskEvent` and `StatusEvent`.

**Key deviations from the draft design doc:**
1. Callback lives on `store.Service`, not `git.Store`. The `internal/git` package was renamed to `internal/store/git` and the Store became branch-stateless (commit d27c70e: "remove branch/agentID state from Store; add per-branch locking").
2. Signature is `func(branch, hash string)` — branch param added because Store no longer carries branch state.
3. Observer lives in `internal/observe/`, not project root.
4. `repos` layer (not `main`) owns the wiring, to handle SwapStore re-application.
5. `StatusEvent` lives in `internal/repos/hub.go`, not `internal/web/taskhub.go`.
