# GET /api/v1/fleet/activity returns the newest events (default and cap 200), newest first, derived from main's first-parent history, the issuance log, the CRL and an in-memory ring of the master's refusals; it keeps no log of its own

Built in PR #527 (verified at merge commit c6e282db). Read-only, open to any principal the edge admits (like /fleet/members); `limit` is a positive integer (400 otherwise), default and cap repos.MaxFleetActivity = 200. An instance with no fleet repository answers 409 not_registered.

KINDS AND THEIR SOURCES (nothing is logged for them):
- created, joined, admitted, left, host-changed: main's first-parent history (store.FleetMainLog): created = the commit that adds the fleet root certificate; joined = a member record that becomes active; left = a record that turns left; admitted = a merge of a member's tip into main (second parent); host-changed = a change of the host record. The walk is bounded by maxFleetWalk = 2000 first-parent commits and stops once `limit` entries are found.
- enrolled: the master's issuance log <home>/fleet/issued.jsonl (pki.LoadIssued), which moves with the root to a new master; a member has none. The log also holds issuances that never reached main (the create's own IssueInstance), so an `enrolled` event can exist for a leaf that is not on main.
- revoked: the CRL on main, the agent from issued/<serial>.pem and the reason from revocations/<serial>.txt when the root's signature verifies.
- refused: the master's ring of refusals (fleetPeers.ring, the last refusalRing = 200, IN MEMORY: a restart starts it empty). Three writers feed it: the hub's receive-pack (PushPolicy.Judged -> FleetPushJudged), the forge fetch judge, and the merger's re-judge. The same branch refused again at the same tip for the same reason is ONE entry (it keeps the first time); an admitted push clears the branch's current refusal. The event's agent is the refused tip's author (store.CommitAgent); when that is not an agent address it falls back to the record that names the branch.

NOT EVENTS: a root key imported, a stand-down, a decommission: nothing records them.

JOINED TIME: `joined`, `admitted` and `left` carry the committer time of the MAIN commit (whole seconds), not of the member's write; `joined` means "the active record landed on main".

KNOWN GAP (F2, queued for PR7b): the agent of a `refused` event is the CLAIMED author of an unverified, refused commit. A member that authors a tip as another agent id makes the refusal show that other id (and, if that id is enrolled and not yet joined, as its Members row's last_refusal). It is display-only: nothing branches on it. Once PR7b shows the author as claimed, or hangs the refusal on an enrolled row only when the tip's signer is that id's key, this reads false.

MISREADING: "a refused first join always appears": on a forge only the fetch judge's and merger's refusals exist; a restart clears the ring.
