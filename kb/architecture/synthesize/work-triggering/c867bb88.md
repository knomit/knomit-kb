# Pipeline work is two channels: edge-triggered seeding from the watermark diff, and a level-triggered restatement shortlist that reads STANDING pairs every session — deliberately watermark-exempt

Edge-triggered channel: dirtyFacts seeds review from the watermark's commit diff — only facts changed since the last run. Level-triggered channel: the cross-cluster restatement shortlist (motif phase 0, PR #99) reads standing `restatement_pairs` state each session regardless of the dirty set, and since #128 level-triggered work is planned even when the dirty set is empty.

Why the second channel exists: two unchanged facts that restate the same claim are STRUCTURALLY invisible to edge-triggered review — once the watermark passes them, neither will ever be dirty again unless edited, so per-cluster review can never re-surface the pair. The standing-state channel is the repair loop for exactly that debt, and it is budget-bounded (one reserved structural slot per session, behind the restatement throttle), not a rescan.

Consequence: growth of `restatement_pairs` (corpus-wide detection, no watermark, no scope) is detection INVENTORY, not an offer queue — do not read pair counts as per-session token exposure; the offer rate is capped by the budget reserve.

WHAT THIS DOES NOT MEAN: it does not mean the watermark is bypassed for seeding, and it does not mean review examines unrelated facts — shortlist pair members are related TO EACH OTHER (path identity, shared rare token, title cosine); they are merely unrelated to the current session's changes.
