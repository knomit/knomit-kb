# internal/corpus/synthesize/step holds the vocabulary the engine and strategies share and imports nothing from synthesize; internal/synthtest is the shared test-support package of the synthesize tree and must not import a package whose tests are built on it

At 67642eff (PR #597, step 13b of the internal/ hierarchy, after 13a #596) package internal/corpus/synthesize/step holds the vocabulary the synthesize engine and its strategies share: types, effort, strategy (Strategy, Deps, WorkItemView, Pipeline*), actor, ref_gate (WriteGate), weight, validation and vector (Dot). It imports nothing from synthesize. internal/edge/mcp (Effort, ScopeFilter, ProgressEvent, PipelineResult, ReviewResult, WithActor, NormalizeEffort, DefaultEffort) and tools/calibrate (Effort, NormalizeEffort) import step directly; the synthesize parent has no aliases of step names. Deps carries *repos.RepoInstance, hence the layering edge step -> corpus/repos (and step -> corpus/refs for ref_gate).

EXPORT DECISIONS: PagedStrategy and StandingWorkStrategy (formerly unexported optional halves of Strategy) are exported from step because the parent engine type-asserts them; they were not re-declared in the parent (no consumer-defined interfaces, no forwarding layer). PageEnvelopeReserveBytes stayed UNEXPORTED (pageEnvelopeReserveBytes); the paging test uses step.MaxDeliveredItemBytes - step.MaxPageFactBytes. synthtest's IntraCommunityEdges and Normalize (no user outside synthtest) were unexported in review.

TESTS: step's own tests that use a store are package step_test, because a test in package step cannot import synthtest (synthtest imports step); they carry the same TestMain as the parent (test signer, fast durability).

synthtest (internal/corpus/synthesize/internal/synthtest) is the shared test-support package of the synthesize tree: sources fixtures, RestatementEnv/embedder, GraphEnv, kind helpers. It lives under synthesize/internal so nothing outside the tree can import it; it is on the forbidden list of TestHarnessNotLinkedIntoShippedBinaries (a production file importing it is RED, review sabotage) and allowed through TestTestSeamsNotReachedFromProduction (seamAllowed, one directory prefix) because it imports storetest. It imports step, store, repos and others. RULE: synthtest must NOT import a package that has tests built on it; SeedShortlist therefore cannot live in synthtest, because it calls the title backfill and shortlist refresh (restatement code). UPDATE at 13c (PR #601, merged 52604c5d; re-read there): restatement became a child package (kb/architecture/synthesize/restatement-child/777df0a4.md), seedShortlist now lives in internal/corpus/synthesize/restatement/restatement_shortlist_test.go, and the parent's restatement_standing_work_test.go carries a mirror (a _test.go helper cannot be imported). The reason is the IMPORT CYCLE (restatement's own tests import synthtest), not 'synthtest imports only step and the store': synthtest also imports repos.

DOES NOT MEAN: that nothing can forward step names back into the parent: no guard catches a parent alias (type X = step.X), var or one-line forwarder in synthesize at 67642eff (review sabotage stayed green); store_reexports_test.go covers only the store (generalised later, see the parent-forwards guard). Behaviour-neutral: the 8 moved step files differ from before only by the package clause and export renames.
