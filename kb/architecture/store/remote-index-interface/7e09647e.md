# Remote operations live on remoteIndex accessed via svc.Remote(), NOT directly on *Service

GetRemote, SetRemote, Sync, Push, threeWayMerge live on *remoteIndex (internal/store/remote.go + remote_sync.go), exposed via Service.Remote() RemoteIndex accessor. remoteIndex holds {rh *repoHandler, fi *factIndex, crypt *Crypt}. Service no longer has a crypt field (it only served credential encryption for GetRemote/SetRemote); Service.SetCrypt(c) now delegates to s.ri.crypt = c. SyncResult and PushResult are EXPORTED (required for the exported RemoteIndex interface). Callers must use svc.Remote().Sync(...) / svc.Remote().Push(...) / svc.Remote().GetRemote(name) / svc.Remote().SetRemote(...) — NOT svc.Sync etc. directly. This is part of the broader push to keep *Service as a thin entry point that exposes sub-indices via accessors (Facts(), Search(), Pipeline(), ToolSession(), Branches(), Remote()).
