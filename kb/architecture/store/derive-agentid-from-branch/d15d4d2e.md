# deriveAgentID strips 'agent/' prefix (else returns the branch verbatim); commitSigs/commitAgentID use it for every authored commit, except that an experiment branch is resolved to its recorded parent first (#394)

deriveAgentID(branch) in service.go extracts the agent identifier from a branch name: strips the 'agent/' prefix if present, otherwise returns the branch verbatim. Examples: 'agent/laptop-abc' → 'laptop-abc'; 'main' → 'main'. AgentIDOf is the exported alias the fleet identity code reads; neither changed meaning in #394.

Commit identity is built in ONE place, repoHandler.commitSigs(ctx, branch, operation) in branch_commit.go (it replaced authorSig/committerSig in #394): author '<agentID>' / '<agentID>+<operation>@agents.knomit.io' (operation e.g. learn/update/retract/move/merge — see git/author-subaddress-encodes-operation), committer '<agentID>' / '<agentID>@agents.knomit.io' (stable per agent). All four commit builders call it: writeFileExact, deleteFile, batchWriteLocked (fact_write.go) and the merge commit in mergeIntoBranch (branch_merge.go, resolved before any tree is written).

The agent id comes from commitAgentID: deriveAgentID(branch) for every non-experiment branch, and for an `exp/<name>` branch deriveAgentID of the experiment's RECORDED parent — so experiment commits are authored by the owning agent, never `exp/<name>` (which is what deriveAgentID's verbatim fallback produced before #394). Consequence: a caller that writes a commit must go through commitSigs; building an object.Signature from the branch name directly reintroduces the #394 bug for experiments. See kb/invariants/store/experiments/commit-author/3a614142.md for the refusal cases.
