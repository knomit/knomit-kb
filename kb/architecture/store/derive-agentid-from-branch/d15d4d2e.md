# deriveAgentID strips 'agent/' prefix; used by author/committer signature helpers

deriveAgentID(branch) in service.go extracts the agent identifier from a branch name: strips the 'agent/' prefix if present, otherwise returns the branch verbatim. Examples: 'agent/laptop-abc' → 'laptop-abc'; 'main' → 'main'. Used by repoHandler.authorSig(branch, operation) to build the author email '<agentID>+<operation>@agents.knomit.io' (operation is one of learn/update/retract/subsume/sync — see git/author-subaddress-encodes-operation fact) and by repoHandler.committerSig(branch) for the stable '<agentID>@agents.knomit.io'. Author varies per commit (encodes operation type); committer is stable per agent across operations. Knomit-emitted commits always have a populated author_email that downstream queries can split on '+' to recover the operation.
