# commitSigs/commitAgentID author every commit as the store's persisted agent id (SetAgentID); ErrNoAgentID when none; an experiment branch is resolved to its recorded parent first (#394)

PR #513 (D18) deleted deriveAgentID and store.AgentIDOf: no code turns a branch name into an agent id any more.

Commit identity is built in ONE place, repoHandler.commitSigs(ctx, branch, operation) in branch_commit.go (it replaced authorSig/committerSig in #394): author '<agentID>' / '<agentID>+<operation>@agents.knomit.io' (operation e.g. learn/update/retract/move/merge — see git/author-subaddress-encodes-operation), committer '<agentID>' / '<agentID>@agents.knomit.io' (stable per agent). All four commit builders call it: writeFileExact, deleteFile, batchWriteLocked (fact_write.go) and the merge commit in mergeIntoBranch (branch_merge.go, resolved before any tree is written).

The agent id comes from commitAgentID, which returns ownAgentID(branch): the id the instance gave the store with Service.SetAgentID (the persisted instance_identity.agent_id, set at every SetSigner site). For an `exp/<name>` branch commitAgentID first resolves the experiment's RECORDED parent after the orphan / empty-or-experiment parent / stale-parent checks (ErrOrphanExperimentRef, ErrStaleExperimentParent) and then returns ownAgentID(parent) — so experiment commits are authored by the owning agent, never `exp/<name>`. A store with no SetAgentID refuses the write with store.ErrNoAgentID before any object is built (inside a test binary only, an installed fallback maps a fixture's branch to 'branch minus agent/').

Consequence: a caller that writes a commit must go through commitSigs; building an object.Signature from a branch name directly reintroduces both the #394 bug for experiments and the name inference D18 forbids. See kb/invariants/store/experiments/commit-author/3a614142.md for the refusal cases and kb/invariants/identity/no-name-inference/e412df80.md for the rule.

UPDATE (E7b, PR #579, merged into dev as a6958fa6; re-read at a6958fa6): the sentinel is vcs.ErrNoAgentID (internal/store/internal/vcs/agent_id.go); store.ErrNoAgentID no longer exists. It deliberately did NOT move to internal/store/model: no caller outside the store needs it, so there is no re-export to replace (kb/architecture/store/model-leaf/7c5bf558.md). commitSigs and commitAgentID now live in the vcs child (CommitSigs), not in the parent's branch_commit.go and agent_id.go that the pinned refs name; those paths are HISTORICAL. store.TestFallbackAgentID no longer exists: the test-binary-only fallback is vcs.SetTestFallbackAgentID (internal/engine/store/internal/vcs/agent_id.go), installed from tests, read only by vcs OwnAgentID, inert outside a test binary, and no production file reads it (repos.Manager.AgentID returns the configured deps.AgentID).
