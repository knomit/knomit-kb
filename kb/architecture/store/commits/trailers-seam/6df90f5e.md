# PR 3 seam (documented, not built): the causal-trace trailers are stamped by a ctx-carried trailer set read at the THREE authored-commit builders (plumbing.go writeFileToStore, deleteFileFromStore, fact_write.go batchWrite), never at the 19 callers; PR 1 only READS Knomit-Trace with store.TrailerValue

F07 causal trace, revision 2 addendum. The commit message reaches object.Commit.Message byte for byte from every caller (MCP learn/update/retract, web fact create/update, synthesize dedup/decision/discovery — 19 non-store call sites) through factIndex.writeFile / deleteFile / batchWrite (internal/store/fact_write.go), and the commit object is BUILT in exactly three places: writeFileToStore and deleteFileFromStore in internal/store/plumbing.go and batchWrite in internal/store/fact_write.go, each calling storeCommit, which signs EncodeWithoutSignature — so trailers are INSIDE the signed bytes (go-git encodes "\n\n"+Message into the payload).

The seam PR 3 uses: `store.WithTrailers(ctx, Trailers{Trace, Cause, Trigger})` carried on the ctx; those three builders read it, mint Trace when empty (the task id when the fact is a task, else a fresh id) and append the trailer paragraph (Knomit-Trace / Knomit-Cause / Knomit-Trigger). One place owns the format; no signature change across the callers; transport commits carry none by construction (merge commits in branch_merge.go and replays in remote_reconcile_rebase.go are not stamped; a replay copies the original message, so Knomit-Trace survives while a Knomit-Cause that pointed at a replayed commit dangles — an origin force-rewind only, for PR 3's brief). The rejected alternative — appending the string at each caller — is six-plus edits and misses synthesize.

PR 1b builds NONE of this. It reads `Knomit-Trace` from the firing commit's full message with store.TrailerValue (internal/store/trailers.go): the last paragraph, Key: value lines, last occurrence wins, case-insensitive; go-git v5.18.0 has no trailer parser and commit_log.message keeps only the first line, which is why the message is parsed, not the log. A knomit write today produces no trailer, so change.trace is '' until PR 3 (TestDispatch_TraceFromTrailer writes one by hand in the message and sees it on change.trace).
