# Service is a thin entry point; sub-indices exposed via Facts/Search/Pipeline/Remote accessors

*Service is a thin entry point that exposes sub-indices via accessor methods: Facts() FactIndex, Search() SearchIndex, Pipeline() PipelineIndex, ToolSession() ToolSessionIndex, Branches() BranchIndex, Remote() RemoteIndex. Remote operations (GetRemote, SetRemote, Sync, Push, threeWayMerge) live on *remoteIndex which holds {rh, fi, crypt} — NOT on *Service directly. Service no longer has a crypt field (it only served credential encryption); Service.SetCrypt(c) delegates to s.ri.crypt = c. SyncResult and PushResult are EXPORTED (required for the exported RemoteIndex interface). Callers must use svc.Remote().Sync(...) etc. — NOT svc.Sync. This pattern keeps Service from accumulating responsibilities and makes the per-sub-domain interfaces individually mockable.
