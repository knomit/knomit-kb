# RelevantMethodology composite score: 0.6*vector + 0.4*tag_overlap, with universal markers excluded

RelevantMethodology(branch, sourceBody, sourceDomains, sourceEntities, k) ranks methodology facts by a composite score on [0,1]: 0.6 * VectorScore (cosine via sqlite-vec on sourceBody embedding) + 0.4 * TagOverlap. TagOverlap = (domain_overlap + entity_overlap)/2 where each overlap = |source ∩ candidate| / max(1, |source|). The constants live in package-level vars so they can be tuned without code-tree-wide changes. The 60/40 split favours vector because tag coverage is empirically incomplete (~28% missing domain, 20% missing entities). CRITICAL: 'meta', 'reasoning', 'methodology' are EXCLUDED from the candidate-side domain set before intersection — they're universal markers on every methodology fact and would inflate every tag_overlap score. Filter: type='methodology' AND deleted=false AND visible-on-branch (uses facts_type index). Path is NOT part of the filter — TYPE is the canonical, schema-validated marker. kb/meta/reasoning/ is a soft path convention, not load-bearing for retrieval. Empty candidate set returns ([]MethodologyMatch, nil), not error. Default k=3 keeps prompt bloat tractable; total injection length cap 1500 tokens, truncate lowest-scoring first.
