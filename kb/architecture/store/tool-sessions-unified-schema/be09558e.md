# explore + explain share tool_sessions schema; tool_queue added for BFS

explore_sessions + explore_seen_paths were RENAMED to generic tool_sessions + tool_seen_paths (with a `tool` field on each session distinguishing 'explore' vs 'explain'). A new tool_queue table is added for BFS state (session_id, path, commit_hash, depth) — used by explain; explore uses LastCommit on the session row instead. ExploreIndex interface renamed to ToolSessionIndex — same machinery serves both tools. NO migration of existing data (rename happens in schemaSQL — fresh start was acceptable at the time). knomit_explain is a paginated BFS over a fact's provenance graph: starting from the root fact, follows local refs, reading each referenced fact AT THE COMMIT WHERE THE REFERENCE EXISTED — the graph is a PROVENANCE SNAPSHOT frozen at the root fact's most recent commit. Refs later changed or deleted are still visible in their ORIGINAL form. External URL refs are returned as-is for the model to handle.
