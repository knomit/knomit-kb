# tool_sessions schema is shared by knomit_explain and knomit_query (tool_queue for BFS/snapshot)

The generic tool_sessions + tool_seen_paths tables (each session row carries a `tool` field naming its consumer) plus a tool_queue table back the stateful read tools; the interface is ToolSessionIndex. Originally these were explore_sessions/explore_seen_paths, renamed when knomit_explain was added.

knomit_explore has since been REMOVED (its browse-by-recency folded into knomit_query as sort=recent — see kb/decisions/mcp/query/explore-merged-as-sort-recent). The two remaining consumers of this schema are:
- knomit_explain: a paginated BFS over a fact's provenance graph, using tool_queue for BFS state (session_id, path, commit_hash, depth). The graph is a PROVENANCE SNAPSHOT frozen at the root fact's most recent commit — each ref is read AT THE COMMIT WHERE THE REFERENCE EXISTED; refs later changed or deleted are still visible in their original form; external URL refs are returned as-is.
- knomit_query: snapshots the remainder of a result set (relevance OR sort=recent) into tool_queue and pages it via queryResume.

The former explore-only mechanism (LastCommit on the session row for the WalkChangedFiles git-walk) is gone along with WalkChangedFiles. No data migration accompanied the original rename (fresh start was acceptable then).
