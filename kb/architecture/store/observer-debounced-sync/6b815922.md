# git.Store.OnCommit + 50ms debounced observer drives index sync + SSE broadcast

git.Store has an onCommit callback set ONCE at init time via SetOnCommit. INIT-TIME-ONLY CONTRACT: SetOnCommit MUST be called before any writes — eliminates synchronization on the field. Every method that updates a branch ref (WriteFile, BatchWrite, DeleteFile, Sync merge) calls s.onCommit(hash) AFTER SetReference succeeds, AFTER s.mu is released (fire-and-forget). In main.go, the observer wraps onCommit with a 50ms debounce timer: resets on each Notify call, fires the callback after the quiet window with the latest hash. The callback calls idx.Sync(gs) (which diffs git from meta.last_commit to HEAD and updates the index) + hub.BroadcastStatus(hash). Collapses rapid writes (e.g. 20 deletes during synthesize) into a single sync + SSE push. obs.Stop() cancels any pending timer and runs a final flush — called during shutdown before srv.Shutdown(). The observer lives in main package (wiring-only).
