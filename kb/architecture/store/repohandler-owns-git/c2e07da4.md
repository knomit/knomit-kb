# repoHandler owns DB + git storage + git reads; sub-indices delegate via .rh field

repoHandler is the complete shared backend: db, gits (*storegit.Storer), repo (*gogit.Repository), configMu sync.Mutex. *repoHandler satisfies both BranchIndex and gitReader (var _ gitReader = (*repoHandler)(nil)). factIndex no longer owns gits/repo/configMu — accesses via fi.rh.gits, fi.rh.repo, etc. searchIndex.Sync(ctx, branch) and Rebuild(ctx, branch, progress) take NO gitReader parameter — they use si.rh directly. The 8 forwarding stubs that used to exist on Service are DELETED. factIndex retains 5 delegation stubs for FactIndex-exposed methods (HeadCommit, ListAll, ListAllWithHash, LastCommitForPath, DiffFiles) that forward to fi.rh. Anti-pattern: do not add new gitReader-style parameters; access via the embedded *repoHandler.
