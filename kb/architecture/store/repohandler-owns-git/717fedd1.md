# repoHandler owns DB + git storage + git reads; factIndex/searchIndex delegate via fi.rh / si.rh

repoHandler is the complete shared backend: db *sql.DB, gits *storegit.Storer, repo *gogit.Repository, configMu sync.Mutex. *repoHandler satisfies BOTH BranchIndex AND gitReader (var _ gitReader = (*repoHandler)(nil)). factIndex no longer owns gits/repo/configMu — it accesses via fi.rh.gits, fi.rh.repo, fi.rh.configMu, fi.rh.resolveRef, fi.rh.readFileAtCommitHash. searchIndex.Sync(ctx, branch) and Rebuild(ctx, branch, progress) take NO gitReader parameter — they use si.rh directly. The 8 forwarding stubs that used to exist on Service (HeadCommit, ListAll, etc.) are DELETED. factIndex retains 5 delegation stubs for FactIndex-exposed git-read methods (HeadCommit, ListAll, ListAllWithHash, LastCommitForPath, DiffFiles) that forward to fi.rh — because FactIndex callers expect these on the index. Anti-pattern: do not add new gitReader-style parameters to internal methods; access via the embedded *repoHandler.
