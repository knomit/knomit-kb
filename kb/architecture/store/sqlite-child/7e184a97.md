# store/internal/sqlite owns engine primitives only (driver, vec codec, SQL funcs, ctx-tx helpers, Crypt, donated-embedding key, test durability switch); vec_table.go, canonicalizeDomain and the interfaces stayed in the parent store package

Step 6 of the internal/ hierarchy stack extracted internal/store/internal/sqlite. It holds: Register (the once-only sqlite_vec.Auto plus the "sqlite3_knomit" driver with ConnectHook pragmas), the SQL funcs registered there (knomit_parse_fact, knomit_cosine_sim, knomit_canon_domain, knomit_motif_key), Float32SliceToBytes / BytesToFloat32Slice / UsableKNNSimilarity / CosineSim, GroupingKey and MotifClusterKeyExpr, Conn and BeginTxIfNeeded (thin wrappers over store/git's ctx-tx plumbing), Crypt/NewCrypt, WithPrecomputedEmbeddings/PrecomputedEmbedding, and the test-only durability switch (SetTestFastDurability, SyncDSNParam; the atomic is unexported there).

Stayed in the parent: vec_table.go (methods on *searchIndex, so it is index cluster), canonicalizeDomain (textnorm alias used by index code; the child calls textnorm.Canonicalize directly for knomit_canon_domain), and all interfaces. The parent's sqlite_conn.go is the seam: it re-exports Crypt, NewCrypt, CosineSim, WithPrecomputedEmbeddings, SetTestFastDurability, SyncDSNParam (public surface unchanged for callers outside store) and keeps the old unexported names (registerVec, float32SliceToBytes, conn, beginTxIfNeeded, groupingKey, ...) as forwards so sub-index code did not change.

Consequences: the child must not import package store (it imports only store/git, fact, textnorm and third-party). archtest sameLayerEdges lists store/internal/sqlite -> store/git because the ctx-carried tx (ctxKeyTx) is defined by the git storer. TestFastDurabilityOnlyReferencedFromTests now allows two files to name the setter: the child's definition and the parent forwarder; every needle must still appear in the definition.

Does NOT mean: that SQL statements moved. Statements still live in storegit.Storer and the sub-indices; the child only owns the engine registration and shared helpers.
