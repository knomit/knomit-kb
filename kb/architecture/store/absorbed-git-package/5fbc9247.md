# internal/git was deleted; all git ops live on store.Service, identity moved to internal/identity

The internal/git package was DELETED. All git operations are now methods on *store.Service (read, write, sync, replay, plumbing, httphandler, commitlog). store.FactRow is the SINGLE definition (git.FactRow deleted). Constructors take *sql.DB ONLY: store.Open(db), store.Init(db, files, branch), store.CloneFrom(db, url, branch, auth, progress) — the Service creates its own *storegit.Storer internally. The onCommit callback was eliminated — Service syncs its own index internally after writes (no external wiring). Identity primitives (EnsureKeyPair, AgentBranch, LoadOrGenerateKey, SanitizeHostname, ResolveAuth, ResolveAuthWithOrigin, RemoteAuthConfig) extracted to a NEW internal/identity package; cmd/* and config/config.go import identity instead of the deleted git package. Replay is a standalone function taking two *store.Service: store.Replay(ctx, local, remote, localBranch, remoteBranch, strategy).
