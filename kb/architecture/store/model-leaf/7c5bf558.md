# internal/store/model is the leaf that holds the plain data, sentinel errors and pure helpers the vcs, sessions and sqlite children define and callers outside the store use; it imports nothing from the store, so a sentinel has ONE definition and errors.Is needs no re-export

Since PR E7b (#579, refactor/store-e7b-model, merged into dev as a6958fa6; every claim below re-read at a6958fa6), internal/store/model is the one importable leaf where the value types, sentinel errors and pure helpers of the vcs, sessions and sqlite children live. It replaced the roughly 64 aliases, consts, var forwards and one-line func forwards that vcs_seam.go, sessions_conn.go and sqlite_conn.go held in package store. vcs, sessions, sqlite and every caller outside the store import model directly; model imports nothing from the store or its children, so a sentinel is ONE value however it is reached and errors.Is needs no re-export.

MOVED (origin -> model). From vcs: Branch, Experiment (+Branch()), ExperimentPrefix and ExperimentBranch / IsExperimentBranch / ExperimentNameOf, PathChange, ChangesQuery / ChangesResult / ChangesScope, the Change* consts, the cursor and bookmark codecs and ParseChangesSince, RevisionMeta, RevisionDiff, the whole trailer file (Trailers, TrailerEntry, the Trailer* consts, WithTrailers, WithAgentTrace, TrailersFromContext, AppendTrailers*), Accept / AcceptList, Embedder / BatchEmbedder / IndexManager / RebuildProgress / EmbedderThresholds, IsRoleBranch / ChooseConsensusBranch / IsGeneratedRef, and the sentinels ErrBranchNotFound, ErrPathNotFound, ErrNoConsensusBranch, ErrNoSigner, ErrHistoryChanged, ErrUnknownSince, ErrSinceNotBehind, ErrInvalidPrefix, ErrInvalidChangesCursor, ErrStaleExperimentParent, ErrOrphanExperimentRef, ErrTraceOverride, ErrTraceTrigger. From sessions: PipelineSession, PipelineWorkItem, PipelineSessionStats, ToolSession, QueueItem, ErrPipelineSlotChanged, and SessionDBSuffix / IsSessionDBFile / SessionDBPathFor (renamed from DBSuffix / IsDBFile / PathFor). From sqlite: Crypt / NewCrypt, CosineSim, WithPrecomputedEmbeddings / PrecomputedEmbedding.

NEW or NEWLY EXPORTED, not moved: model.HasTrailers is NEW (an ungated export that replaced vcs's HasTrailersForTest peek at the private ctx key). model.ParseFullHash (shared by ParseChangesSince and the vcs changes read) and model.CosineSimOK (formerly the unexported cosineSim) are newly exported; the SQL function knomit_cosine_sim in internal/store/internal/sqlite/sqlfuncs.go calls model.CosineSimOK, so Go and SQL share one definition.

INTERFACES that moved, and why each is live: Embedder / BatchEmbedder are an injected backend abstraction (production *embeddings.Embedder plus testenv.DeterministicEmbedder). The IndexManager interface and the AcceptList type described in this PR no longer exist in model (Service.IndexManager() now returns *index.Index, and model/accept_list.go holds only the Accept struct).

STAYS IN THE CHILDREN: vcs.ErrNoAgentID, NormalizeChangesPrefix (vcs; no caller outside the store), ErrNoDropBranchRowsHook, and every method that needs a repo or a database. STAYS IN THE PARENT as the one remaining exported forward: store.SyncDSNParam (sqlite_conn.go), a store operation over private sqlite state that a leaf cannot hold. (HISTORICAL: store.TestFallbackAgentID was a second forward until it was deleted; the test-only fallback is now vcs.SetTestFallbackAgentID, read only by vcs OwnAgentID inside a test binary, and no production file reads it.)

ENFORCED BY TestStoreModel_IsALeaf (test/archtest/store_model_leaf_test.go), with TestStoreModelLeafDetectorSees proving the detector sees an import; the store/* -> store/model edges are listed in test/archtest/layers_test.go (TestLayers is report-only). Guards that followed the moved code: the changes guard (internal/engine/store/changes_guard_test.go) allowlists model/changes.go for the cursor codecs and its floor of 8 distinct calls applies ONLY to model/ keys (other files keep 15); internal/engine/store/triggers_guard_test.go keys "model/trailers.go"; internal/corpus/repos/triggers_guard_test.go keys model.TrailerValue and model.WithTrailers.

CONSEQUENCE: a new type that a vcs, sessions or sqlite API returns and a caller outside the store names goes in model, never behind an alias in a *_seam.go or *_conn.go file. model must not import store/*, and must not get a behaviour that needs a repo or database.

MISREADING: 'model holds everything exported' is false. It holds data and pure helpers only; vcs.ErrNoAgentID and store.SyncDSNParam show where the line is. Nor are the interfaces in it a licence for more: they stay only for the reasons above (the two that were scheduled to become concrete, IndexManager and AcceptList, are no longer in model).
