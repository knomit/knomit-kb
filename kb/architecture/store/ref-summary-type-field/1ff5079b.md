# RefSummary carries the target/source fact's epistemic Type for UI styling

internal/store/search_graph.go's RefSummary struct gained a Type string field (json:type,omitempty) populated by the Cypher queries in IncomingAtCommit / OutgoingAtCommit returning s.type / t.type and scanning into RefSummary.Type. Propagated through buildGraphRefItems in internal/web/handlers_fact_sub.go to graphRefEntry.Type, then to the frontend RefVersion / RefGroup types (latest version's type used as group type). Why: the redesigned ExplainView chip colors and icons depend on the referenced fact's epistemic type — the chip becomes a per-type visual cue instead of all-blue.
