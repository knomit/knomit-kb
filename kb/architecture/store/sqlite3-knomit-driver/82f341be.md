# Custom sqlite3_knomit driver carries pragmas + GraphQLite extension (no vtab registration)

Knomit uses a custom SQLite driver name `sqlite3_knomit` (NOT `sqlite3`), registered exactly once per process via registerVec() in vec.go using sync.Once. The driver carries: (1) GraphQLite extension load via the Extensions field (Extensions: []string{graphqliteLibPath()}); (2) a ConnectHook that runs on EVERY pooled connection — registers SQL functions (registerSQLFuncs) and applies per-connection pragmas (synchronous=NORMAL, cache_size=-65536 = 64MB page cache, mmap_size=268435456 = 256MB mmap I/O, temp_store=MEMORY). PRAGMAS MUST RUN IN ConnectHook — db.Exec() only reaches one pooled connection. sqlite-vec is auto-loaded via sqlite_vec.Auto() inside the once block.

POOL CONFIG (file DBs): db.SetMaxOpenConns(4) AND db.SetMaxIdleConns(4) — EQUAL, with SetConnMaxLifetime(0) + SetConnMaxIdleTime(0) so connections NEVER expire — plus Open() PRE-WARMS the pool (warmPool() force-opens all 4 connections up front). The DSN also sets `_txlock=immediate`. This trio is LOAD-BEARING and interdependent: immediate serializes cross-branch GraphQLite writes (which have no internal BUSY handling), but a lazily-opened/churned connection runs the ConnectHook -> loads the GraphQLite extension (a write to its EAV schema) -> which under a held immediate write lock self-deadlocks. Keeping the pool fully warm + pinned guarantees no connection is ever initialized mid-transaction. Do NOT set MaxIdleConns < MaxOpenConns, a non-zero ConnMax*Time, or drop warmPool. See [[graphqlite-write-serialization]]. (`:memory:` is special-cased to a SINGLE connection.)

WHAT THIS DOES NOT MEAN: the ConnectHook does NOT register any virtual tables. There is no registerVTabs function and no first_parent_chain vtab — the first-parent-ancestry walk was reimplemented as a recursive CTE over commit_parents (migration 000007; see internal/store/derived_from.go comment 'same streaming + short-circuit semantics as the previous first_parent_chain virtual table'). The ConnectHook body (internal/store/vec.go) is exactly: registerSQLFuncs + 4 pragmas + Extensions=graphqliteLibPath().
