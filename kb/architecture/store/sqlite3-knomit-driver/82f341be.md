# Custom sqlite3_knomit driver carries pragmas + extensions + vtab registration

Knomit uses a custom SQLite driver name `sqlite3_knomit` (NOT `sqlite3`), registered exactly once per process via registerVec() in vec.go using sync.Once. The driver carries: (1) GraphQLite extension load via the Extensions field; (2) a ConnectHook that runs on EVERY pooled connection — registers SQL functions (registerSQLFuncs), applies per-connection pragmas (synchronous=NORMAL, cache_size=-65536 = 64MB page cache, mmap_size=268435456 = 256MB mmap I/O, temp_store=MEMORY), registers vtabs (registerVTabs for first_parent_chain). PRAGMAS MUST RUN IN ConnectHook — db.Exec() only reaches one pooled connection. db.SetMaxOpenConns(4): SQLite serializes writes internally, limiting the pool avoids SQLITE_BUSY contention. sqlite-vec is auto-loaded via sqlite_vec.Auto() inside the once block.
