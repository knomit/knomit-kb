# Config layers defaults -> knomit.toml -> env; KNOMIT_HOME resolved first

config.Load() layers configuration lowest-to-highest: hardcoded Defaults() -> knomit.toml -> environment variables (each env var overlays only if set).

KNOMIT_HOME (KNOMIT_REPO is a backward-compat alias; the default is per-OS, see config.DefaultHome) is resolved FIRST, by config.ResolveHome, because it is the config search root. ResolveHome tilde-expands it and REFUSES a value that is still relative (`KNOMIT_HOME "<v>" must be an absolute path; set it to one`), for every caller. The root therefore cannot be overridden from inside the TOML (Load restores Home after decoding the TOML).

The config file is named knomit.toml (NOT config.toml) and is read ONLY from <home>/knomit.toml (findConfigFile). It is never looked for beside the binary; `knomit serve` and the desktop warn after log setup if one is there.

In the TOML, home/host/port/socket/ontology_root/onnx_lib_path/local_origin_root/methodology_min_score are BARE top-level keys (the home key is spelled `repo`). The rest are tables: [llm], [embeddings], [git], [remote], [cluster_cache], [session], [discovery].

Key defaults: host=localhost, port=19278, ontology_root=kb, embeddings.model=embeddinggemma, git.serve=true. (llm.provider=gemini and llm.model=gemini-2.5-flash were defaults until PR7, chore/remove-synthesis-job, which deleted the [llm] model, provider, api_key, cache and batch keys and KNOMIT_LLM_MODEL, KNOMIT_LLM_PROVIDER, KNOMIT_API_KEY, KNOMIT_LLM_CACHE and KNOMIT_LLM_BATCH with the v1 adapter they selected; [llm] now holds only the [llm.providers.<name>] tables, and KNOMIT_LLM_TRACE is read outside config by the registry wiring.)

Malformed numeric/duration env values fail at boot rather than being ignored. Some knobs are env-only (no TOML key): KNOMIT_REFLECT_PROPOSE_CAP, KNOMIT_REFLECT_NOVELTY_THRESHOLD, KNOMIT_PPROF_ADDR, KNOMIT_BASE_URL, KNOMIT_MCP_DEBUG.

WHAT THIS DOES NOT MEAN:
- The config file is NOT `config.toml`: a config.toml in KNOMIT_HOME is silently IGNORED.
- Nor is a knomit.toml placed next to the binary read: only <home>/knomit.toml is (config.go findConfigFile).
