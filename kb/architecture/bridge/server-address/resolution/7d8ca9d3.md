# kb resolves ONE server for every call — argument > KNOMIT_SERVER > desktop lockfile (server.json) > http://localhost:19278 — spelled by internal/serveraddr as http(s)://host:port, unix:///abs/path.sock or npipe:////./pipe/<name>; a malformed value is an error naming its source; local-listener requests carry the placeholder host http://localhost

Since PR fix/knomit-server (2026-10-02; replaced KNOMIT_BASE_URL, which the hooks read only, with no alias).

RESOLUTION (tools/bridge/knomitapi/server.go ResolveServer): (1) kb's positional argument (the proxy only — hooks have none, and knomitapi.ClassifyArgs never sees it), (2) KNOMIT_SERVER, (3) the desktop lockfile config.LockfilePath() = <state dir>/knomit/server.json -> http://127.0.0.1:<port>, (4) http://localhost:19278. Env and lockfile are read on every call, never cached. KNOMIT_HOME is NOT an input: it only decides where the default path's local listener is (config.SocketPath). The hooks now read the lockfile too (before, they went straight to 19278).

EVERY CALL: tools/bridge/main.go connect() builds discovery's client (3 s) and the proxy's (timeout 0, SSE) from the SAME Server by the same rule, so discoverAgentBranch — plain TCP to the lockfile/default before the fix, the rehearsal bug's first call — now follows a named socket too; terminateSession reuses the proxy client.

SPELLING (internal/serveraddr): http/https need a host and allow no path (other than '/'), query, fragment or credentials; unix:// is taken LITERALLY (no %-decoding, so 'Application Support' and '%' round-trip) and must be absolute (unix://relative is refused); Windows uses npipe:////./pipe/<name> (Docker's spelling) and refuses unix://, unix refuses npipe://. Parse errors do not name the source; ResolveServer wraps them as 'KNOMIT_SERVER: ...' or 'the server argument: ...', and kb exits 2. ForLocal/ForTCP format the server's own address (ForTCP turns a wildcard bind host into 127.0.0.1).

REQUEST URLS for a local listener are built on serveraddr.LocalBase = http://localhost (a placeholder: the transport dials the socket whatever the URL says); TestLocalBase_HostIsAcceptedByTheServer pins that hostguard.LoopbackHostOK accepts it, though socket requests are judged by peer credentials before any Host check. The hooks client disables keep-alives because every local listener shares that placeholder host, so a pooled connection could otherwise serve a request meant for another listener.

A malformed KNOMIT_SERVER in a hook: BaseURL logs at ERROR and returns the placeholder; the hooks client's dial resolves the same value and fails naming KNOMIT_SERVER, so no request leaves (TestClient_HooksMalformedKnomitServerSendsNothing).
