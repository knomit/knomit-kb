# buildMCPHandlers constructs exactly 3 MCP server instances (one per profile), shared across repos

Server.buildMCPHandlers() constructs EXACTLY THREE MCP server instances (one per profile: code, chat, generic) and wraps each in mcpserver.NewStreamableHTTPServer. Built ONCE lazily inside Server.Handler() if s.mcpHandlers == nil, then never rebuilt. The handlers map is map[string]http.Handler keyed by PROFILE name (NOT by repo). Each MCP server resolves the repo at request time via repos.RepoFromContext(ctx) populated by RepoMiddleware. mcp.NewServer is called with s.OntologyRoot as the default fallback and the optional embedder (for learn-dedup batching). See mcp/profile-keyed-servers-not-per-repo for the design rationale. Adding a new MCP profile: add the name to the profiles slice in buildMCPHandlers AND register the matching ProfileInstructions(profile, ...) branch in internal/mcp/instructions.go.
