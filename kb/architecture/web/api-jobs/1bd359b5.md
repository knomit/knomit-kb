# The job routes (synthesis-runs and index-rebuilds: start, list, get, delete, events) live in internal/edge/web/api/jobs, whose only export is Mount(r, rm, llmAdapter); router.go mounts it inside the /repos/{repo}/branches/{branch} group, and a nil llmAdapter makes only the synthesis start answer 503

Verified at 97ae7c19 (PR #627, web split step 12c, merge commit on dev). internal/edge/web/handlers_jobs.go moved to internal/edge/web/api/jobs/handlers.go (a pure move; the TaskHub-only behaviour is unchanged, see kb/decisions/web/jobs/taskhub-is-the-only-job-record/c514ec1b.md). The package exports exactly `func Mount(r chi.Router, rm *repos.Manager, llmAdapter llm.LLMAdapter)` (mount.go, no results); router.go calls `jobs.Mount(r, s.Manager, s.LLMAdapter)`.

ROUTES Mount registers on r: POST/GET /synthesis-runs, GET/DELETE /synthesis-runs/{id}, GET /synthesis-runs/{id}/events, and the same five for /index-rebuilds. The route table left router.go; router.go only mounts the package.

PRECONDITIONS: the caller must mount it INSIDE the /repos/{repo}/branches/{branch} group, behind RepoMiddleware and BranchMiddleware. Every handler reads the repo with repos.RepoFromContext; the rebuild start reads the branch with httpx.BranchFromContext. rm is used by the rebuild start and the rebuild cancel to send lifecycle events.

NIL ADAPTER: a nil llmAdapter makes ONLY the synthesis start answer 503 ("Synthesis unavailable"); list, get, delete, events and the rebuild routes are unaffected. A repo with no TaskHub also answers 503 on the synthesis start.

CONSEQUENCE: handlers are unexported and not callable from web; a test of a job route either goes through web's full router or builds a small router around jobs.Mount inside api/jobs (keepalive_test.go does the latter).

DOES NOT MEAN: that Mount authenticates or resolves the repo itself. It does neither; mounted outside the repo and branch groups the handlers would see a nil repo.
