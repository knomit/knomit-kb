# The job routes (index-rebuilds: start, list, get, delete, events) live in internal/edge/web/api/jobs, whose only export is Mount(r, rm); router.go mounts it inside the /repos/{repo}/branches/{branch} group. The synthesis-runs routes and the llmAdapter parameter are gone

Verified at 97ae7c19 (PR #627, web split step 12c, merge commit on dev). internal/edge/web/handlers_jobs.go moved to internal/edge/web/api/jobs/handlers.go (a pure move; the TaskHub-only behaviour is unchanged, see kb/decisions/web/jobs/taskhub-is-the-only-job-record/c514ec1b.md). At that commit the package exported `func Mount(r chi.Router, rm *repos.Manager, llmAdapter llm.LLMAdapter)` (mount.go, no results) and router.go called `jobs.Mount(r, s.Manager, s.LLMAdapter)`.

CHANGED BY PR7 (chore/remove-synthesis-job): the package now exports exactly `func Mount(r chi.Router, rm *repos.Manager)`, router.go calls `jobs.Mount(branch, s.Manager)`, `web.Server` has no LLMAdapter field, and handleStartSynthesis is deleted.

ROUTES Mount registers on r (at 97ae7c19 it also registered POST/GET /synthesis-runs, GET/DELETE /synthesis-runs/{id} and GET /synthesis-runs/{id}/events; PR7 deleted those five and TestJobs_SynthesisRoutesGone pins their 404): POST/GET /index-rebuilds, GET/DELETE /index-rebuilds/{id} and GET /index-rebuilds/{id}/events. The route table left router.go; router.go only mounts the package. hubOps maps the one remaining job kind, index-rebuild, to the TaskHub op "rebuild".

PRECONDITIONS: the caller must mount it INSIDE the /repos/{repo}/branches/{branch} group, behind RepoMiddleware and BranchMiddleware. Every handler reads the repo with repos.RepoFromContext; the rebuild start reads the branch with httpx.BranchFromContext. rm is used by the rebuild start and the rebuild cancel to send lifecycle events.

NO ADAPTER ANY MORE: the old nil-llmAdapter 503 ("Synthesis unavailable") went with the synthesis start. No job route depends on an LLM.

CONSEQUENCE: handlers are unexported and not callable from web; a test of a job route either goes through web's full router or builds a small router around jobs.Mount inside api/jobs (keepalive_test.go does the latter).

DOES NOT MEAN: that Mount authenticates or resolves the repo itself. It does neither; mounted outside the repo and branch groups the handlers would see a nil repo.
