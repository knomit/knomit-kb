# chat_state is the rail's row-change event: the chat's rowState {chat, title, state: idle|running|awaiting_approval|error, turns, cost_usd?, last_activity, started_at}, sent only when the row differs from the last one sent (last_activity aside)

rowState (chat.go) is derived under the chat lock from the view: awaiting_approval when approvals are pending, else running, else error when the last turn ended with a non-cancelled error, else idle; turns counts user items; cost_usd sums the turns' cost (absent without a price card). noteState compares the JSON with the last frame and emits only a change, from startTurn, the approval ask and answer, each usage event and finishTurn. Since the rail PR, rowState also carries title (the first message, set once), last_activity and started_at, and GET /chats embeds the same rowState in each list row, so the live event and the row never disagree (kb/architecture/web/api-chat/621fc1e7.md). noteState ignores last_activity when deciding whether the row changed, because it moves with every frame. Not sent for a chat's creation (the POST answers) or its end (chat_end).
