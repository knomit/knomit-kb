# chat_state is the rail's row-change event: {chat, state: idle|running|awaiting_approval|error, turns, cost_usd?}, sent only when the row differs from the last one sent

rowState (chat.go) is derived under the chat lock from the view: awaiting_approval when approvals are pending, else running, else error when the last turn ended with a non-cancelled error, else idle; turns counts user items; cost_usd sums the turns' cost (absent without a price card). noteState compares the JSON with the last frame and emits only a change, from startTurn, the approval ask and answer, each usage event and finishTurn. The next PR (GET /chats rows with title/state) should extend rowState and reuse it for the list rows so the live event and the row never disagree. Not sent for a chat's creation (the POST answers) or its end (chat_end).
