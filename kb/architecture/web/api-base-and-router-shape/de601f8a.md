# APIBase=/api/v1; router uses chi v5 with Recoverer + Compress(5); per-route middleware at group level

APIBase = '/api/v1' (router.go) is the SINGLE prefix constant for the HAL API. Server.Handler() mounts s.NewAPIRouter() under APIBase via chi.Mount. The router uses chi v5 with global middleware Recoverer + Compress(5) (the HAL hard-rule compression — see web/hal-response-hard-rules fact). Default NotFound and MethodNotAllowed handlers emit application/problem+json so 404/405 responses match the error shape on the rest of the surface. Per-route middleware (BranchMiddleware, RepoMiddleware) attach at the route-group level via r.With(BranchMiddleware).<Verb>(...) — NOT at the router root — so /repos and /repos:rescan don't require branch decoding. hal.URLBuilder{Base: APIBase} is constructed once in NewAPIRouter and passed to every handler that needs to build outbound URLs.
