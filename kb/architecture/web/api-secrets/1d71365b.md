# The /api/v1/secrets routes (api/secrets, Mount(r, rm)) are mounted only on the plain API router behind requireLocalOrSameOriginAdmin, never on the OAuth listener; responses never carry a value

internal/edge/web/api/secrets exports only Mount(r chi.Router, rm *repos.Manager). router.go's NewAPIRouter mounts it as r.Route("/secrets") with r.Use(s.requireLocalOrSameOriginAdmin), like /oauth/pending, so the OAuth listener's router (apiRouter via OAuthHandler) does not serve it at all, and on the plain listener only a local socket/pipe principal or the anonymous loopback principal holding admin with the browser proof (X-Knomit-Client: web) gets through. A bearer or certificate principal holding admin is refused 403.

Routes: GET / (list), POST / (201 with Location), GET /{id} (view plus repos), PATCH /{id} (name, expires_at absent/null/string told apart with json.RawMessage, hosts as the full list, value fields), DELETE /{id}. The view is metadata only: id, name, type, hosts, expires_at, status (ok|expiring|expired|none, computed server-side, expiring = within 14 days), created_at, updated_at, fingerprint (ssh_key), linked_repos, _links.self.

PATCH validates every field before writing (control.ValidateSecretName, NormalizeHosts, ValidateSecretValue) and, when it carries a value, refuses with 503 up front if the instance key is unreadable (Secrets.CanStoreValues false), so metadata never changes alone, then applies name, hosts and expiry in ONE transaction (control.Secrets.Update), so any refusal (a host in use, a taken name) changes nothing; the already-validated value is replaced last through Manager.ReplaceSecretValue, which wakes linked repos with a breaker reset.

Error mapping: ErrSecretInvalid 400 (names the field), not found 404, name taken 409, HostInUseError 409 with hosts and repos extension members, InUseError 409 with repos ("Unlink these repositories first: a, b"), ErrSecretUndecryptable 422, ErrEncryptionUnavailable or a nil Secrets tenant 503 ("Secret storage is unavailable: the instance key cannot be read.").

A new api package needs entries in three archtest allowlists: sameLayerEdges (layers_test.go), webKnownTypes (web_no_interfaces_test.go) and webAPIExportAllowlist (web_split_test.go).
