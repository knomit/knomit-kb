# web.Server struct owns server-wide state (LLMAdapter, embedder, config); SynthDeps deleted

internal/web has a Server struct that owns server-wide state: Manager, GitHandler, EmbeddingsEnabled, OntologyRoot, AgentBranch, SessionManager, LLMAdapter, Embedder. cmd/serve.go constructs the Server and calls srv.Handler() instead of the old NewRouter(args...). Synth handler is a method on *Server that creates the Reviewer ON-DEMAND from per-repo gs/idx + server-wide embedder/agentBranch — cheap struct init. SynthDeps (the field on repos.RepoInstance that bundled Reviewer + LLM) is DELETED entirely — LLM doesn't belong on repos, only on web. repos.Deps loses its LLM field; the LLM adapter is constructed and held by web.Server. Don't pass LLMAdapter through repos.
