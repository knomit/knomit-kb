# web.Server struct owns server-wide state (LLMAdapter, Embedder, config); SynthDeps deleted; synth handler is a free func taking Manager+LLMAdapter

internal/web has a Server struct that owns server-wide state: Manager, GitHandler, EmbeddingsEnabled, OntologyRoot, AgentBranch, SessionManager, LLMAdapter, Embedder (plus ReadOnly, APIOnly, CORSOrigins, JobRegistry, and the pluggable provider fields). cmd/serve.go constructs the Server and calls srv.Handler() (server.go) instead of the old NewRouter(args...); Handler() lazily builds the MCP handlers, mounts /git and the API router under APIBase.

The synthesis-run POST handler is handleStartSynthesis(m *repos.Manager, llmAdapter llm.LLMAdapter) in handlers_jobs.go — a FREE FUNCTION (not a *Server method), wired in router.go as handleStartSynthesis(s.Manager, s.LLMAdapter). It creates the Reviewer ON-DEMAND per request via synthesize.NewReviewer(ri, nil) — from the resolved repo instance ri, NOT from server-wide embedder/agentBranch — and runs it in the repo's TaskHub. Returns 503 if llmAdapter is nil, 409 if a synth job is already running.

SynthDeps (the field on repos.RepoInstance that bundled Reviewer + LLM) is DELETED entirely — zero references remain. repos.Deps has no LLM field; the LLM adapter is constructed and held by web.Server. Don't pass LLMAdapter through repos.

WHAT THIS DOES NOT MEAN: the synth handler is NOT a method on *Server, and there is no entity named handleSynthesizeStart — the function is handleStartSynthesis and it is a package-level func. The Reviewer is built from the per-repo ri, not from s.Embedder/s.AgentBranch (verify: handlers_jobs.go).
