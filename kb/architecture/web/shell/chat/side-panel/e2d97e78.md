# A tool call's side panel is headed by the row that was clicked: ToolCallHead draws the same ToolCallDot and ToolCallLine as the timeline row, from the transcript's own ToolCall

ChatToolGroup.tsx owns three pieces: ToolCallDot (7px state mark: amber running, green done, red failed; on the rail it is absolutely placed, elsewhere inline), ToolCallLine (toolCallLabel, the key argument in mono, then size and time; 12.5px, weight 400, line-height normal, #c8c8c8 or #e0a0a0 when is_error), and ToolCallHead (dot + line, data-error/data-state, optional `style`, rendered as chat-result-title). The timeline row renders ToolCallDot + ToolCallLine inside its button. Since feat/chat-result-json-view, ChatSidePanel renders ToolCallHead IN ITS TOP ROW (chat-panel-header), beside the close, in place of the breadcrumb a result entry used to have; ChatResultPanel no longer draws any heading. Commit entries keep their breadcrumb header (chat-panel-crumb); fact entries keep their band. The panel gets the row's data through ChatSidePanel's callFor prop (ChatFacet passes findCall(state.turns, id)), so header and row share durationMs, summary and loaded; when the transcript has no such call it falls back to toolCallOf(callId, loadedCall) (ChatSidePanel's onCall stores it when ChatResultPanel reports the loaded call), which has no duration or size. Before the call loads and with no transcript row, the top row holds only the close. Consequence: to change how a call looks or is worded, change ToolCallLine / toolCallLabel once; never give the panel its own title or tool wording. ChatSidePanel.test asserts dot and line computed styles, label and line text, and data-error are equal between row and header for a succeeded bind, a failed bind, an unknown tool and the loader, and that ChatSidePanel.tsx and ChatResultPanel.tsx source contain no toolRowLabel/toolVerb/tool words. Misreading to avoid: the header is not a heading in the display font any more (the old 19px 'knomit: Knomit bind' title is gone); fact entries (ChatFactView) are untouched and keep their own heading.
