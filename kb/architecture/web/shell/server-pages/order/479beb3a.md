# serverPagesFor answers ['access', 'logs'] (Access first) since feat/access-layout, but TOGGLE_SERVER still opens on Logs, so the gear lands on the SECOND tab

web/src/facets.ts serverPagesFor(false) is ['access', 'logs'] and the top bar draws the server tabs in that order. The landing page is a separate decision in viewReducer's TOGGLE_SERVER, which still returns server: 'logs'. Do not read 'Access is first' as 'the gear opens Access': it does not; changing the landing page means changing TOGGLE_SERVER (and App.server.test's expectation that server-tab-logs is selected after opening). On a read-only server serverPagesFor is [] and there is no gear. The lit gear is the accent #7c9 on the glyph with a transparent background (no #1a231d fill).
