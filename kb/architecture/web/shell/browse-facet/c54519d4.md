# The branch or mounts picker and the filter live in BrowseFacet's toolbar, not the top bar; the top bar holds only the rail toggle, the name crumbs, the facet tabs and the gear

`BrowseFacet` (web/src/BrowseFacet.tsx) owns ExperimentBand, the create/index banners, a `FacetToolbar` with test id `browse-toolbar` holding `BranchPicker` (repo context) or `MountsPicker` (lens context), the FilterBar embedded while live, and the Library | splitter | RightPanel row. The top bar no longer carries any of these.

Consequence: tests and code that looked for `toknomitr-search`, `toknomitr-repo-select` or the branch chip inside `toknomitr-bar` must look in `browse-toolbar` or the rail. `/` still works because it targets `#filter-input` by id. BranchPicker is NOT in the window-drag region any more, so it carries no `data-nodrag`; the topbar-drag-region gotcha applies only to controls left in TopBar (the rail toggle, the tabs, the gear).

WHAT THIS DOES NOT MEAN: a dropdown reading like a host name (for example `<host> v` at the left of the toolbar) is the BRANCH picker (`toknomitr-branch`, the agent branch is `agent/<host>-<fp8>`), not a server or host picker.
