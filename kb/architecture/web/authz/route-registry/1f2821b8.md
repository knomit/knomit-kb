# The HTTP route -> permission registry is internal/edge/web/route_rules.go (apiRouteRules rooted at the API router, outerRouteRules for /git/*, /docs, /assets/*, /*); TestRouteRules_EveryRouteDeclared walks both live routers and requires EXACTLY one rule per METHOD+pattern; it is NOT enforced until the flip (P4)

routeRule{Method, Pattern, Perm | Resolve+Possible}. Patterns are spelled exactly as walkFull prints them: the API router rooted at '/' (no /api/v1), the outer router's own routes. MCP mounts and the /git mount are HandleFunc/Mount routes, so they are declared for every method chi registers: CONNECT DELETE GET HEAD OPTIONS PATCH POST PUT QUERY TRACE (chi v5.4 adds QUERY; net/http has no constant). ruleFor(router, rules, r) finds a request's rule via chi's Router.Find, which descends into mounted subrouters and returns the composed pattern; no route or an unserved method => (zero,false) => deny. For the API router r.URL.Path must be relative to /api/v1.

Tests (route_rules_test.go): EveryRouteDeclared and NoDeadRows walk a server built with an OAuth issuer and a git handler and APIOnly=false (otherwise /oauth/*, /git/* and the static routes are not mounted and would go undeclared); WellFormed; ResolversStayInPossible (fixtures per resolver, and the handler still reads the whole body); RuleFor_FindsMountedSubrouterPatterns; Rulings (/chats* chat:use, /secrets* secret:manage, /oauth/* auth:manage, MCP mounts kb:read, sessions/logs ops:run, version public).

Consequence: adding a route now fails these tests until it gets a row. Until P4 the old gates (writeGate, requireOperator, RequireLocalVia, requireLocalOrSameOriginAdmin) still decide; the table changes no behaviour.

Assignments worth knowing: GET /fleet, /fleet/members, /fleet/activity are kb:read but GET /fleet/root is fleet:manage (it RETURNS the fleet root key files); GET /openapi.yaml is public like /docs; POST /facts/resolve and factset DELETEs are kb:read; POST /ontologies:validate is kb:write (today's write gate); GET /chat-providers is kb:read (not under /chats).
