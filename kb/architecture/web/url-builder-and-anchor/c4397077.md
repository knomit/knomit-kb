# All outbound URLs go through hal.URLBuilder + Anchor; commit pin propagated by construction

ALL outbound URL construction goes through hal.URLBuilder + hal.Anchor (internal/web/hal/anchor.go). Anchor{Branch, Commit} captures temporal context: empty Commit = HEAD; set Commit = pinned snapshot. URLBuilder methods (Fact, FactIncoming, FactOutgoing, FactCommits, BranchOrCommitPrefix) take an Anchor and propagate the '/commits/{sha}/' segment automatically — commit-anchored hrefs come out with /commits/{sha}/; HEAD-anchored hrefs don't. The '/'→':' substitution for branch names happens in exactly ONE place: hal.EncodeBranch (used by URLBuilder.Branch). Anti-pattern: building href strings with fmt.Sprintf or strings.Join inside a handler — always go through URLBuilder so the anchor and branch encoding stay consistent. NOTE: FactCommits explicitly STRIPS the commit pin (commit logs are not themselves commit-pinned — the fact's commit log is always branch-anchored).
