# The New fleet wizard derives its steps from the state (stepsFor) and maps each join:check refusal code to a Bundle-step card and each join refusal code to a Review note; a step the state has not earned is not offered

Verified at the merge of PR #529 (60ddfb1c), web/src/fleetWizardState.ts and fleetText.ts (the wizard shipped in #526/#528; recorded here from HEAD). STEPS are derived by stepsFor, never fixed: create on this instance: Start, Hosting, Review; create on a forge not probed yet: Start, Hosting; create on a forge that answered: Start, Hosting, Access, Review; join without a checked bundle: Start, Bundle; join to a fleet its master hosts: Start, Bundle, Review; join to a fleet on a forge: Start, Bundle, Access, Review. Reducer rules: a new forge URL drops its probe and the access confirmation; a new bundle drops its check; a new credential drops accessChecked; a probe that answered jumps to Access; a checked bundle jumps to Access (hosting forge) or Review; GOTO a step the state has not earned is ignored; a step that disappears clamps to the last one. Server messages are never reworded: the card shows the server's text verbatim with its code beneath.

JOIN:CHECK refusal code -> Bundle-step card headline (checkRefusalCard): agent_mismatch 'This bundle is for another instance' (hint: send the master this instance's agent id and public key and ask for a new bundle); key_mismatch 'The bundle was issued for a different key' (same hint); bundle_invalid 'That is not a fleet bundle'; unreachable "Couldn't reach <host>" (host from the bundle's url: header by bundleHost); bundle_refused 'The fleet at <host> refused this bundle' (hint: ask the master for a new bundle); any other code 'The check was refused'.

JOIN refusal code -> the note under the refusal on Review (joinRefusalNote): key_mismatch 'Nothing was kept. Send the master this instance's public key and ask for a new bundle'; root_differs 'Nothing was kept. The bundle is for another fleet'; join_refused 'Nothing was kept. You can try again once the master's next round has published the certificate'; bundle_refused 'Nothing was kept. Ask the fleet's master for a new bundle'; other 'Nothing was kept.' (join is all or nothing, kb/invariants/fleet/join/a0225037.md).

CREDENTIALS: credentialFor(url, method, user, secret) is the one assembly of a forge credential for the fleet routes (a secret typed under auto-detect is token auth unless the URL is ssh; basic is user:password; none sends no token); the wizard's Access step and every Fleet Settings flow use it.

MISREADINGS. 'The rail lists a fixed Create or Join sequence': it lists only earned steps. 'The Bundle card text comes from the page': the headline does, the detail beneath is the server's.
