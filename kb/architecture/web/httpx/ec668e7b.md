# internal/edge/web/httpx holds the web edge's 21 shared HTTP helpers (step 12b of the web split): web and later resource packages call httpx.X directly, there are no forwarding shims in web, and compress.go and cors.go stay in web

internal/edge/web/httpx is the shared-helpers package of the web split (step 12b, PR #622, merge commit 3e67923b on dev, re-read there). It exports exactly 21 names. 17 are new to it: StoreUnavailable, WriteStoreUnavailable, WriteStoreError, WriteLifecycleProblem, IsLifecycleRefusal, DecodeJSON, DecodeOptionalJSON, IsJSONMediaType, StartSSE, SelfWithQuery, RefuseUnwritableBranch, IsLocalVia, TrimOriginURL, ValidateURLAuth, AssembleAuthToken, IsGitURL, ArchiveSummary. 4 moved unchanged: APIBase, BranchMiddleware, BranchFromContext, RequireLocalVia.

By concern: store-error translation (errors.go), lifecycle refusals (lifecycle.go), JSON body decoding (decode_json.go), SSE (sse.go; the sseStream type is unexported, only StartSSE is exported), branch middleware and APIBase, local-via checks (local_via.go), the read-only/unwritable-branch refusal (readonly.go), origin URL and auth-token helpers (origin_url.go, origin_auth.go), archive summary (archive.go), and the query-string self link (params.go).

LAYERS. httpx imports edge/web/hal and lower layers, never edge/web. test/archtest/layers_test.go lists the one edge "edge/web/httpx -> edge/web/hal" in sameLayerEdges (httpx is a sibling of hal under edge/web, not a subpackage of it). web -> httpx needs NO entry: isFamily treats a package and its subpackages as one family. Later resource packages import httpx, not web.

NO SHIMS. Call sites in web say httpx.X. There are no aliases, const copies or unexported forwarders in web (verified at 3e67923b: no lowercase writeStoreError, decodeJSON, storeUnavailable, writeLifecycleProblem or selfWithQuery remains anywhere under internal, cmd or test). compress.go and cors.go stay in web because no child package uses them.

GUARDS that follow the move: internal/engine/store/changes_guard_test.go keys allowed calls as <package qualifier>.<name>, so the entries read httpx.WriteStoreError, httpx.WriteStoreUnavailable, httpx.SelfWithQuery and httpx.BranchFromContext. TestNoHandlerDecodesARequestBodyOutsideDecodeJSON (internal/edge/web/decode_json_guard_test.go) walks web recursively, so it covers httpx too. Since 12a (PR #621, merged on dev as 7dccaa09) httpx is covered by the no-interfaces guard W (kb/conventions/go/package-boundaries/web-no-interfaces/d36fa222.md; its webKnownTypes entry is sseStream in sse.go) and by guard F, which forbids forwarding shims inside the web family (kb/invariants/testing/web-family-forwards).

DOES NOT MEAN: that httpx is a place for any helper two files share. A name moves here only when a package outside httpx needs it; unexported helpers (requireJSONContentType, decodeBodyInto, writeDecodeProblem, sseStream, cancelIndexURL) stay private. It also does not mean the rest of the web split is decided here: the rulings for the later resource packages are recorded when those steps land.
