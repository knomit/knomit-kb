# knomit-tray is pure supervisor + lockfile discovery; CGO confined to tools/tray/

knomit-tray (tools/tray/) is a pure process supervisor with NO HTTP logic. It picks a free port via netutil.PickPort (prefers 19278), spawns 'knomit serve --port N --host 127.0.0.1', WaitForHealthy(10s), writes a lockfile {pid, port, version} to <StateDir>/server.json with 0600 perms and atomic write-then-rename. knomit-remote and any future MCP client discover the running server via this lockfile (no URL needed). Single-instance enforcement: lockfile PID + os.FindProcess(pid).Signal(syscall.Signal(0)) probe — alive PID returns ErrAlreadyRunning, stale (dead PID) is treated as free. CGO is CONFINED to tools/tray/ (webview_go, fyne.io/systray); the main knomit binary stays CGO-free. Phase 1 supervisor does NOT auto-restart on crash — user must click 'Restart server' in the menu. WKWebView requires the GUI event loop on the main OS thread — runWindow calls runtime.LockOSThread().
