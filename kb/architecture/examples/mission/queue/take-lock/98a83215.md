# The mission queue's per-copy lock is knomit's atomic move: a session TAKES a copy by learning it into inbox/<agent>/active/ with `retract` of the working/ path in one call, so a second session's identical move is refused and `concurrent` > 1 is safe; CAPACITY counts working + active (the backlog), `concurrent` is the parallelism

examples/mission/ since feat/mission-drain-inbox. inbox/<agent>/working/ is the queue (taken or assigned, not started); inbox/<agent>/active/ holds copies a session has taken. The work-task skill's take is ONE knomit_learn on the mission handle: the copy's title/body/entity unchanged, `category: <agent>/active`, `expires: <the session's lease>`, and `retract: [<working path>]`. The retract precondition makes it exclusive: the second identical move finds the copy gone and is refused as a whole (TestMission_ActiveCopyLockAndLease), so two draining sessions never work one copy. The ack retracts the ACTIVE path.

DRAIN: the session works every copy in working/, re-queries after each ack, and stops only when the query is empty; the copy named in its prompt is only the starting point. A copy under active/ named in the prompt (its session died; the lease fired) is taken over by the same move, active -> active.

CAPACITY (claims.js, awards.js) is the BACKLOG: offer, bid and decide count every copy under inbox/<agent>/ (working + active). decide re-checks it right before the take and withdraws its claim when full (TestMission_DecideRechecksCapacity). takeAward NEVER refuses for capacity: the award already retracted the offer, so refusing would lose the task. The recipe's `concurrent` is the PARALLELISM (sessions at once); the template ships 1.

The backstop dup-check now matches inbox/** and counts working AND active copies (a peer may move its copy into active/ before the other's arrives, so the working path never appears in the receiver's diff range); decide's 'somebody already works on it' check counts both too.

MISREADING: an experiment name is NOT a lock — knomit_experiment open on an existing name resumes it. The lock is the move.
