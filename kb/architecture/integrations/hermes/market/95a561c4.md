# Hermes Agent (Nous Research) is the largest self-hosted agent host by GitHub stars as of 2026-09-13 — 245k stars, 760+ contributors, MIT, Python, gateway/cron/kanban personas — and its own users call its memory 'intentionally constrained'

Snapshot taken 2026-09-13 (GitHub API): 245,092 stars, 50,946 forks, repo created 2025-07-22, latest release v0.21.2 (v2026.9.11). v0.21.0 'Pantheon' (2026-08-31) counted ~5,800 commits and 760+ contributors since v0.20.0. Turing Post (June 2026) claimed Hermes overtook OpenClaw on OpenRouter daily tokens, 224B vs 186B — third-party, unverified.

What it is: MIT-licensed, self-hosted, model-agnostic Python agent harness marketed as 'the self-improving AI agent'. Surfaces: CLI/TUI, always-on messaging gateway (Telegram, Discord, Slack, WhatsApp, Signal, email, Home Assistant, ~25 channels), stateful cron (since v0.21.0), SQLite kanban dispatching profile processes, delegate_task subagents, ACP for VS Code/Zed/JetBrains, `hermes peer` agent-to-agent, MCP client (`mcp_servers:` in config.yaml, tools named mcp_<server>_<tool>) and MCP server (`hermes mcp serve`). Model backends: 18–50+ providers incl. Anthropic, OpenAI, OpenRouter, local OpenAI-compatible servers; Nous Portal is the paid gateway that monetizes the free agent.

Center of gravity is personal assistant + automation + homelab, NOT coding-first; third-party comparisons rate Claude Code higher on coding. Head-to-head rival is OpenClaw (Node.js, human-authored markdown workspace). Memory platforms (mem0, Honcho, Supermemory, Letta) are treated as providers, not rivals.

Known criticisms: memory 'intentionally constrained'; consolidation rule is a prompt not code; contradictions accumulate; 'forget' leaves an internal summary; provider layers push reply latency ~1 s → 3 s+; minors break upgrades (v0.21.0→v0.21.2 shipped state.db lock/corruption bugs); June 2026 EvoMap plagiarism allegation that Nous handled poorly on GitHub.

CONSEQUENCE: for knomit, Hermes is a distribution channel roughly five orders of magnitude larger than knomit's own (1 star, 2 contributors on 2026-09-13), whose users self-host by conviction (matches knomit's local-first stance) and whose memory pain points are knomit's core mechanics. Pin any adapter to a Hermes version range and keep knomit logic out of the Python plugin because of churn.

WHAT THIS DOES NOT MEAN: star count is not usage; the token-share and any valuation figures are claims from third parties.
