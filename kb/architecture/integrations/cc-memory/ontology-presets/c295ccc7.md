# Two embedded ontologies; --ontology-preset selects between them

knomit will ship two embedded ontologies under internal/fact/: ontology_default.yaml (existing, Wikipedia-style for general knowledge) and ontology_code.yaml (new, source-code repos). The code ontology defines top-level topics invariants, architecture, conventions, decisions, gotchas, incidents, meta, each with curated children (e.g. invariants/{architecture,data,protocol,concurrency}; conventions/{testing,logging,errors,naming,git}). 'meta/reasoning' is preserved from default because knomit_review and knomit_hypothesize write methodology facts there. A new --ontology-preset <name> flag on cmd/init.go selects from the embedded registry; the existing --ontology <path> still works for custom files; the two flags are mutually exclusive.
