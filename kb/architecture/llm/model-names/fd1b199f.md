# A models entry is validated per provider: shape, then empty id or name, then duplicate id, then names. A name must be unique within its provider and must not equal the id of a different model there

Load refuses a [llm.providers.<p>] models list with these messages, each prefixed by 'config: [llm.providers.<p>]': models[i] must be a model id or { id, name } (non-string, non-table, unknown key, or non-string id/name); models[i] id is required (empty or missing id); models[i] name must not be empty (a name key present but blank); models: id "x" is listed more than once; models: name "x" is used by more than one model; models: name "x" is the id of another model. The last check takes the effective name, which is the name or else the id. A model with no name is therefore protected from being named by another model's name. Two providers may share a name. A name equal to the model's own id is allowed. Misreading to avoid: a name is not a unique key across providers, and a name is never a lookup key for requests.
