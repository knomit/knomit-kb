# A chat model's display name is resolved at read time from the current config; the model id stays the identity everywhere else

Under [llm.providers.<p>] each models entry is a model id string or an inline table { id, name }. The name is display-only. The id remains the identity: the per-model tables [llm.providers.<p>.model.<id>] are keyed by id, API requests that pick a model send the id, and chat records, chat logs, the session log and server logs store the id only. Never store the name in a chat. Chat items and the models list carry a name field computed from the config when the response is built (chatItem.Name via manager.modelName -> Registry.ModelName -> LLMProviderConfig.ModelName). A model no longer configured, or a provider no longer configured, yields its id. Do not read the name from a stored chat record, and do not use it as a key.
