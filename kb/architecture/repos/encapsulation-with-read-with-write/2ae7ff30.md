# RepoInstance fields are unexported; lock-protected access via WithRead callback only

ALL RepoInstance fields are unexported (mu, name, dbPath, agentBranch, gs, svc, idx, hub, syncCancel, syncWg, mcpHandlers, synthDeps, startSync, close). Lock-protected fields (gs, svc, idx, mcpHandlers, synthDeps) are accessed EXCLUSIVELY via ri.WithRead(fn func(StoreDeps)) which calls fn under a read lock and bundles all five fields into a StoreDeps value. There is NO public RLock/RUnlock — those are removed. The unexported withWrite(fn func()) is used only within the repos package (SwapStore, SetupMCP). Immutable fields get simple getters: Name(), Branch(), TaskHub(), ActivateSync(url). dbPath/syncCancel/syncWg/close are internal to repos package, no getters. Anti-pattern (FORBIDDEN): direct field access from outside repos package — the field unexport makes this a compile error. SetupMCP fixed a prior data race where mcpHandlers/synthDeps were written without a lock; now uses withWrite for the assignment.
