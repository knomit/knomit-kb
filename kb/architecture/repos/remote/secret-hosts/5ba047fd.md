# A stored secret's hosts list matches a remote by control.HostAllowed: a bare host allows every port, host:port allows only that port; SetHosts refuses a change that would stop a linked repo from matching

Secrets are host-bound. control.RemoteHost(url) extracts the lowercased host (host:port when the URL has a port) from http(s)://, ssh:// and scp-like user@host:path remotes; file:// and local paths are an error (no host). control.NormalizeHost accepts only a bare host with an optional :port (no scheme, path, userinfo).

control.HostAllowed(hosts, remoteHost) is true when an entry equals the remote host, or when a bare-host entry equals the remote's host name (so "github.com" allows github.com:2222, but "github.com:2222" does not allow github.com). The resolver's host check should reuse HostAllowed rather than re-implement matching.

Secrets.SetHosts(id, hosts) replaces the whole list (normalised, deduplicated, at least one). It refuses with *HostInUseError (errors.Is ErrSecretHostInUse), writing nothing, when a linked repo's remote host is allowed by the current list and would not be by the new one; Hosts names the removed entries that repo matched, Repos names the repos. A removal that leaves the repo still covered by another entry is allowed.
