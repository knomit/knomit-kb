# Four remote auth methods (token/basic/ssh/none); tokens encrypted at rest

A repo origin supports four auth methods, stored in Remote.AuthMethod and inferred from the URL/fields if empty. **token** (GitHub PAT etc.): AuthToken=<token>, sent as HTTP basic auth with username defaulting to x-token; auto-detected for https URLs with a token. **basic**: AuthToken="user:password" stored in the single field, split on the FIRST colon. **ssh**: key path from KNOMIT_REMOTE_SSH_KEY, falling back to the agent key ~/.knomit/id_ed25519; auto-detected for git@/ssh:// URLs. **none/anonymous**: public repos. Auth tokens are NEVER stored plaintext — AES-256-GCM with a key derived (HKDF-SHA256) from the agent SSH private key, stored base64 in remotes.auth_token; if the SSH key is unreadable the encryptor is unavailable and SetRemote REFUSES to persist any token. The upstream consensus branch is Remote.Branch (default main, configurable e.g. master). Local-path origins are disabled unless KNOMIT_LOCAL_ORIGIN_ROOT is set, then gated to within that root via validateLocalOrigin.
