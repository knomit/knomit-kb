# Manager.Start globs repos/*.db and creates nothing; launches the session reaper; Close is two-pass cancel-then-wait over index-heal+sync loops

Manager.Start() makes `<home>/repos/`, opens `control.db` (lens registry + repo settings), then globs `repos/*.db` (sorted) and Adds each, skipping session sidecars (store.IsSessionDBFile) and invalid names (warn log). It opens NO repo specially and CREATES none — there is one glob loop and no privileged name — so a fresh home boots with zero repos registered and Start still returns nil. Finally it launches the background idle-SESSION REAPER via m.startSessionReaper(parseSessionReaperConfig(cfg.Session)), storing its stop func in m.sessionReaperStop (a misconfigured [session] block fails Start at boot rather than silently disabling the reaper).

Manager.Close(): (1) stop the session reaper first (m.sessionReaperStop); (2) snapshot the instances list, then PASS 1 cancels each repo's index-heal (indexCancel) AND sync loop (syncCancel) so they wind down in PARALLEL; (3) PASS 2 waits indexWg THEN syncWg per repo (heal's activate() does syncWg.Add for the reconcile loop, so indexWg must settle first), then hub.Shutdown() + closeFn(). Two passes because cancelling everything up front lets loops wind down concurrently instead of serializing a cancel-wait roundtrip per repo. Returns nil; the error return matches io.Closer for forward compatibility. Callers MUST pair Start with Close.

WHAT THIS DOES NOT MEAN: Start does not open a default repo first and then glob the rest — that two-step shape, the isDefault flag, and initDefaultGit were all removed (2026-08-07); see the no-default-repo invariant. There is no config.DefaultRepoName constant to consult. Start also does NOT launch a 'cluster-cache warmer' / startClusterChecker / clusterCheckerStop — that background Louvain goroutine was DELETED (commit d526c3e); the background goroutine Start launches today is the session reaper. Close pass-1 is NOT 'stop the cluster checker first'; it cancels index-heal + sync loops. Enforcing code: internal/repos/manager.go (Start, Close); internal/repos/session_reaper.go (startSessionReaper).
