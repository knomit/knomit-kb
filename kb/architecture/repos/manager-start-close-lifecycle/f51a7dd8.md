# Manager.Start opens knomit.db first then globs; Close is two-pass cancel-then-wait

Manager.Start() opens knomit.db FIRST with isDefault=true so a fresh DB gets initDefaultGit (clone-from-origin or create-with-default-ontology). Then globs repos/*.db (sorted) and Adds each, skipping invalid names with a warn log and skipping the already-opened knomit. Finally launches the background cluster-cache warmer via startClusterChecker, returning its stop func into m.clusterCheckerStop. Manager.Close() does TWO-PASS shutdown: (1) stop the cluster checker FIRST because its Service-side reads need repos still open; (2) cancel ALL sync loops concurrently (snapshot instances list then call ri.syncCancel for each); (3) wait + shut down each repo's hub + closeFn sequentially. Two passes because cancelling all syncs first lets them wind down in PARALLEL — sequential wait+close per repo would serialize the cancel-wait roundtrip. Returns nil; error return matches io.Closer for forward compatibility. Callers MUST pair Start with Close.
