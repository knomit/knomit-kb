# authz.Materializer caches each (principal, implicit roles) policy stamped with the bindings version; every For reads Store.Version with one SELECT, so a Bind/Unbind/reseed takes effect on the next call; a store error returns an error AND a policy granting nothing; the owner never touches the store

internal/foundation/authz/materialize.go. For(ctx, p, via, implicit...):
0. A principal that does not round-trip through ParsePrincipal to itself (zero principal, zero-padded uid, malformed SID, anonymous with an ID, unknown kind) => error and a policy granting nothing, before the owner comparison or any store read.
1. If p's Kind+ID equal the owner given to NewMaterializer (and that owner is a non-empty os principal): Policy{Owner: true}, Version 0, no store access. Has() is true for the ten known permissions and Public only: an empty or unknown permission string is denied even to the owner, so a typo in a gate fails closed.
2. Otherwise one SELECT of auth_state.bindings_version. Error => return the bare policy (only Public) plus the error, even if a cached entry exists.
3. Cache key = principal string + sorted implicit roles (+ AnonymousRoles for anonymous). A hit is used only while its stamped version equals the version just read. A miss loads bindings and role permissions in one read-only transaction stamped with the version read inside it; seeing a new version drops the whole cache map (bounded by principals seen since the last change).
4. Permissions = union over admitted roles; an unknown permission row is ignored with a WARN.

Policy.Via is audit-only; Has never reads it. The zero Policy denies everything but Public, so code that finds no policy in the context (PolicyFrom false) fails closed.

Consequence for long sessions (P4, chat/MCP): compare Policy.Version with Store.Version to notice a revoked token or unbound role; a cached Policy value held across calls does not update itself.

Read-only mode: MaterializerOptions.AnonymousRoles = [guest] is held in memory only and never stored; any other role there is ignored with a WARN.
