# knomit exposes 7 MCP tools over a per-branch endpoint with 3 profiles

The MCP surface is 7 tools: knomit_learn (write facts in one commit), knomit_query (paginated snippet search), knomit_explain (walk versioned provenance), knomit_update (revise in place; refs append), knomit_retract (commit a removal), knomit_review (work-stealing prune/distill/reflect), knomit_hypothesize (generate hypothesis facts; user-initiated). They are mounted at POST /api/v1/repos/{repo}/branches/{branch}/mcp?profile={code|chat|generic}. There are exactly 3 MCP server instances (one per profile) shared across all repos; handlers resolve repo+branch from request context. The profile changes ONLY the instructions sent to the calling model (the same 7 tools register in every profile): code = technical knowledge (bridge default), chat = conversational, generic = any domain. Per-session instructions are computed from the repo's ontology via an AfterInitialize hook. Clients usually reach this via knomit-bridge (stdio).
