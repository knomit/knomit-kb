# mcp.storeIndices(ri) extracts all 5 sub-indices via single WithRead into mcpStore struct

mcp/helpers.go defines mcpStore struct + storeIndices(ri *repos.RepoInstance) mcpStore. Extracts all FIVE store sub-indices (facts, search, toolSession, pipeline, branches) under a SINGLE ri.WithRead(svc) callback. Each handler calls storeIndices once at the top of its closure, then references only the fields it needs (e.g. query uses .search, learn uses .facts + .search, explain uses .facts + .search + .toolSession). If svc == nil inside WithRead, the struct returns zero-valued fields — caller's nil checks on individual fields tell them what's available. This is the MCP-side equivalent of synthesize/store-indices-extract-once: single lock, all snapshot from same svc, SwapStore-safe. Anti-pattern: calling ri.WithRead inside a handler helper — do it once at the boundary and pass mcpStore (or specific fields) down.
