# args.go provides unmarshalArg[T any] for structured args via JSON round-trip

mcp/args.go provides unmarshalArg[T any](req mcpgo.CallToolRequest, key string, target *T) error — a generic helper for structured args. It calls req.GetArguments(), looks up the key, JSON-round-trips through json.Marshal + json.Unmarshal into target. Returns user-friendly errors suitable for mcpgo.NewToolResultError(err.Error()): missing key → '<key> is required'; marshal failure → 'invalid <key>: <err>'; unmarshal failure → 'invalid <key> format: <err>'. Used by handlers that take structured args (learn for the facts array; potentially future handlers with complex inputs). The round-trip costs CPU but is the simplest way to convert map[string]any from mcp-go into a typed struct without reflection. Anti-pattern: hand-rolling type assertions on the map[string]any — brittle and produces poor error messages.
