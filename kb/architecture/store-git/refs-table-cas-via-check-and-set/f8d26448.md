# Refs table uses INSERT OR REPLACE for SetReference; CheckAndSetReference is the CAS primitive

Storer.CheckAndSetReference(new, old) is the CAS primitive for atomic ref updates. Behaviour: if old != nil, read current ref by old.Name(); if found and cur.Hash() != old.Hash() return storage.ErrReferenceHasChanged; otherwise call SetReference(new). Used by code paths that need to detect concurrent ref movement (push, sync merge-result writes). NOTE: the storer's refs table is shared across all branches/tags/HEAD via the name PK — SetReference(ref) is an INSERT OR REPLACE, so callers that want atomic-CAS semantics MUST use CheckAndSetReference. The is_symbolic int flag distinguishes hash refs from symbolic refs (e.g. HEAD pointing to refs/heads/main); target stores either a hex hash or a refs/heads/<name> string depending on the flag.
