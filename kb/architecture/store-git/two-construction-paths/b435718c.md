# NewStorer wraps existing DB (ownsDB=false); NewMemoryStorer opens :memory: with Core schema only

Two construction paths for *Storer: (1) NewStorer(db *sql.DB) wraps an EXISTING DB — ownsDB=false, the caller (typically store.Service.Open) manages the database lifecycle including migrate.All for the full schema. (2) NewMemoryStorer() opens :memory: SQLite, applies storemigrate.Core(db) (FOUNDATIONAL schema only — objects + refs + kv + branches + commit_log + branch_commits, NO vec0/GraphQLite/facts/pipeline/tool), and ownsDB=true. Close() is no-op for non-owned DBs; closes the in-memory DB for owned ones. NewMemoryStorer is used by tests that need a real Storer without the full search-index stack. Anti-pattern: calling Close on a NewStorer-wrapped DB — the upper layer's *sql.DB would be closed under it, leading to use-after-close in store.Service.
