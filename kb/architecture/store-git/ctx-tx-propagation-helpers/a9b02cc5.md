# txctx.go provides WithTx/Conn/BeginTxIfNeeded — the shared ctx-tx propagation pattern

txctx.go defines the SHARED context-propagated tx pattern used by both the storer and store-level callers: ctxKeyTx is the private context key; CtxExecer (ExecContext + QueryContext + QueryRowContext) is the union interface satisfied by *sql.DB AND *sql.Tx. Helpers: WithTx(ctx, tx) stores the tx in ctx; TxFromContext(ctx) returns the stored tx or nil; Conn(ctx, db) returns tx-from-ctx if present else db (this is the read primitive used everywhere a method takes ctx + needs to do SQL); BeginTxIfNeeded(ctx, db) is the owner-determining helper — returns (newCtx, tx, ownTx, err): ownTx=false if ctx already has a tx, ownTx=true if a new tx was started; caller checks ownTx to decide whether to commit/rollback. WithoutTx(ctx) returns ctx with stored tx REMOVED — use after commit/rollback so callers don't accidentally re-use a closed tx. This is the single source of truth for the ctxKeyTx — the store package's conn() helper uses the same context key so a tx started by one layer is visible to the other.
