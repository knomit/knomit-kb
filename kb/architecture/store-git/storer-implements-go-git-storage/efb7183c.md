# *storegit.Storer implements go-git's full storage.Storer over a shared *sql.DB

*storegit.Storer implements go-git's full storage.Storer composite interface over a shared *sql.DB. Compile-time assertions in the package: EncodedObjectStorer (storer.go), ReferenceStorer (refs.go), ConfigStorer + IndexStorer + ShallowStorer + ModuleStorer (kv.go). Tables backing each: objects (hash+type composite PK, type as int, data BLOB), refs (name PK, target, is_symbolic int), kv (key PK, value BLOB). The storer is content-addressed at SQL level: 'INSERT OR IGNORE INTO objects (hash, type, size, data)' means identical content writes dedup naturally. AddAlternate returns 'alternates not supported' — knomit never delegates to other object stores. PackRefs is a no-op (refs are already in SQLite, nothing to pack into pack files). Anti-pattern: adding a new go-git interface assertion without backing tables — if go-git starts asking via the new interface, missing impl panics.
