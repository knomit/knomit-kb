# pki.InstallOptions.ExpectInstalledRoot and its root-replace branch have no production caller at PR #528's merge: every non-test caller passes InstallOptions{}, and ten pki tests pin the per-root CRL watermark through it

At merge e417fd76 of PR #528, a search of the non-test Go sources under internal, cmd and tools finds ExpectInstalledRoot only in internal/pki/install.go (the field, its doc, the check `installed.Fingerprint != opts.ExpectInstalledRoot`, and the helper comment); production callers pass pki.InstallOptions{} (the desktop's confirm-the-root install flow that used it is gone). The option and its root-replace branch (a different root installs only when the option equals the installed root) survive because about ten pki tests (install_test.go, the per-root CRL watermark A->B->A cases) are written through it; removing it means rewriting them. The PR #528 reviewer skipped the removal on that ground and recorded it as a PR8 candidate. CONSEQUENCE: do not read the option's presence as a live feature or as the place a root change is confirmed (a root replace in production is blocked by the join's own pre-flights: trust_installed refuses). This fact reads false once the option is removed or a production caller adopts it.
