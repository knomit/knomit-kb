# Two embedded ontology presets (default, code); lazy sync.Once parse; OntologyByPreset selects

internal/fact/ embeds TWO ontology presets via //go:embed: ontology_default.yaml (id 'general', general-purpose) and ontology_code.yaml (id 'source-code', source-code knowledge with topics invariants/architecture/conventions/decisions/gotchas/incidents/meta). Each is parsed lazily via sync.Once (defaultOntology / codeOntology package vars) — the parsing PANICS on failure to guard against shipping a broken yaml file (release would never start). DefaultOntology() returns the general preset; CodeOntology() returns the code preset; OntologyByPreset(name) selects by name ('default' or 'code') and errors on unknown. Added via the `knomit init --ontology-preset <name>` flag (Apr 2026). Adding a new preset: add the .yaml file under internal/fact/, add a //go:embed var + sync.Once accessor, add a case to OntologyByPreset.
