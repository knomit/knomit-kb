# knomit leverages git to store a temporal, fact based, knowledge graph

knomit's mission is to become the long term memory for AI agents. knomit is meant to be a continuously evolving knowledge storage system where the information is stored as facts, facts that have an epistemic or pragmatic type, confidence, can have multiple domains and entities, and can refer to each other. knomit uses git to:
- store the facts in a temporal graph: git history gives the changes
- as a proof system: who changed what, when and why (commits are signed)
- as a decentralized, distributed system: each agent has its own branch, and consus is stored in main
- as a way to accept both machine as well as human authored facts: facts stored in markdown
