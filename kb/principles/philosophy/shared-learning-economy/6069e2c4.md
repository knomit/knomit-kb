# Learning effort is shared across peers, not re-paid by each

Learning is expensive — it costs an agent tokens, time, and reasoning to derive a fact. That cost should be paid once across the whole swarm, not once per agent. What one peer learns, others inherit by fetching and merging its branch, rather than independently re-deriving the same knowledge. Deduplication is therefore not only intra-branch — it is the economic point of being distributed.

Why: a fleet of agents that each re-learn the same truths in isolation is just N disconnected notebooks. The value of the distributed, machine-branch model is compounding: every merge into consensus makes the next agent's recall cheaper, because the answer is already there. Consensus is how the swarm converts redundant individual effort into shared capital.

What NOT to do:
- Design an agent loop that re-derives knowledge already present in consensus without checking first
- Treat each agent's branch as a private silo that never merges back
- Optimize a single agent's learning in isolation while ignoring whether the swarm already knows it
