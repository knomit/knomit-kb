# Git history is the timeline of belief

Knomit treats git history as a first-class temporal axis, not as
implementation detail. Each commit is a moment of belief: the state
of the fact graph as it was understood by some agent at that instant.
The full `git log --follow` of a fact file IS its epistemic history —
how the claim evolved, when confidence shifted, when sources were added,
when domains broadened.

Why: this is the foundation for "what was known, when, by whom, and on
what evidence" — the question knomit exists to answer. Without it,
the system would degrade to a current-state KB indistinguishable from
a wiki with timestamps.

What NOT to do:
- Treat git as a backup store rather than the primary temporal model
