# A fresh git worktree fails about 26 internal/repos Mission and SampleRecipe tests until git submodule update --init checks out third_party/knomit-playbooks

These tests read `.knomit/templates/mission/...` from the `third_party/knomit-playbooks` submodule, and a new worktree does not check out submodules. Without it they fail with "knomit-playbooks checkout ... is missing or empty", which reads like a regression in the diff.

Run `git submodule update --init` in the worktree, alongside the `dist/` and `web/node_modules` symlinks, before claiming the Go suite green. WHAT THIS DOES NOT MEAN: the failures are not flaky and not caused by the change under test.
