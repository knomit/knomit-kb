# internal/repos must NOT import internal/app (app imports repos → cycle); repo creation inlines store init

internal/app/app.go imports knomit/internal/repos, so internal/repos can NOT import internal/app — that would be an import cycle. This is why Manager.Create (lifecycle.go) inlines the on-disk repo init (os.MkdirAll + store.Open + svc.InitRepo for preset/custom, svc.InitFromRemote for clone) instead of calling app.InitRepoOnDiskBytes. The exported app.InitRepoOnDiskBytes / app.ResolveAgentBranch helpers (refactored out of app.InitRepo) exist for the CLI (knomit init) path only; do not try to reuse them from internal/repos. Manager.Create uses m.deps.AgentBranch (already resolved at Manager construction) rather than re-deriving the agent branch from the key fingerprint.
