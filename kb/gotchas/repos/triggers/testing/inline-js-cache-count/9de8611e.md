# TestTriggers_InlineJSCacheBySource fails under -count>1 because the inline-JS compile cache in internal/domain/fact is process-global (pre-existing, still open)

Found by the PR #632 reviewer (L2); NOT introduced by 14c and NOT fixed there; still open after the merge ee850fd6. The inline-JS compile cache in internal/domain/fact is process-global, so a second iteration finds the changed js already compiled and the assertion 'a changed js compiles once' fails (4 of 5 iterations at -count=5). It reproduces at 37dc65d5 (before 14c) with -count=3. CONSEQUENCE: do not read a -count>1 failure of this test as a regression from a trigger change; run it with -count=1, or clear the cache between iterations in a fix. The test is in internal/corpus/repos/triggers_inline_test.go.
