# A Go certificate's parsed URIs have already been through url.Parse, which LOWERCASES the scheme, and crypto/x509 ACCEPTS a port in a URI SAN's authority — so a strict SAN check must read the raw DER and refuse ports itself

Two behaviours of crypto/x509 (measured on go1.26.6) that make an intuitive strict-SAN check silently weaker than it reads.

ONE: `x509.Certificate.URIs` is NOT what the certificate says. The parser (parser.go ~line 420) runs every uniformResourceIdentifier through `url.Parse`, and url.Parse lowercases the scheme. `KNOMIT://instance/h-<fp8>` and `Knomit://…` both arrive as `knomit://…`, so a case-exact check written against `leaf.URIs` cannot see them. `internal/pki` reads the SAN extension (2.5.29.17) as raw DER with cryptobyte instead (`rawURIs`), counts every URI whose scheme is knomit IN ANY CASE (so two spellings cannot both slip past a first-wins pick), and requires the exact lowercase `knomit://` prefix.

TWO: a port is NOT refused upstream. The parser only calls `domainNameValid(uri.Host, false)`, and it accepted `instance:443` and `instance:`. Without knomit's own `strings.Contains(u.Host, ":")` check such a SAN reached the role lookup, and the refusal read 'unknown role "instance:443"' instead of a malformed-SAN refusal. An earlier reviewer note said x509's domain validation would stop ports; measurement showed it does not.

CONSEQUENCE: when a check relies on 'Go already validated this', pin that belief with a test that fails if Go's behaviour changes, or do the check yourself. `TestVerifyInstanceChain_SANShapeIsStrict` does the latter: 19 malformed spellings (case, userinfo, port, query, fragment, escapes, multi-segment, two URIs, opaque form, bad fp8) each assert ErrSANMissing, and every guard in parseSAN was sabotaged individually and shown to turn its case red.

FIXTURE TRAP found on the way: a test that uppercases the fp8 to get a negative case is only negative when the fp8 contains a hex LETTER. An all-digit fp8 (about 1 key in 43) uppercases to itself, so the case is valid and the test fails intermittently. The fixture now draws keys until the fp8 has a letter.
