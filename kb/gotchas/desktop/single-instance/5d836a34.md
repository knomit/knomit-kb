# singleinstance.Acquire ignores any server.json with schema >= 2, because `knomit serve` now writes one into the file the desktop used as its lock — without the exemption a desktop beside a live `knomit serve` on the default home would say "already running"

THE COUPLING: the desktop takes its single-instance lock by reading the pid in the server.json at config.LockfilePath() and refusing to start if that pid is alive (tools/desktop/internal/singleinstance). Since knomit#493 (merge 9860c726) every `knomit serve` writes a schema-2 server.json for its own home - on the default home that is the SAME file. Without a rule, a live serve's pid would read as another tray.

THE RULE: Acquire returns nil for a file with Schema >= 2 (a server, not a tray). Before #493 serve wrote nothing there, so Acquire passed; the exemption restores exactly that. It does not weaken the lock against another desktop: the desktop's own write is v1-shaped (no `schema`), so a second desktop still blocks on the first's live pid. A schema-2 file can replace the first desktop's only if a serve wrote it, and a serve writes only when it holds its home's socket, which the running desktop holds (and since #488 a desktop that cannot bind its socket fails its boot).

PRE-EXISTING GAP, NOT WORSENED: Acquire is check-only and the desktop writes its record after app.New, so two desktops launched inside that window both pass.

THE LOCK KEY CHANGED WITH IT: tools/desktop/app.go now passes config.LockfilePath() (resolves through KNOMIT_HOME), so on a non-default home the lock is per home and a second desktop can start beside the first; the default home is byte-for-byte unchanged. See the corrected kb/gotchas/desktop/rebuilding-kills-the-running-server.

REMOVAL: PR 5 of the desktop series moves the lock to a desktop-only lock file, and this exemption goes with it. Until then, any new writer of schema >= 2 into this file inherits the exemption, and any change that makes a desktop write schema 2 would silently disable the single-instance check.

PIN: TestAcquire_LiveServerFileIsNotAnotherDesktop (sabotage: removing the exemption turned it red).
