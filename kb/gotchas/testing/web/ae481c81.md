# When the web motif handlers moved to real stores, four mutations that stub tests used to catch became equivalent: no test against any real vocab.MotifIndex can distinguish them

W0e (PR #611) rewrote the motif handler tests onto real stores. Review sabotage showed four mutations that the old stub tests caught now stay GREEN, because they cannot be observed against any real vocab.MotifIndex: (1) renderMotifCollection sorting in place instead of on a copy: ClustersUnder returns a fresh slice on every call and nothing reads the slice after rendering. (2) the cluster detail writing DF into df_total: the detail reads unscoped, so DFTotal equals DF always. (3) authored_mints wired from Clusters instead of Mints: VocabularyHealthUnder mints exactly once per cluster, so the two always agree. (4) carriers queried at the stem tier instead of exact while every member spelling is passed: stem matches exactly the spellings that share a stored or computed cluster key, which are the members, so exact reaches the same set; a 'plural spelling outside the cluster' decoy is impossible on a real vocabulary.

What IS still observable: whether EVERY member spelling is passed (rather than only the first). It needs a spelling written AFTER the last alias rebuild: such a spelling is a member through the computed key, but at the exact tier it resolves only to itself.

DOES NOT MEAN that the copy, the df_total field or the exact tier can be removed from the code. They are defensive and part of the published contract; they just cannot be pinned by a web test. A reviewer must not demand a test for them, and must not treat a GREEN sabotage run of these four as a hole in the suite.

BOUNDARY (W0f, PR #612): the equivalence above is a property of vocab.MotifIndex, not of real stores in general. A topic-listing sort or a per-mount branch choice looks equally GREEN after a real-store port but IS observable once the fixture separates it (unsorted first-seen order, a second pinned branch with a decoy); see kb/conventions/testing/web/99f75ede.md. Try that fixture shaping before declaring a surviving mutant equivalent.
