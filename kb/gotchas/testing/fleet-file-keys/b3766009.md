# Moving a function between fleet files changes the keys of the archtest installCallers/installCRLCallers lists and the repos TestFleetRecordWriters_* / TestFleetStateWriters_* guards, and they go red with the new file's name; fleet_texts_test globs fleet*.go and needs no edit

At 786b0ce7 (PR #609) these guards are keyed by FILE name: test/archtest/install_callers_test.go lists the production files allowed to call pki.InstallBundle (fleet_create.go, fleet_join.go), pki.InstallCRL (fleet_revoke.go, fleet_tick.go) and the leaf installer; internal/corpus/repos/fleet_state_callers_test.go allows eight files and compares an exact per-call `file:function` string; the TestFleetRecordWriters_* guards likewise name files. Consequence: moving a function between fleet files (as 15a did when it split fleet_membership.go) turns the matching guard RED, and the failure names the new file, so the repair is to edit the key, never to loosen the guard. The failure is loud, not silent.

The exception is internal/corpus/repos/fleet_texts_test.go (TestFleetTexts_NameNoRESTRoutes), which globs fleet*.go: a new fleet file is covered without an edit.

DOES NOT MEAN: that the file-keyed guards also pin FUNCTIONS. installCRLCallers pins files only; any function in a listed file may call.
