# The storytests contract cells are behind `//go:build contract` — `go test ./...` NEVER runs them, and CI does

Five files in `test/storytests/` open with `//go:build contract`: `contract_auth_resolution_test.go`, `contract_token_expiry_test.go`, `contract_clone_test.go`, `contract_repoint_test.go`, `contract_wrong_main_test.go`. They are NOT compiled by a plain `go test ./...` — and `go test ./test/storytests/ -run TestContract_...` answers `[no tests to run]`, which reads like the test does not exist rather than like it was excluded.

CI runs them in a separate step (`.github/workflows/tests.yml`): `CGO_ENABLED=1 go test -tags contract ./test/storytests/ -count=1 -timeout 300s`. There is a second tagged suite too: `go test -tags desktop ./tools/desktop/...`.

**The consequence to act on: a green `go test ./...` is NOT a green suite.** During PR #65 every development and review command omitted the tag across ~30 commits, eleven per-task reviews and a whole-branch review. All of them reported the suite green while a contract cell was red, and the failure only appeared in CI. The cell was guarding the exact invariant that PR's central change touched (auth resolution must never silently downgrade to anonymous), and the branch had genuinely broken it.

**Before claiming a change is verified, run all three:**

    go test ./... -count=1
    go test -tags contract ./test/storytests/ -count=1 -timeout 300s
    go test -tags desktop ./tools/desktop/...

In a git worktree the cgo tests additionally need `dist/` — the native libs are gitignored, so symlink the main checkout's (`ln -sfn <main-checkout>/dist dist`) or the link step fails on `libtokenizers` and you will mistake it for a code error.

This is the same failure shape as the local-origin-gate gotcha, where storytests were silently dead because `LocalOriginRoot` was unset: a test suite that is invisible locally and live in CI. There the gate was config; here it is a build tag. When a test's absence is plausible, verify it is running rather than inferring from a pass.
