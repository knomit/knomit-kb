# The e2e harness cannot seed a remote knomit instance's published main (HTTP writes land on its agent branch; git push needs an enrolled instance cert), so origin-connect apply/commit coverage lives in Go tests over a bare-repo remote, including remote_wins

The e2e harness cannot seed a remote knomit instance's published `main`: facts written through the remote's HTTP API land on its agent branch, there is no merge endpoint, and a git push needs an enrolled instance certificate. The origin-connect /test step counts facts on the remote's main, so an e2e spec that needs a seeded remote cannot work. The two specs that tried ('migrate local facts...' and 'remote_wins strategy...', behind SEED_SKIP) were permanently skipped and were DELETED under knomit#485; e2e/tests/journeys/remote-migration.spec.ts now keeps only the 'cancel mid-workflow' spec, which needs no seeded remote.

Where the coverage lives instead: Go tests under internal/edge/web that drive the real wizard (create session, /test, /apply, /commit) against a bare-repo remote built with seedKnomitRemoteForTest / seedKnomitRemoteFilesForTest (file:// origin under the manager's LocalOriginRoot). TestConnect_ConflictStrategyReachesTheReplay runs it once per conflict_strategy and reads results back through GET /facts: remote_wins leaves the REMOTE body on a shared path, local_wins the LOCAL body, and the local-only and remote-only facts survive in both. After /commit it also asserts the session 404s and GET /origin reports the remote URL and branch. Before it, every wizard test applied local_wins, so nothing noticed /apply ignoring the request's strategy.

Consequence: do not add e2e specs that need a seeded remote main without first building bare-repo seeding for the e2e remote (via KNOMIT_LOCAL_ORIGIN_ROOT) or an operator push (#434). Add wizard cases to the Go tests instead.

WHAT THIS DOES NOT MEAN: a green e2e run is still silent on apply/commit and conflict strategies, which are covered only by the Go tests; and the missing e2e seeding is a harness limitation, not a product limitation.
