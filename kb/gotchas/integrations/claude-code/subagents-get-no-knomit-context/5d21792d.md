# Subagents receive NONE of knomit's guidance — 0 of 998 briefs carry the CLAUDE.md block — and capture 18x less per edit than the main thread; the gap is missing context, not ignored instructions

Measured 2026-08-15 across the full local Claude Code transcript history: 568 session files and 998 subagent transcripts under `~/.claude/projects/*/`.

**The capture gap.**

| | edits | knomit writes | writes per edit |
|---|---|---|---|
| main thread | 3,879 | 644 | 0.166 |
| subagents | 4,111 | 38 | **0.009** |

Subagents perform MORE edits than the main thread and capture **18x less per edit**. Of 302 subagents that did real work (>= 3 edits), **5 (2%) recorded anything**. They are also knowledge-STARVED, not merely capture-poor: 137 knomit reads across 998 subagents, and 27 subagents read the corpus without ever writing to it.

**The cause — they never get told.** Of 998 subagent briefs (first user turn):

- **2 (0%)** contain the CLAUDE.md block `## Working with knomit memory`
- **0 (0%)** contain "knomit as long-term memory"
- **12 (1%)** name any `/knomit-*` command
- **832 (83%)** mention "knomit" ONLY because the project directory is named knomit

That 83% path artifact is the trap: a naive grep for "knomit" in briefs reports 95% coverage and suggests the guidance is reaching subagents and being ignored. It is not reaching them. **Subagents get no CLAUDE.md knomit block, no SessionStart injection, no principles, no invariants, no area TOC.**

**Consequence to act on.** This is a correctness problem before it is a capture problem: a subagent editing code under an invariant it has never read can violate it silently. The main thread has both the CLAUDE.md block and the SessionStart block and captures at 0.166/edit; subagents have neither and capture at 0.009/edit. Context, not compliance, is the variable.

**The implementable lever.** `SubagentStart` is one of the twelve CC hook events that carry `hookSpecificOutput.additionalContext` (see the additional-context-union gotcha), and hooks demonstrably reach inside subagents — the bridge log shows 12,558 `post-edit` firings against roughly 7,990 recorded edits. Nothing currently fires at subagent start.

**This does NOT mean** injecting context is sufficient to make subagents capture — that remains a hypothesis. What it definitely fixes is subagents working blind against invariants. The baseline for a later before/after is precise: **5 of 302 working subagents (2%)**.

**Also do NOT conclude** the main thread is fine: 139 sessions did >= 5 edits and **62% of them captured nothing**. The subagent gap is the larger one, not the only one.
