# `git log --all --grep='^Knomit-Trace: <id>'` cannot be run against a knomit instance: its git objects live in SQLite (internal/store/git), so the trace is read on the ORIGIN or any clone after a push — the documentary test pushes to a bare repo with the store's own Remote().Push and greps there

TestScript_TraceReadableWithGitLog (internal/repos/triggers_script_test.go): `svc.ConfigureRemote(fileuri.New(bare), "main", agentBranch)` then `svc.Remote().Push(ctx, agentBranch, nil)` (go-git's file transport needs the `git` binary; the test skips without it), then `git -C bare log --all --grep='^Knomit-Trace: <C0>$' --format=%H` lists exactly the story's script commits (the root C0 itself carries no trailer and is found by its own hash), and `--format=%(trailers:key=Knomit-Cause,valueonly)` shows git's own trailer parser reading the paragraph. No viewer or endpoint exists by design.
