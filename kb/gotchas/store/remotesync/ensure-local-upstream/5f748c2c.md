# OPEN, UNFIXED: EnsureLocalUpstream does not check ctx after LockBranch returns, so an Unmount that cancels it while it waits for the lock lets it go on to SetReference and then fail on the cancelled ctx, leaving refs/heads/<upstream> created without its branches row, commit_log or notify

STATUS: OPEN and UNFIXED at 8a96c89b (PR #586 deliberately left it out of scope). Re-read at 8a96c89b.

WHAT THE CODE DOES. remotesync.Index.EnsureLocalUpstream (internal/store/remotesync/local_reconcile.go) calls rh.vr.LockBranch(upstream) (no ctx parameter; the wait cannot be abandoned), then runs without any ctx.Err() check: the existence check, DeriveBeforeAdvance (which runs under context.WithoutCancel, so a cancel does not stop it), SetReference of refs/heads/<upstream>, then EnsureBranch(ctx) and PopulateCommitLog(ctx), which issue SQL under the caller's ctx, then NotifyCommit (also WithoutCancel). Since #586 the caller is the Sync life's goroutine (internal/repos/stages.go), so an Unmount cancels that ctx while the goroutine may still be parked on the lock behind an index Rebuild.

CONSEQUENCE (derived from the code above, not reproduced). After the lock is finally granted with a cancelled ctx and the local upstream missing, SetReference succeeds and EnsureBranch / PopulateCommitLog then fail on the cancelled ctx: the function returns an error with refs/heads/<upstream> already created but its branches row, commit_log and commit notification not done. Whether a later open or the reconcile loop repairs that state was NOT verified; a later EnsureLocalUpstream would see the ref and return (false, nil) without repairing it.

SCOPE. Needs a missing local upstream (the case the bootstrap exists for) AND the Rebuild holding the lock AND an Unmount landing in that window; the lock holder is the index job, which an Unmount cancels first, so the window is short. It is a candidate bug to triage, not a known production failure.

WHAT THIS DOES NOT MEAN. #586's fix (moving the call off the driver) did not introduce it and does not worsen it; and the absent lock-free pre-check was a separate, deliberate decision.
