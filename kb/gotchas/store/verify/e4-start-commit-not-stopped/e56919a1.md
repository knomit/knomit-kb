# checkOwnLineage judged origin's agent TIP even when that tip was already reachable from origin's main (walkHistory never checked stop for its start commit) — fixed in #442: a start in the stop set is visited by nobody

A defect in the E4 design described by kb/decisions/store/verify/first-contact/dbecb0e6 ('every commit beyond origin's main'). internal/store/verify_walk.go walkHistory(start, stop, visit) pushes the start commit unconditionally and consults `stop` only when descending to parents. checkOwnLineage (verify_e4.go) calls it with start = origin's agent-branch tip and stop = everything reachable from origin's main. When the agent tip is itself in main's history (a forge fast-forward merge of agent/<host> into main, the agent branch left in place), the tip is still visited and judged; if it is not own-signed or accepted — e.g. a clone's own init commit, unsigned by design — InitFromRemote fails with 'origin's agent/... holds 1 commit(s) not signed by this instance, beyond origin's main', which is false ('beyond' does not hold).

Observed 2026-10-03 while fixing TestRemote_PushWithConcurrentRemoteUpdate on the lifecycle-machine branch: after MergeIntoMain left main == agent/test == the unsigned init commit, B's clone still refused. The test now deletes the merged branch instead. FIXED in PR #442 (merged as 3291e2f8): walkHistory now returns without visiting anything when stop[start] is true, so an agent tip that is reachable from origin's main (the init commit above, or a forge web-merge commit GPG-signed by the forge that the instance's sync fast-forwarded onto) is adopted whoever signed it. E4 still refuses a commit genuinely beyond main that is not own-signed, accepted, or vouched. Every other walkHistory caller with a non-empty stop set (CheckRange, onlyMergeCommits, PushedBranches, E4's transitive-trust walk) already guarded stop[start] itself, so the change alters only checkOwnLineage's behaviour. Regression: TestE4_TipAlreadyOnUpstream and TestWalkHistory_StartInStop.

WHERE THIS LIVES NOW (verified at the PR C merge ba59d2b2): walkHistory is vcs.WalkHistory in internal/engine/store/internal/vcs/history_walk.go and still begins with `if stop[start] { return nil }`; checkOwnLineage is verify.CheckOwnLineage in internal/engine/store/verify/e4.go, called from remotesync.InitFromRemote in internal/engine/store/remotesync/bootstrap.go. The regression tests TestE4_TipAlreadyOnUpstream and TestWalkHistory_StartInStop are in internal/engine/store/verify_e4_upstream_test.go. The text above uses the names at #442.
