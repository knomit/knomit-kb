# Known residuals of the origin-switch design (#544): old-origin commits ride along to the new origin, A to B to A or an unmerged respelling counts as a switch, the first round after upgrade is never a switch, a failed identity write repeats the switch once, same-origin rewind windows are unchanged

READ BEFORE SAYING 'a switch is lossless and safe everywhere'. Residuals of PR #544 (read at merge 8a01d3ca; review 5 verdict APPROVE, all accepted by the 2026-10-18 ruling):
(1) OLD-ORIGIN COMMITS RIDE ALONG. On a switch the branch keeps and pushes everything: foreign commits and an old fleet master's writes go to the new origin unchanged, inside this copy's branch, not re-signed (review 5 probe E1: an own consumed commit, a foreign commit, an unsigned own write, an experiment merge with a body resolution and a member's merged commit all reached the new origin as the original commits). A fleet's new host may refuse some of them (#528 N1 class); nothing in #544 filters or pauses.
(2) A to B to A, OR A RESPELLING THE NORMALISER DOES NOT MERGE, counts as a switch. A commit the origin removed in between returns once, via the merge.
(3) FIRST ROUND AFTER UPGRADE. A repository with no recorded identity is not a switch; if its URL changed before that round, the pre-#544 behaviour (rewind) applies once. The identity is recorded after that round.
(4) IDENTITY-WRITE FAILURE WINDOW. The identity is recorded by one statement after a successful switch round. If that write fails (a failed SQLite write), the next round is a 'switch' again; if that same origin scrubbed in between, the scrub is not applied that once.
(5) SAME-ORIGIN WINDOWS UNCHANGED. The same-origin rewind keeps its pre-existing failure windows (cd3a2bbf, 5482c3ab); #544 touches none of that code.
(6) A switch to an origin whose history is unrelated keeps the pre-existing rules (issue #541).

MISREADING. None of these is a data-loss path of the switch itself; (1) and (2) are about content reaching or returning to an origin, (3) and (4) about a rewind or a missed scrub happening once.
