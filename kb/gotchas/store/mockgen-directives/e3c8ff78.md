# The BatchEmbedder mockgen //go:generate directives live on the interface in internal/store/model/embedder.go, and `go run go.uber.org/mock/mockgen` fails in this module on a missing go.sum entry for golang.org/x/tools

At 32414d74 the BatchEmbedder interface is declared in internal/store/model/embedder.go, and its two //go:generate mockgen lines are there too (lines 47-48): destination ../mock_batch_embedder_test.go (package store) and ../../mcp/mock_batch_embedder_test.go (package mcp), source package knomit/internal/store/model. They used to sit in internal/store/interfaces.go and named knomit/internal/store, which no longer declares BatchEmbedder; E7a deleted interfaces.go (internal/store/interface_guards.go too), so there is no store file to look in. CONSEQUENCE: change the directive where the interface is, and keep the source package argument equal to the interface's package.
