# A Go file named *_js_test.go (or *_<goos>_test.go / *_<goarch>_test.go) is build-constrained by its NAME: `go test` silently reports "no tests to run" for it on every other platform

Go treats a filename suffix matching a GOOS or GOARCH (`_js`, `_wasm`, `_linux`, `_windows`, `_arm64`, …) before `.go` or `_test.go` as an implicit build constraint. A test file for a feature called "js" named `triggers_js_test.go` is therefore compiled only for GOOS=js: on darwin, linux and windows its tests do not exist, `go test -run TestX` prints "ok … [no tests to run]" and CI is green while running nothing. Hit in F08 PR A while adding inline `js:` trigger tests; renamed to `triggers_inline_test.go`. Consequence: when a new test file's `-run` reports "no tests to run", check the filename suffix before the regex; name feature files so no `_`-separated trailing segment is a GOOS/GOARCH value.
