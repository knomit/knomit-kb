# mattn/go-sqlite3 vtab support requires the sqlite_vtable build tag

Virtual-table support in github.com/mattn/go-sqlite3 is gated behind the 'sqlite_vtable' (or 'vtable') build tag. Without the tag, (*SQLiteConn).CreateModule does not exist and the package compiles to a stub. Every 'go build' / 'go test' for this repo must include '-tags sqlite_vtable' — the Makefile + CI defaults are updated to do so. Failure mode if you forget: tests against the vtab fail with 'no such module' at query time while everything else passes — a confusing, silent failure of vtab registration.
