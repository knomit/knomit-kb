# On Windows errors.Is(err, syscall.ECONNRESET) is FALSE for a real connection reset: the socket error is syscall.Errno(10054) WSAECONNRESET (and 10053 WSAECONNABORTED), while syscall.ECONNRESET is an invented Errno (536870935) — match WSAECONNRESET/WSAECONNABORTED by value in a _windows.go file

MEASURED (go1.26.8 windows/amd64): a peer's RST surfaces as *net.OpError{Op:"read", Err:*os.SyscallError{Syscall:"wsarecv", Err: syscall.Errno(10054)}} (WSAECONNRESET, "An existing connection was forcibly closed by the remote host") or Errno(10053) (WSAECONNABORTED, "An established connection was aborted by the software in your host machine"). `errors.Is(syscall.Errno(10054), syscall.ECONNRESET)` and `errors.Is(syscall.Errno(10053), syscall.ECONNABORTED)` are both FALSE: on Windows syscall.ECONNRESET is one of Go's invented Errno values (uintptr 536870935, APPLICATION_ERROR range) and Errno.Is compares only the oserror sentinels.

CONSEQUENCE. Code that detects a reset portably with errors.Is(err, syscall.ECONNRESET) silently never fires on Windows (e.g. internal/engine/llm/resilience.go uses that form; its Windows behaviour was not checked here). Match by value: `var en syscall.Errno; errors.As(err, &en) && (en == syscall.WSAECONNRESET || en == syscall.WSAECONNABORTED)`, in a //go:build windows file (syscall.WSAECONNRESET exists only on Windows). knomit's pki.isConnReset does exactly this (conn_reset_windows.go), with a false stub elsewhere.

MISREADING. Not "errors.Is never works for syscall errors on Windows": the oserror sentinels (os.ErrNotExist, os.ErrPermission, ...) do map. Only the POSIX-named network Errnos are the trap.
