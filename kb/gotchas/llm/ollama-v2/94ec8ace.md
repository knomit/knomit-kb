# Ollama API fields the Ollama adapter depends on and the Ollama version each was checked at: truncate, shift and tool_call_id from v0.30.0, prompt_eval_cached_count from v0.35.0 (llama.cpp b11963 at v0.40.14)

Claims about Ollama in the Ollama adapter facts are pinned to these checks of ollama/ollama api/types.go and the server source. ChatRequest.Truncate (json truncate): present at v0.30.0, v0.35.0 and v0.40.14; unset or true means the server drops the oldest messages to fit num_ctx. Message.ToolCallID (json tool_call_id) and ToolCall.ID (json id): present at v0.30.0, v0.35.0 and v0.40.14; the server assigns 'call_<8 chars>' ids to calls it parses (server/routes.go, v0.40.14). Metrics.PromptEvalCachedCount (json prompt_eval_cached_count, a pointer): ABSENT at v0.30.0, present at v0.35.0, v0.40.0 and v0.40.14; from there prompt_eval_count is cache_n + prompt_n, the whole prompt (llm/llama_server.go). Tool arguments that are not valid JSON fail the request server-side (llm/llama_server.go, v0.40.14). With truncate:false the prompt-over-context 400 a real Ollama v0.40.14 sends is NOT its own promptTooLongMessage ('the prompt is longer than the context length currently available to the model', reachable only with truncate:true) but the text of the llama.cpp it vendors, b11963: 'request (N tokens) exceeds the available context size (M tokens), try increasing it' (tools/server/server-context.cpp:4080-4086, HTTP 400 from server-common.cpp:125-128; the version is the claim, line numbers are dated support). ChatRequest.Shift (json shift, top-level): present at v0.30.0, v0.35.0 and v0.40.14 (api/types.go ChatRequest, L181, L166, L172); unset means context shift on for every model except deepseek2 (server/sched.go resolveContextShift); the adapter sends false. The oldest version checked for each field is the lowest tag named here; v0.30.0 was the oldest tag read, so 'present at v0.30.0' does not say when it first appeared. Consequence: when behaviour on a different Ollama matters, re-read these fields at that tag; do not extend a claim to an untested version. The adapter handles a server without prompt_eval_cached_count by an estimate flagged per field (Usage.EstimatedFields). Does NOT mean the pre-v0.35.0 behaviour of prompt_eval_count was observed: it is the documented older meaning, not re-measured.
