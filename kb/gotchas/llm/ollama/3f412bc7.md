# Ollama's documented default context depends on VRAM (under 24 GiB 4k, 24-48 GiB 32k, 48 GiB or more 256k); this is version-unpinned background, not a rule knomit relies on

Per Ollama's published docs (https://docs.ollama.com/context-length, fetched 2026-11-05 by the design author; URL not re-fetched by the PR 1 worker), with no num_ctx and no OLLAMA_CONTEXT_LENGTH the server's default context depends on VRAM: under 24 GiB it is 4k, 24-48 GiB 32k, 48 GiB or more 256k. The docs are current, NOT pinned to v0.40.14, so the tiers are unverified against that version's source. Background only: knomit sends num_ctx on every request, so these tiers never decide a knomit chat's window. /api/ps showing context_length 32768 on a machine means a request loaded the model that way, not that 32768 is the server default. Does NOT mean knomit reads or relies on these tiers.
