# The Ollama adapter used to drop thinking that arrived after the first content or tool-call line

Before commit 82ec20ba, OllamaChat.Stream flushed its reasoning block once, at the first content or tool-call line (guarded by a reasoned flag). Thinking that streamed in after that flush was appended to the thinking buffer and never emitted: it reached neither the response blocks, the EventReasoning sink, nor the KNOMIT_LLM_TRACE file. Test TestOllamaChat_ReasoningAfterFirstFlushIsKept (thinking, content, thinking, tool_call, thinking) is the regression anchor. Consequence before the fix: any reasoning written after the first content line was absent from the trace and from replay history. Since 82ec20ba the runs are built in stream order and this no longer happens. Do not reintroduce a single flush point.
