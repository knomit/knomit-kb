# llama-server context shift is ON by default in Ollama and silently discards KV while generating, still ending done_reason 'stop'; knomit sends shift:false so an overrun ends 'length' (ErrTruncated)

Ollama v0.40.14 (vendoring llama.cpp b11963) launches llama-server with --context-shift unless the request sends shift:false or the model is deepseek2 (server/sched.go resolveContextShift, llm/llama_server.go; ChatRequest.Shift, json shift, top-level not under options, api/types.go). When prompt plus output reaches num_ctx WHILE GENERATING, llama-server discards half of the tokens after n_keep from the KV cache (Ollama sends num_keep = 4 by default), so the system prompt tail and oldest turns vanish mid-response and the response STILL ends done_reason 'stop'. Nothing signals the cut. Only the response being generated is affected; the stored history is intact and the next request resends everything. knomit therefore sends shift:false on every request (user decision, 2026-11-04): llama-server then stops with STOP_TYPE_LIMIT, Ollama reports done_reason 'length', and the adapter returns a *StopError that Is ErrTruncated with the partial response (tools/server/server-context.cpp, llama.cpp b11963; line numbers are dated support, the version is the claim). Trade-off: shift is a runner launch attribute, so another client of the same shared Ollama that sends a different shift value forces a model reload each time the two alternate; accepted. Misreading to avoid: shift:false does NOT stop prompt-too-long 400s. A prompt with n_tokens >= n_ctx is refused at slot start with 'request (N tokens) exceeds the available context size (M tokens), try increasing it' whether shift is on or off, and that is ErrContextFull, a different error from ErrTruncated. Consequence: PR4 must still reserve output room (num_ctx covers input plus output) so a normal reply does not hit 'length'. Tested by TestOllamaChat_ShiftFalseOverrunIsErrTruncated (request body carries shift:false; done_reason length gives a StopError that Is ErrTruncated). Not verified live.
