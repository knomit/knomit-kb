# Connect at 375px still has two layout defects after PR #530: with the repositories rail open the Connect form shrinks to about 69px, and the top bar tabs clip

As of PR #530 (4bdcf031), observed in a browser pass at 375px width, not covered by any test and not fixed by that PR. (1) With the repositories rail open, the Connect form column is squeezed to about 69px wide: the stacked-grid fix (.k-connect-grid below 640px) acts on the viewport width, not on the space left after the rail, so a narrow viewport plus an open rail is still unusable. (2) The top bar tabs clip at 375px. CONSEQUENCE: do not read 'Connect works at phone width' as covering the rail-open case or the top bar; a fix for the first likely needs a container-based breakpoint rather than the viewport media query. Verify in a real browser before relying on this (jsdom cannot show it); retract when fixed.
