# jobEventsKeepalive is a package var private to api/jobs, so web cannot shorten it; TestJobs_EventsKeepaliveOnAnIdleStream moved into api/jobs/keepalive_test.go with its own small router harness and must not run in parallel, while the other job contract tests stay in web and decode through a test-side jobEnvelope copy

Verified at 97ae7c19 (PR #627). jobEventsKeepalive (`var jobEventsKeepalive = 30 * time.Second`, handlers.go) is now private to package jobs. A test in package web can no longer shorten it, so the idle-stream keepalive test moved: TestJobs_EventsKeepaliveOnAnIdleStream is in internal/edge/web/api/jobs/keepalive_test.go. It sets the var to 20 ms and restores it with t.Cleanup, and its comment states that tests in that package must not run in parallel.

HARNESS: because the test no longer runs through web's Server, keepalive_test.go carries a small testRouter (the repo lookup and httpx.BranchMiddleware around jobs.Mount at /repos/{repo}/branches/{branch}, no auth edge) and a local streamRecorder (a locked recorder with SetWriteDeadline and Flush). It is a deliberate copy of the part of web's shared SSE test double that it needs; web's sse_recorder_test.go is not importable.

WHAT STAYED IN WEB: the job contract tests (handlers_jobs_test.go, handlers_jobs_hub_test.go, handlers_jobs_rebuild_index_test.go) still run through the full router. They decode the job body into jobEnvelope, a test-side copy of the wire shape declared in handlers_jobs_hub_test.go, because the real jobEnvelope is unexported in api/jobs.

CONSEQUENCE: a change to the job body in api/jobs/handlers.go does not fail the web tests at compile time; the copy must be edited by hand and the contract tests will fail at decode or comparison instead. A new test that needs to shorten the keepalive must live in api/jobs.

DOES NOT MEAN: that the keepalive behaviour changed. Handler behaviour, the 30 s interval and the keepalive frame are as in kb/gotchas/web/sse/4a1d419d.md.
