# Server.BearerVerifier and BearerMiddleware take the concrete *oauth.Verifier, and the removed gitHTTPProvider 500 branch was unreachable because every *store.Service has Handler()

W0b (PR #600, merged fa631358; re-read there): Server.BearerVerifier is *oauth.Verifier (the old BearerVerifier interface had one production implementation; the only setter is internal/app/app.go, and oauth.NewVerifier never returns nil, so the == nil check in oauth_router.go behaves as before). GitRemoteHandler calls svc.Handler() directly: the removed 'git serving not supported' 500 branch of gitHTTPProvider was unreachable because ri.Acquire() returns a *store.Service and (*Service).Handler() exists on every one (a typed-nil *Service passed the old assertion too). CONSEQUENCE: do not re-add a 'does the store serve git' check in the handler; there is no such state to detect. DOES NOT MEAN git serving cannot fail: it fails inside the handler like any HTTP handler.
