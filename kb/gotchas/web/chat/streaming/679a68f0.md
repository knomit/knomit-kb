# The streaming caret is an mdast node appended inside the last paragraph (remarkCaret in chatTableBars), not a sibling span after the markdown block

ReactMarkdown renders block elements, so a span placed after it lands on its own line. chatLivePlugins (used only for the block a running turn is still streaming into) adds a remark plugin that appends a node with data.hName='span' to the last paragraph or heading, descending through list, listItem and blockquote; only a trailing table or code block gets a paragraph of its own. The caret keeps data-testid chat-caret. The activity-line time is the group's WALL time (wallDurationMs), from started_ms/ended_ms on each tool call; see the tool-call timestamps fact.
