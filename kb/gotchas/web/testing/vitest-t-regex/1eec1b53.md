# vitest's -t filter is a REGEX: a test name containing parentheses (or other regex metacharacters) silently matches nothing and the run passes green

Found in PR #528's sabotage runs: a sabotage run of FleetWizard used `-t "... (local false) ..."`; the parentheses are a regex group, no test matched, vitest reported success, and the mutation looked GREEN-proof when nothing had run (the re-run with a plain substring went RED, as it should). CONSEQUENCE: when a sabotage or targeted run is green, check that at least one test actually ran (the count line) and use filters without regex metacharacters, or escape them. MISREADING: a green targeted vitest run proves nothing until the number of tests run is nonzero.
