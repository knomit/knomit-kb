# A mechanism that defunds itself on bad outcomes CANNOT recover if being defunded also stops it producing outcomes — "a resolution restores it" is unreachable by construction

The restatement shortlist is funded by its own judge verdicts: enough pairs judged with none resolved defunds the corpus. The naive design says "a later resolution refunds it" — but a defunded corpus emits no pairs, so it generates no verdicts, so no resolution can ever occur. The recovery path is not merely unlikely; it is unreachable by construction. The mechanism is a LATCH, not a governor.

**The fix shape, in two parts.** (1) A bounded probe path: a defunded corpus still spends one pair every Nth session (`throttleProbeInterval`, counter in `restatement_throttle_state`), so feedback keeps arriving at a known price. (2) The probe slot must be consumed only when it ACTUALLY PRODUCED EVIDENCE. `probeAllowed` advances the waiting counter but the caller consumes it only if a pair was really emitted — a probe that found nothing to offer has bought no information, and charging it an interval re-introduces the latch at a slower rate.

**Generalises.** Any kill-switch keyed on its own results has this shape. The vocabulary kill switch in the motif work is the same design. When you write "X turns back on when Y happens", check whether being off is what prevents Y.

**The named misreading.** "There is a recovery path, so it cannot latch" — the existence of a recovery CONDITION is not the existence of a recovery PATH. Ask what generates the evidence the condition reads, and whether the off-state still generates it.
