# Every subagent of one Claude Code session shares ONE Playwright MCP browser, ONE knomit MCP connection and ONE SCRATCHPAD directory: an agent once clicked Leave in another agent's tab, and once ran another agent's same-named script against that agent's worktree

WHAT (seen during PR #531). All subagents spawned by one Claude Code session use that session's MCP servers, so they share (1) ONE knomit MCP connection: knomit_experiment open moves every agent of the session onto that experiment, which is why only one agent writes experiments at a time (kb/decisions/experiments/concurrency/0829b72e.md, kb/meta/methodology/multi-agent/knomit-binding/b8a4802a.md); and (2) ONE Playwright MCP browser with one set of tabs and one selected tab. An agent once clicked Leave in a tab that another agent had switched to its own rig, and so left the fleet on the wrong instance.

CONSEQUENCES. One experiment writer at a time, named in every brief. An agent never acts through the shared MCP browser tab: it drives its own Playwright script with its own browser context (its own launched browser and profile), so a click can only land in a page that script opened. Reading a page through the shared browser is safe; clicking, typing and navigating are not, because the selected tab is shared mutable state another agent can change between the agent's snapshot and its click.

DOES NOT MEAN: that subagents cannot use a browser or knomit at all. Separate Claude Code sessions have separate connections and browsers and are not affected.

SCRATCHPAD (seen 2026-10-17, after PR #531). Subagents of one session also share the session's SCRATCHPAD directory. An agent once ran another agent's same-named script, found in the shared scratchpad, and it acted on that other agent's worktree instead of its own. CONSEQUENCES: each agent works only inside its OWN scratchpad subfolder (named for it in the brief), puts every script, log and probe there, and never runs a script it did not write in this run, even when the name matches the one it meant to create: write the script fresh in its own folder, then run that. Briefs name the subfolder. DOES NOT MEAN: that agents must not read each other's reports; reading a file is safe, executing it is not, and a script's working directory and target must be passed explicitly rather than inherited.
