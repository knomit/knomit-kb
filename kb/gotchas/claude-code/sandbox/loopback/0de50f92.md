# claude sandbox blocks looknomitck by default; allowedDomains can't express localhost — set sandbox.network.allowLocalBinding

When claude's OS sandbox is enabled with a network allowlist, connections to localhost/127.0.0.1 are blocked by default. `allowedDomains` only accepts domain names (with `*.` wildcards) — NOT `host:port` and not a bare `localhost`, so you cannot allowlist a looknomitck service through it. The dedicated switch is `sandbox.network.allowLocalBinding: true`.

This is required for any local MCP server reached over looknomitck — e.g. the knomit-bridge stdio MCP, which connects to the knomit server on 127.0.0.1:19278. Verified against claude 2.1.150: with `allowLocalBinding:true` a sandboxed process reaches the live server (HTTP 200) while a non-allowlisted external domain is still blocked (403). tools/drone exposes this as `--allow-local` (default true), emitting the key under sandbox.network.
