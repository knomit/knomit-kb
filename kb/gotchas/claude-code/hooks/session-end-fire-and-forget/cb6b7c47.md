# CC SessionEnd hook is fire-and-forget — cannot inject context

Claude Code's SessionEnd hook has its exit code ignored and its output discarded. Context injection via hookSpecificOutput.additionalContext does NOT work from SessionEnd. This is why the knomit-CC memory design (Shape B) drops SessionEnd entirely; its intended 'session digest' role is partially covered by the rate-limited Stop hook instead. If you find yourself reaching for SessionEnd to push context into the next conversation, that path is blocked — use Stop or PreCompact, or write the digest as a fact via a /knomit-* skill before the session ends.
