# Code written with no compiler fails first on FIXTURES, not on logic — and those failures read as "the feature is broken", while a hand-audit catches only what the compiler would have caught anyway

knomit PR 2 (~1300 lines) was written under a box embargo with no build, vet or test available. On the first run: `go build` and `go vet` BOTH passed first try, and the tests did not. That split is the lesson — the compiler was not what was going to fail.

FOUR DEFECTS, and the two expensive ones were fixtures:

1. Every end-to-end test invented its own `Mcp-Session-Id`. mcp-go VALIDATES session ids and answers `Invalid session ID` with a 404 before any handler runs, so nine tests failed for a reason unrelated to their subject. The second round showed the same thing per MOUNT: a URL-scoped endpoint is still its own MCP connection and needs its own initialize handshake.
2. A semicolon inside a SQL COMMENT in a new control migration. The idempotency guard splits the file on `;` before stripping comments, so the prose read as a statement break — a trap documented in an existing migration's header that had been read during the same session.
3. A test hardcoding the control chain's version number, which a new migration moves.
4. A new `{param}` subtree unclassified in paramClass, which fails by design rather than defaulting.

WHAT THE HAND-AUDIT WAS WORTH. Before the box freed, the whole diff was audited by hand for unused imports, unused locals, arity mismatches, struct fields and signatures. It caught NONE of the four, because those are what the compiler checks and the compiler passed. It DID catch two things a compiler never would — test paths addressed at `/api/v1/...` against a router the real server mounts UNDER that prefix (every call would have 404'd), and a new route missing from openapi.yaml.

THE PRACTICAL RULE: when a toolchain is unavailable, spend the audit on the SEAMS BETWEEN a component and its harness — route prefixes, session handshakes, fixture preconditions, generated-file registries — not on what `go build` would tell you in two seconds once it is available. And expect the first run to be noisy in a way that looks like a broken feature and is not.
