# Short-string embeddings (tags, motifs, slugs) are anisotropic and model-dependent — center them, and re-validate on any model swap

Embedding short strings (2-4 word tags, path slugs, motif names) behaves very differently from embedding documents, in two measured ways. (1) Anisotropy: raw vectors sit in a narrow high-similarity band; subtracting the vocabulary mean and re-normalising brings mean off-diagonal similarity to ~0 and is REQUIRED before any threshold is meaningful. (2) Model dependence: on nomic-v1.5 a semantically true pair (ai-adoption ~ ai-coding-agents, 0.771) and a false pair (operations ~ business, 0.776) are indistinguishable — short-string similarity is unusable; on embeddinggemma the same pairs separate (0.677 vs 0.581). Even centered embeddinggemma stays blind to some same-mechanism pairs (single-copy-invariant ~ single-source-of-truth = 0.22).

Consequence: any feature matching short strings by embedding must (a) center over the string vocabulary, (b) treat thresholds as model-calibrated, and (c) be re-validated when the embedding model changes — porting a threshold across models by value is meaningless here.

**THE SHIPPED REMEDY (motif Phase 0, PR #99): the short-string title hack.** A bare short string is embedded through `Model.ShortStringTemplate`, which on embeddinggemma renders it as `title: {content} | text: none` — NEVER the query or document template. It LOOKS wrong (an empty text field) and it is RIGHT.

**The measurement that justifies it, and the reason it is worth trusting.** The research harness put knomit-kb's top title pair at cosine **0.784**; the shipped production path prints **0.783** — a transfer within 0.001. That happened BECAUSE the production rendering matched the one the research operating point was measured under. This is the concrete demonstration of (c) above: the transfer is a property of the RENDERING matching, not of the number being robust.

**Not swept on nomic.** The template is calibrated for embeddinggemma only. A model swap re-opens both the template choice and every threshold derived under it.

**The named misreading.** `title: {content} | text: none` is not a formatting detail to tidy up. It is part of the calibration — changing it silently invalidates every operating point measured through it, with no error and no test failure.
