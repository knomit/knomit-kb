# Before this instance has a certificate, a Fleet port held by ANOTHER program looks exactly like 'waiting' (no bind is attempted, reload exits 0, the wizard offers Host here); the create succeeds and then surfaces addr_in_use on the Members card (accepted in #545 under 8f04bc80)

WHAT (review finding F4, ACCEPTED at #545; behaviour read at merge commit 7ce30154 and observed on the real binary). `app.OpenTLSServer` checks `pki.HasInstanceCert` BEFORE it binds, so an instance with no certificate never learns whether its configured Fleet port is free. Reproduced: a program held 127.0.0.1:19879, `[tls].addr` was set to it and `knomit reload` run. It printed `tls: off (no_certificate), waits for ...` and exited 0; GET /fleet said `listener_reason: no_certificate`; the New fleet wizard showed no blocking card (Hosting: "not running yet ... the create starts it"; Review: "the create starts the fleet listener"). The create then SUCCEEDED, `StartTLSWhenInstalled` failed with addr_in_use (log: "mTLS listener not started after the certificate was installed"), and the Members page showed the #537 held-port card ("Members cannot join yet: ... its port is held by another program"). The recovery is therefore visible, after the create rather than before it.

WHY ACCEPTED, not fixed. The alternative was a probe (listen then close) in the no-certificate branch, an app change beside the narrow door of kb 7a1bd4ee. The user's ruling in kb 8f04bc80 (detect and surface; do not try to prevent every failure up front) applies: the failure is detected on the next step and shown with its way out. It is not new in kind: a port set at boot behaved the same at dev; #545 only extends it to the reload path, which is now the main one.

CONSEQUENCE. Do not read `no_certificate` + `listening: false` as "the port is free"; it means only that no bind was tried. Anything that must know the port is free before a create needs its own probe, which does not exist. The three #537 held-port strings apply only once a certificate exists (for example Host here on a member).

MISREADING. "The wizard guarantees the Fleet port is usable": it guarantees only that a port is configured.
