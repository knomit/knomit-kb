# A script-interrupt test runs the script under a 24 h budget and waits on a signal from a stub host call, so only cancellation can end it; a regression is red in about 60 s (hang detector plus Close's drain bound), and a short script budget must not be restored

TestScript_NoStoreHeldDuringScript used to sleep 300 ms until the script spun, then asserted the swap took under 1 s and the Serve restart under 500 ms. On Windows slow-tests the swap took 1.8 s and failed the 1 s bound. It now proves that cancellation interrupts the script, with no wall-clock bound:
- The script makes one host call, knomit.query({spinning: true}). The stub hook answers it without Acquire, so no lease is held, and signals a channel; then the script runs `while (true) {}`.
- ScriptBudget is 24 h, so the budget can never end the script. The swap and restartServe can complete only by interrupting it. The 30 s selects are hang detectors only.
- The swapped-in copy predates the fire's record, so the script fires again on the new Serve. The test waits for that second signal before restartServe, so the restart also meets a spinning script.

SABOTAGE (reviewer, against a commit): making runSandboxed interrupt only when the ctx error is DeadlineExceeded turns the test red in about 60 s: the 30 s hang detector fires, then Manager.Close gives up after its 30 s drain bound (the spinning goroutine then leaks for the rest of the package run). It does NOT hang until go test's timeout.

CONSEQUENCE: the 24 h budget cannot wedge CI, and a short script budget must NOT be restored to make a failure arrive sooner or to bound the test; that brings the wall-clock flake back.

WHAT THIS DOES NOT MEAN: not every script test should use a long budget. TestScript_TimeoutIsOutcome tests the budget itself; since #659 (merge 1aaaf983) it no longer carries latency bounds: it brackets the host ctx's deadline between two clock reads (kb/conventions/testing/timing/bracket-the-deadline/9d302850.md) and its host-time check is TestScript_HostTimeIsNotTheScripts on the dispatcher's test stopwatch (kb/conventions/testing/timing/stopwatch-for-ceilings/b06a0b62.md).
