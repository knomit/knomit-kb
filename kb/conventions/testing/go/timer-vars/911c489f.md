# To test an idle-interval behaviour without sleeping real seconds, make the interval an unexported package var and shorten it in the test with a t.Cleanup restore — jobEventsKeepalive is shortened to 20 ms in TestJobs_EventsKeepaliveOnAnIdleStream

jobEventsKeepalive (internal/edge/web/handlers_jobs.go) is an unexported package-level var, not a const, so the test can set it to 20 ms and restore it with t.Cleanup(func() { jobEventsKeepalive = old }). TestJobs_EventsKeepaliveOnAnIdleStream then opens a job stream for a running job, waits for a `: keepalive\n\n` frame, and asserts the body still holds only the initial running task frame. No real-seconds sleep, so the 30 s production interval costs the suite nothing.

CONSEQUENCE: when a new idle-interval behaviour needs a test, expose the interval as a var in the package that owns it and restore it in t.Cleanup.

WHAT THIS DOES NOT MEAN: the var is a test seam, not a runtime setting; production code never reassigns it. The save/restore mutates package state, so a test using this seam must not run under t.Parallel with another test that opens a job stream.
