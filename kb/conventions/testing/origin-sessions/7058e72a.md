# Origin-session expiry tests drive sessionManager.now and .interval (struct fields, not package vars), so they can run in parallel; expiry means idle for MORE than 10 minutes, and a Get resets the idle clock

S6 sets a fake clock on sm.now and sets sm.interval to an hour so the sweeper never ticks, then calls sm.runCleanup by hand. Because these are per-manager struct fields and not package variables, tests using them can run in parallel. Boundary: at exactly sessionExpiry (10m) idle the session SURVIVES; it is evicted only after more than 10m. A Get touches LastAccess, so it restarts the idle clock; a session whose use is held is skipped, and release restarts the clock (TestSessionManager_S6_InUseSessionIsNotIdle). Production leaves now = time.Now and interval = cleanupInterval (60 s). DOES NOT MEAN: that a test may change the package constant sessionExpiry; the test asserts it is 10m.
