# To test `knomit serve`'s whole RunE without ONNX or a model, swap the embedder through the `serveAppOptions` seam in cmd/serve.go (identity in production); to test only the config-failure path, make config.Load fail with KNOMIT_LLM_CACHE=notabool — envBoolOr fails before app.New is reached

cmd/serve.go's RunE calls config.Load first, then app.New, which builds the real ONNX embedder (at PR #286 serve did not pass Options.Embedder, the test seam PR #284 added; STALE since the serve TLS/supervised tests: serve now passes its options through `var serveAppOptions = func(o app.Options) app.Options { return o }` in cmd/serve.go, the identity in production, which a test replaces to inject a deterministic embedder). So any test that drives serve through RootCmd.Execute and gets as far as app.New needs the model and ORT. The way around it, used by cmd/root_test.go in PR #286: set KNOMIT_LLM_CACHE to a non-boolean (e.g. `notabool`) via t.Setenv; config.Load fails in envBoolOr (internal/config/config.go, around L463 / L707) and RunE returns before app.New. That is enough to assert on stderr shape (no usage block, no double print) and the returned error.

What it does NOT cover: anything after config.Load — listener binding, the crash marker, shutdown. PR #286 tests those by extracting helpers (listenTCP, serveInto, serveUntil) and driving them directly, plus a pre-bound port for listenTCP. If serve ever needs a full-boot test, the clean route is to thread Options.Embedder from a test-only hook into serve's app.New call, not to download the model.

CURRENT STATE (verified at 9860c726, knomit#493 post-merge): the closing sentence's 'clean route' exists. cmd/serve.go line `app.New(ctx, cfg, serveAppOptions(app.Options{LogTap: logTap}))` goes through serveAppOptions; TestServeTLS_BindConflictFailsTheBoot (cmd/serve_tls_bind_test.go) and the supervised matrix (cmd/serve_supervised_test.go) set it to inject an embedder and drive the WHOLE RunE, listener binding and shutdown included, and assert on the returned error (the #261 contract). So the KNOMIT_LLM_CACHE=notabool trick is now only the cheapest way to reach the config-failure branch, not 'the only embedder-free way through RunE'; anything after config.Load is tested through serveAppOptions. Restore the original in t.Cleanup, as those tests do.
