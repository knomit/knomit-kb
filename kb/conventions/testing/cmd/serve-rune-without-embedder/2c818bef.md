# To test `knomit serve`'s RunE error path without ONNX or a model, make config.Load fail: KNOMIT_LLM_CACHE=notabool fails in envBoolOr before app.New is reached — serve does not expose app.Options.Embedder, so this is the only embedder-free way through RunE

cmd/serve.go's RunE calls config.Load first, then app.New, which builds the real ONNX embedder (serve does not pass Options.Embedder, the test seam PR #284 added for internal/app's own tests). So any test that drives serve through RootCmd.Execute and gets as far as app.New needs the model and ORT. The way around it, used by cmd/root_test.go in PR #286: set KNOMIT_LLM_CACHE to a non-boolean (e.g. `notabool`) via t.Setenv; config.Load fails in envBoolOr (internal/config/config.go, around L463 / L707) and RunE returns before app.New. That is enough to assert on stderr shape (no usage block, no double print) and the returned error.

What it does NOT cover: anything after config.Load — listener binding, the crash marker, shutdown. PR #286 tests those by extracting helpers (listenTCP, serveInto, serveUntil) and driving them directly, plus a pre-bound port for listenTCP. If serve ever needs a full-boot test, the clean route is to thread Options.Embedder from a test-only hook into serve's app.New call, not to download the model.
