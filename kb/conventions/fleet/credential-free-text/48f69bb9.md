# Any error or log text that may quote a URL goes through credentialFreeText / credentialFreeErr: go's HTTP client redacts only a URL's password, not a token in its user slot, and every /fleet/follow error text is credential-free

Verified at the merge of PR #529 (60ddfb1c); a review finding (S2) confirmed by a live check: a follow with `https://LEAKTOK@host/...` returned a 502 detail and logged text containing the token, because go-git and the HTTP client quote the URL and the HTTP client redacts only the password, never a token in the user slot. RULE: FollowFleetHost returns every error through credentialFreeErr (it also rewrites a FleetError's Msg reached via errors.As), and the move's log lines go through credentialFreeText; any new fleet text that interpolates a URL uses credentialFree(url) (user, password and token stripped; scp-style git@host:path unchanged; a malformed URL loses its userinfo by regex). The host record, the bundle url line, GET /fleet URLs and refusal texts already follow it (kb/architecture/fleet/host-record/9c4e1732.md).

CONSEQUENCE: a new error path in the follow/move code needs no per-site stripping if it returns through FollowFleetHost, but a new LOG line that formats an error from go-git must call credentialFreeText itself.

Probe wording: probeFleetForge answers 'the forge could not be reached: ...' or 'the forge refused the credential: ...' (forgeProbeError). It is still errors.Is(ErrOriginUnreachable) (502 unreachable) but no longer carries 'origin was not attached': a follow's probe runs before anything is attached, and on a credential change the origin stays attached all along. The same words for the pki classification path (an unreachable URL reaching ResolveOrigin) are still 'origin was not attached: pki: ...' (known, minor).

MISREADING: 'Go strips credentials from URLs in errors': only the password.

TESTS. TestFleetFollow_ErrorTextsAreCredentialFree (unreachable, publish_refused, the move's publish warning), TestCredentialFreeText, TestFleetREST_FollowAnswersNoUserinfo, and the probe wording assertions in TestFleetFollow_TheMasterChangesOnlyItsCredential.
