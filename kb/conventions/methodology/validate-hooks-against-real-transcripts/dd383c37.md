# Validate any prompt- or phrase-matching integration against the local Claude Code transcript corpus BEFORE building it — it is free, and it has now killed two designs that looked sound on invented examples

`~/.claude/projects/*/*.jsonl` holds every local Claude Code session, and `**/agent-*.jsonl` holds every subagent transcript. For this project that is 568 sessions, 1,291 genuinely typed human prompts, and 998 subagent transcripts. Scanning it costs nothing — no API calls, no subscription usage — and it answers "would this ever fire on real input?" directly.

**Two designs it has killed:**

1. The original `user-prompt-submit` hook, deleted in `dd5f32ba` (2026-05) after field testing: "fire frequently but almost never emit — across 35 fires in a typical session: 0 substantive emits… regex demanded stereotyped design-intent phrases; real prompts never matched."
2. Its 2026-08 replacement, killed BEFORE being written. Matchers derived from a 24-prompt eval set ("remember that X", "record that Y") scored **1 hit across 1,291 real typed prompts (0.08%)**, and that one hit was a session remark, not durable knowledge. The user does not phrase requests that way; the median real prompt is 77 characters and reads like "continue with the PRs".

**The rule.** A matcher validated only against examples its author invented is measuring the author's imagination. Extract the real corpus and score against it first.

**Two extraction traps, both hit in practice:**

- **Slash-command and skill bodies look like user turns.** They inflate the corpus (263 of 1,554 here) and produce phantom matches — the first run "fired" 38 times, almost entirely on injected `/code-review` and `/knomit-remember` bodies. Filter turns beginning `Base directory for this skill:` and known command text. `tool_result` turns are also role=user and must be dropped.
- **The project name poisons keyword counts.** Grepping subagent briefs for "knomit" reported 95% coverage; 83% of those matched only a file path containing the project directory name. Test for distinctive guidance text (`## Working with knomit memory`), never the bare product name.

**This does NOT mean** the corpus answers behavioural questions. It says whether a matcher fires on real input, not whether the model does anything useful when it does — that still needs a live run. Use it to eliminate designs cheaply, not to validate them.
