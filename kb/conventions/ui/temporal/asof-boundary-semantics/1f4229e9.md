# asOf is preserved entering 'history' but demoted to 'live' entering tree/chrono

Cross-view boundary rule for state.asOf: when crossing INTO 'history' view, asOf is preserved (including the diff mode — diff state survives navigating between facts). When crossing INTO 'tree' or 'chrono', asOf is FORCED to {mode:'live'}. Rationale: tree and chrono are HEAD-only views by design (their list endpoints accept no commit parameter); allowing a non-live anchor to persist would create a 'pill says SCRUBBED but list is HEAD' inconsistency and 404 on fact-clicks. The fact view (when factPath set and mode==='diff') reads state.asOf directly, so diff is restored without re-typing when user navigates back to a fact in history. The existing crossingBoundary rule (clear non-path filters and free text on history↔non-history) is preserved alongside this.
