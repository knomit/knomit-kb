# Amber/warning styling is reserved for things that actually FAIL — trade-offs get plain text, because if every consequence is amber nobody reads amber

# The rule

Warning styling (amber, ⚠, bold "permanently") is for conditions that block or break: an unreachable remote, an ontology that will not parse, a name already taken.

Trade-offs — choices that work fine but cost something — get PLAIN TEXT, stated once, in the user's terms.

# Where this came from

A draft of the create wizard described local-only creation as:

> "⚠ Attaching a remote later **replays every fact into a separate history** rather than merging — the two have no commits in common. Pointing at an empty remote now avoids that **permanently**."

Three alarming words for a consequence the user cannot evaluate and probably will not hit. The designer's correction: *"we're scaring users shitless — it's NOT that dire, it will just work anyway."*

The mechanism was accurately described; the volume was wrong. `store.Replay` carries every fact across, deduped by path, latest version of each. What does NOT follow is each fact's earlier revisions. That is one calm sentence, not a hazard sign.

The shipped copy:

> "You can connect a remote whenever you like, and all your facts come across. The only thing that doesn't follow is each fact's earlier revisions — starting from a remote keeps that full timeline."

# Corollary: no "recommended" badge on peer choices

When two options are genuine peers, a badge on one makes the other read as the wrong answer. Preference is carried by ORDERING and by describing the preferred option more fully — not by decoration.

# Corollary: never claim what the system cannot know

The same restraint applies to facts, not just tone. A pre-create summary must not display fact or commit counts, because a refs-only probe cannot know them; and "no branches were found" must not be shown for an auth-refused probe, whose empty branch list means REFUSED, not NONE.

# The general principle

If every consequence is painted amber, the reader stops reading amber — and then misses the one that mattered.
