# Confidence tiers for knomit CC skills: 1.0 / 0.95 / 0.85

Confidence values the knomit Claude Code skills write, per the embedded SKILL templates:

- **1.0** — `/knomit-principle` (designer intent; user-invoked only).
- **0.95** — `/knomit-decided`, and facts the user EXPLICITLY confirmed (incl. user-confirmed `/knomit-bootstrap` facts).
- **0.85** — `/knomit-remember`, and derived/inferred `/knomit-bootstrap` facts.

There is NO hook-driven auto-capture tier: hooks only NUDGE the model to call a skill; they never write facts. The earlier 0.6 'auto-capture' tier and the `/knomit-kickoff-area` command are gone (kickoff-area was renamed `/knomit-bootstrap`). `/knomit-update` adjusts confidence up/down as evidence corroborates or weakens a claim.
