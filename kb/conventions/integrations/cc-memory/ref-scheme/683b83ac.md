# Knomit ref scheme: src://<source>/<path>@<commit>, https://, file:///, or unschemed local fact path

Refs in knomit_learn calls follow four forms. (1) 'src://<source>/<path>[@<commit>]' for source files in a registered source repo, optionally git-anchored — e.g. src://knomit/internal/store/service.go@cfef409. (2) 'https://' or 'http://' for external URLs (PRs, docs). (3) 'file:///abs/path' for filesystem references outside any source repo. (4) No scheme = local fact path within this KB. The <source> slug comes from the bridge's required --source flag (one slug per session), so a single KB can hold facts about multiple source repos unambiguously. Never write bare paths like 'internal/store/service.go' — the resolver treats them as local fact paths and lookups will clash or fail.
