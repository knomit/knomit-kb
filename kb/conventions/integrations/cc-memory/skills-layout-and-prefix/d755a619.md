# knomit skills use 'knomit-' prefix and CC's per-skill-directory layout

All six skills in the knomit-CC integration are named with a 'knomit-' prefix (/knomit-recall, /knomit-remember, /knomit-why, /knomit-decided, /knomit-kickoff-area, /knomit-review) to avoid clashing with built-in Claude Code skills like /review. They live at .claude/skills/<name>/SKILL.md — CC requires the per-skill-directory layout, not flat .md files. This is project-scoped (lives in the project's .claude/skills/, not the user's ~/.claude/skills/) so contributors inherit the integration by checking out the repo.
