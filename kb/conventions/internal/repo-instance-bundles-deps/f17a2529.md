# Pass *repos.RepoInstance, NOT individual indices — RepoInstance bundles all repo deps

Operations that need multiple store indices (FactIndex, SearchIndex, PipelineIndex, BranchIndex, ToolSessionIndex) plus AgentBranch + Ontology + Embedder should take a SINGLE *repos.RepoInstance, not a long list of individual interfaces. Inside, extract what you need under ri.WithRead(func(svc *store.Service)). Example: synthesize.NewReviewer went from 7 params (gs, idx, reviewIdx, branches, agentBranch, embedder, onProgress) to 2 (ri, onProgress); callers in web/ collapsed from ~15 lines of index extraction to a one-liner. The RepoInstance.Embedder() accessor was added in this refactor to complete the dependency bundle. Anti-pattern to avoid: extracting indices in the caller and passing them as individual args — this leaks store internals into upstream code and breaks when SwapStore is called (the stale index references will read from the closed DB).
