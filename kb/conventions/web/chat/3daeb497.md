# A tool row's label is derived from the tool name, not looked up: knomit_<rest> reads 'knomit: Knomit <rest with spaces>', any other name is shown as it is

chatState.toolRowLabel(tool) strips a leading 'knomit_', replaces the remaining underscores with spaces and writes 'knomit: Knomit <rest>' (knomit_repos -> 'knomit: Knomit repos', knomit_materialize -> 'knomit: Knomit materialize'); a tool whose name does not start with 'knomit_' is shown as its own name. There is no table, so a new MCP tool needs no page change. A selectable (finished) row appends ' ▸'. The group of consecutive calls is headed 'Used Knomit'. Both the row and the result panel's title use the same function. Misreading to avoid: the label is wording for the person, never an identifier; code keys on the call id and the tool NAME (e.g. 'knomit_materialize' decides fact rendering), not on the label.
