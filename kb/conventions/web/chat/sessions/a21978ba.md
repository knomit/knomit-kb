# The Sessions marker rule: a session whose client name is 'knomit-chat' is drawn 'Chat · <provider> · <model>' (provider is the part of the client version before the FIRST slash); every other client stays 'name version'

A chat registers in client_sessions under its chat id with clientInfo name 'knomit-chat' and version '<provider>/<model>' (internal/edge/web/api/chat create: ClientName 'knomit-chat', ClientVersion provider + '/' + model). SessionsTable.clientLabel draws that row's Client cell as 'Chat · provider · model', splitting the version at the FIRST '/' only, because a model name may itself hold a slash (an Ollama 'library/o1' reads 'Chat · local · library/o1'). A version with no slash reads 'Chat · <version>'. Any other client, claude-code included, is unchanged ('name version'). Where it shows: the Activity facet's sessions table (the former Sessions tab), under the target the chat binds. The chat id is also the session log's filename stem, so the row's id and the log correlate.

Misreading to avoid: the match is on the client NAME constant, so a client that merely has 'chat' in its name is not marked.
