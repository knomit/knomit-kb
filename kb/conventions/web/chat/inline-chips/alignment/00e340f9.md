# Every chip a chat answer's markdown is swapped for (fact link, repo chip, commit link) carries .k-chat-chip and aligns ONLY through it: words as baseline, marks centred (.k-chat-chip-mark), vertical-align baseline, margin-block -2px on .k-prose.k-chat-answer .k-chat-chip; a kind's own rule never sets height, vertical-align, align-items or display

App.css defines one alignment for every inline chip in a chat answer (ChatFactChip.tsx: FactLink, RepoLink, CommitLink):
- .k-chat-chip: display inline-flex; align-items baseline (the chip's words are its baseline); vertical-align baseline (they sit on the line's own baseline); box-sizing border-box; nowrap.
- .k-chat-chip-mark on the non-text mark (a fact's type glyph, the span wrapping a repo's RepoDot): align-self center, so it is centred beside the words and takes no part in the baseline.
- .k-prose.k-chat-answer .k-chat-chip { margin-block: -2px }: takes the chip's border box (line + 2px borders: 21px fact, 20px repo) out of the line box's sum, so a line with a chip is exactly as tall as one without — in prose (14px/1.65 = 23px) AND in a table cell (12.5px/1.45 = 18px), where a 21px chip otherwise pushed the cell's words 2px below the row's other cells.
- Each kind's own rule (.k-fact-link, .k-repo-link, .k-commit-link) sets only its look and box, never its alignment: font (family, size, weight), colour, line-height, padding, margin-inline, gap, max-width (fact link), border, border-radius, background, cursor and text-align. None sets height, vertical-align, align-items, display or a block margin.

Measured in Chromium (2026-11-09, DPR 1 and 2): before, the repo chip (height 20px, vertical-align -3px, align-items center — the fact chip's pre-2026-11-08 fault) sat 5px below its neighbours' text centre and grew its line 3.4px in prose, 4.4px in a cell; fact chips pushed cell text 2px below the row. After: baseline offset 0, line growth 0, cell-vs-row offset 0 for all three kinds in p, li and td.

Consequence: a new inline chip in chat answers must take .k-chat-chip (+ .k-chat-chip-mark on any icon) and must not set its own height or vertical-align. What this does NOT mean: plain inline code (not swapped for a chip) is not a .k-chat-chip; it still grows a line by under 1px.
