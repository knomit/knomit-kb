# Web copy-to-clipboard control: a `<button type="button">` holding CopyIcon (#888, #7c9 for 1.5s after success) that calls navigator.clipboard.writeText(text).then(...).catch(() => {}); tests mock navigator.clipboard and assert the exact text written

Every copy-to-clipboard affordance in web/ follows one shape (instances at the merge of PR #515: settingsParts.tsx connect-panel buttons, FactBody.tsx source-ref row, ManageFleet.tsx AgentIdCopy):
- A `<button type="button">` (never a link or a div) containing `<CopyIcon size={13} color=... />` from ./icons. Colour is `#888` at rest and `#7c9` for 1.5 s after a successful copy (state flag reset by setTimeout 1500); title switches Copy/Copied; an icon-only button needs an aria-label (e.g. "Copy agent id") and a data-testid.
- The handler is `navigator.clipboard.writeText(text).then(() => { setCopied(true); setTimeout(() => setCopied(false), 1500); }).catch(() => {})`. The empty catch is deliberate: when the clipboard is unavailable (insecure context, denied permission) there is nothing to recover, and no error is surfaced.
- The text is copied exactly as the server provided it: no trim, reformat or quoting. The agent id is opaque (D18), so AgentIdCopy copies st.agent_id verbatim.
- Tests replace the clipboard with `Object.assign(navigator, { clipboard: { writeText: vi.fn().mockResolvedValue(undefined) } })`, click, and assert writeText was called exactly once WITH the exact string, using an id with spaces, slashes and colons so any trimming or encoding is caught. They also assert the control is a BUTTON containing an svg, and that its parent's text is exactly the displayed value.

OPERATIONAL CONSEQUENCE: reuse this shape for a new copy control rather than a new component or a different icon colour pair; copy a different string only on purpose.

WHAT THIS DOES NOT MEAN: the catch does not make a failed copy visible, so do not rely on the UI to tell a user the clipboard write failed.

UPDATE (PR #528, verified at merge e417fd76): ManageFleet.tsx and its AgentIdCopy are gone (the Fleet pages replaced them). The fleet's instance of this affordance is `CopyButton` in web/src/fleetParts.tsx (CopyIcon, green for 1.5 s after a success), used for the agent id, the fleet URL and the public key; the shape and the test rule (mock navigator.clipboard and assert the exact text written) are unchanged.
