# A link rendered from fact data must pass isHttpUrl (utils.ts): javascript: and data: URLs become plain text

Source entries in the materialize payload carry a url that comes from fact content. MaterializeView renders an anchor (target=_blank, rel='noopener noreferrer') only when isHttpUrl(url) in web/src/utils.ts is true (absolute http: or https: after URL parsing); otherwise the label renders as text. markdown.tsx has its own inline http(s) regexp for markdown links; this helper is the reusable form for any other href built from data. Does NOT cover hrefs in markdown bodies, which markdownComponents handles.
