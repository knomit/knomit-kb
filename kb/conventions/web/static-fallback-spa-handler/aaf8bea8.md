# Handler mount order: /git → /docs → /api/v1 → /assets/* → /* SPA fallback

Server.Handler() mounts paths in this strict order (chi matches in registration order): (1) /git — optional smart git HTTP if s.GitHandler != nil; (2) /docs — Swagger UI, registered for GET and HEAD on ONE compressed sub-router (`docsRoute := r.With(compressor())`) with ONE handler value, so the two verbs cannot diverge; it is NOT in the static group and carries no cache headers; (3) APIBase (= /api/v1) — the HAL API router mounted via r.Mount, which carries its own compressor(); (4) and (5) inside ONE r.Group that applies identityForRangeRequests then compressor(): `/assets/*` (assetsPrefix+"*") registered for GET and HEAD only via r.Method with one shared handler value (every other method → 405 with an empty body; before PR #225 r.Handle answered POST with the file), and `/*` via newSPAHandler(fsys, staticHandler, tags) registered with r.Get AND r.Head sharing one value, which serves index.html for any unmatched path so client-side routes survive a page refresh. Order matters: /api/v1/* and /assets/* must be matched BEFORE the catch-all /* or it intercepts everything. Anti-pattern: registering the SPA fallback before the API routes — every API call would return index.html.

**Method sets (since PR #225, dev 86ddf78d).** /docs, /assets/* and /* answer GET and HEAD and nothing else; POST/PUT/DELETE/PATCH/OPTIONS → 405, empty body. HEAD returns GET's exact headers (ETag, Cache-Control, Content-Type, Content-Encoding, Vary) with no body — via http.ServeContent's own HEAD handling on the static paths, and via net/http discarding the body for /docs (a recorder does NOT discard it, which is why TestHead_SendsNoBodyThroughARealServer uses httptest.NewServer). Known wart, not fixed: chi's backtracking into the /* catch-all collects allowed methods twice, so a 405 carries duplicated `Allow` lines (e.g. `GET, HEAD, GET, HEAD`); clients take the union; a deduplicating MethodNotAllowed handler would fix it globally.

**Shape since PR #223 (dev aa37eb35).** There is no `StaticHandler()` any more. The build-tagged files (`embed.go` / `embed_noembed.go`) expose only `embeddedStaticFS() fs.FS` (nil under `noembed`); the untagged `static.go` owns `staticHandlerFor(fsys)`, `newAssetHandler`, `newSPAHandler(fsys, static, *etagger)` and `serveIndex`, so both build variants share one code path and tests inject a `fstest.MapFS` through the unexported `Server.staticFS` seam. The static group sits in a Group, NOT on the outer router, so the API mount is not double-compressed. The SPA fallback serves index.html through `http.ServeContent` — never by re-dispatching a rewritten path to `http.FileServer`, which 301s any path ending in index.html to "./" (see kb/gotchas/web/spa/fileserver-index-redirect-loop/68987070.md). Cache policy, ETag and Range handling for this group are in kb/decisions/web/static/compress-and-cache/d98cfbc9.md.
