# store.ErrBranchNotFound sentinel maps to HTTP 404 via writeStoreError helper

When the requested branch has no matching git ref, store.resolveRef wraps plumbing.ErrReferenceNotFound into store.ErrBranchNotFound (preserving the original via fmt.Errorf %w chaining). Handlers in internal/web call writeStoreError(w, r, err, defaultTitle, branch) which uses errors.Is(err, store.ErrBranchNotFound) to detect the case and emits a problem+json 404 with stable title 'Branch not found'; any other store error falls through to 500 with the caller-supplied defaultTitle. CRITICAL design rule: the web layer stays INDEPENDENT of git internals — no handler imports go-git's plumbing package. Add new sentinels at the store boundary, never let plumbing errors bleed into handlers. Out of scope for branch-404: handlers_branches.go list (reads SQLite, not git), handlers_origin_hal.go (not branch-scoped), handlers_commit_anchored.go (commit-hash-anchored, different error surface), handlers_events.go (SSE, tolerates missing).
