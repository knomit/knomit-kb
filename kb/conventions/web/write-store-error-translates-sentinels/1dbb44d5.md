# writeStoreError is the universal store-error→HTTP-status translator; web stays independent of git

writeStoreError(w, r, err, defaultTitle, branch) in internal/web/errors.go is the universal store-error → HTTP-status translator. Maps: store.ErrBranchNotFound → 404 with title 'Branch not found' + detail `no branch named "<branch>"`; store.ErrFactNotLive → 404 with title 'Fact not found' + detail mentioning retract+commit-anchored fallback; ANY other error → 500 with caller-supplied defaultTitle and err.Error() as detail. ALL store errors in handlers go through this — NEVER call hal.WriteProblem directly with a store error. CRITICAL DESIGN RULE: the web layer is INDEPENDENT of git internals — no handler imports go-git's plumbing package. Add new sentinels at the store boundary (e.g. store.ErrXNotFound) rather than bleeding plumbing errors through. When adding a new sentinel: extend writeStoreError with the new case and pick a stable problem-title string.
