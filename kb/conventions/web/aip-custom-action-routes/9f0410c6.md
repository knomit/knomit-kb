# Custom HTTP actions use Google AIP style: POST /<collection>:<verb>

Collection-level admin actions use Google AIP 'custom action' style: POST /api/v1/repos:rescan. The colon is a literal path character in go-chi (only `{` and `*` are special), so it cannot collide with /api/v1/repos/{repo}. Repo names are validated against [a-z0-9_-]+ which excludes ':', so a repo can never shadow the route. Convention also enforced: all slices in HAL responses serialize as `[]`, NEVER null — handler coerces nil []string into []string{} before serialization for stable JSON shape. Per-resource failures during a multi-resource action don't escalate to 500: they're returned in the `errors` array with 200 status. Only catastrophic failure (directory glob fails, request body unparseable, etc.) becomes 5xx via hal.WriteProblem (problem+json).
