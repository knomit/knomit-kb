# Branch name→id lookups go through the vcs.Repo branch cache (BranchID / EnsureBranch); never query the branches table directly

Branch name→id lookups go through the branch cache of vcs.Repo (formerly repoHandler.cache; a *branchCache with sync.RWMutex + map[string]int64 in internal/engine/store/internal/vcs/branch.go). EnsureBranch and BranchID both consult the cache first, fall back to a SQL lookup on miss, then populate the cache. EnsureBranch is idempotent via 'INSERT OR IGNORE INTO branches(name, git_ref) VALUES (?, ?)' followed by SELECT id. BranchID returns model.ErrBranchNotFound when the branch is absent. DropBranch removes the entry via cache.remove(name). Anti-pattern: querying the branches table directly for ID lookup — always go through BranchID/EnsureBranch so the cache stays warm and consistent and ErrBranchNotFound wrapping is preserved for handlers.
