# Branch name→id lookups go through repoHandler.cache; never query branches table directly

Branch name→id lookups go through repoHandler.cache (a *branchCache with sync.RWMutex + map[string]int64 in branch.go). EnsureBranch and branchID both consult the cache first, fall back to a SQL lookup on miss, then populate the cache. EnsureBranch is idempotent via 'INSERT OR IGNORE INTO branches(name, git_ref) VALUES (?, ?)' followed by SELECT id. branchID returns ErrBranchNotFound when the branch is absent. DropBranch removes the entry via cache.remove(name). Anti-pattern: querying the branches table directly for ID lookup — always go through branchID/EnsureBranch so the cache stays warm and consistent and ErrBranchNotFound wrapping is preserved for handlers.
