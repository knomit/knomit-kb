# Service.dbPath is canonicalized via EvalSymlinks; required for vtab registry lookups

Service.dbPath is canonicalized via filepath.EvalSymlinks at Open time. Why: on macOS /var is a symlink to /private/var, and the vtab registry key MUST match what SQLite returns via PRAGMA database_list (which returns the resolved path). The canonical form is used for both bindVTabRepo(canonPath, rh) at Open and unbindVTabRepo(canonPath) at Close. canonicalizePath falls back to the original path if EvalSymlinks fails or path is `:memory:`. If a caller binds with one path form and the vtab cursor lookup uses another, the cursor errors with 'first_parent_chain: no repoHandler bound for db <path>'. Anti-pattern: storing the raw user-supplied path on Service and binding the vtab with it — use canonicalizePath() before bind/unbind.
