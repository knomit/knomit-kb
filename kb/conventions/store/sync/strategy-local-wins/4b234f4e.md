# Steady-state origin sync uses StrategyLocalWins for conflict resolution

reconcileAgentMerge (the merge-path reconcile) calls mergeIntoBranch with conflictStrategy = StrategyLocalWins — the agent's local edits win overlapping paths against main. This matches the design intent of the old replay-based reconcile and the single-machine writer invariant (this machine is the sole writer for agent/<host>). The rebase fallback (reconcileAgentRebase) uses the same strategy. If overlapping paths matter (rare in single-writer case), the agent author's intent is preserved over the consensus branch.
