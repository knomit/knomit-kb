# Conflict strategy is a PARAMETER chosen at the call site, never baked into the merge — steady-state origin sync picks StrategyLocalWins, and the experiment ops pick the other two in opposite directions

Steady-state origin sync passes conflictStrategy = StrategyLocalWins — the agent's local edits win overlapping paths against main. The choice is made at ONE call site: reconcileAgent(ctx, agentBranch, upstreamMain, StrategyLocalWins, mainRewound) in remote_sync.go. reconcileAgent dispatches to reconcileAgentMerge (mainRewound=false) or the rebase fallback reconcileAgentRebase (mainRewound=true); BOTH take the strategy as a PARAMETER and forward it (reconcileAgentMerge -> mergeIntoBranchLocked; rebase -> mergeTreesWithStrategy). This matches the single-machine writer invariant (this machine is the sole writer for agent/<host>), so overlapping paths are rare; when they occur the agent author's intent is preserved over the consensus branch.

THE FULL SET after PR #235 is three, and WHICH SIDE each name refers to is the thing to get right:

- StrategyLocalWins — dst wins conflicting paths. Steady-state origin sync.
- StrategyRemoteWins — SRC wins. Chosen by SyncExperiment, merging the parent INTO the experiment, because the parent is `src` on that direction. Reading the name as "the remote" rather than "src" is how a sync silently keeps the experiment's version of exactly the path it was run to resolve.
- StrategyRefuse — resolves nothing: collects every conflicting path and aborts with a typed *MergeConflictError before any ref is written. Chosen by CommitExperiment, merging the experiment into its parent, where picking either side silently would discard work nobody chose to discard. See conventions/store/merge/strategy-refuse for its two traps (the value must be non-empty, and it must be stricter than the other two on a dual-add).

WHAT THIS DOES NOT MEAN:
- No strategy is hardcoded inside reconcileAgentMerge/reconcileAgentRebase — both are parameterized (remote_reconcile_merge.go, remote_reconcile_rebase.go). To change the steady-state strategy, edit the reconcileAgent call site in remote_sync.go, NOT the reconcile functions.
- The merge helper is mergeIntoBranchLocked, not a bare 'mergeIntoBranch'.
- An EMPTY strategy is not a fourth option: mergeIntoBranchLocked rewrites it to StrategyLocalWins.
