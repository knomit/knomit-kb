# CreateBranch atomically clones git ref + branch_commits + branch_facts from parent

repoHandler.CreateBranch(branch, fromBranch) in branch.go clones THREE things from the parent atomically: (1) git ref via gits.SetReference to the parent's tip hash; (2) branch_commits visibility via 'INSERT OR IGNORE INTO branch_commits SELECT new_id, commit_hash FROM branch_commits WHERE branch_id = parent_id' — every commit visible on parent is now visible on child; (3) branch_facts per-path fact view via similar SELECT — every branch_facts row on parent becomes a row on child pointing at the same (fact_id, commit_hash). Also inherits the parent's sync watermark from meta.last_commit:<parent> if present, so the child's first im.Sync does an incremental diff from the same baseline rather than a wasteful full rebuild. Without the branch_facts clone, the child's tree at HEAD contains inherited files with no matching branch_facts row — Verify's facts-coherence check correctly flags the gap. No-op if the branch already exists (early return after gits.Reference check).
