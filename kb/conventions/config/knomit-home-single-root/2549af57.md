# KNOMIT_HOME is the SINGLE root for all knomit data; everything derives from it

KNOMIT_HOME env var / config field is the SINGLE root for ALL knomit data. Everything else derives: repos+DBs under $KNOMIT_HOME/repos/, SSH keypair at $KNOMIT_HOME/id_ed25519, ONNX model cache at $KNOMIT_HOME/models/, config file at $KNOMIT_HOME/knomit.toml (searched after exe-adjacent). Default: ~/.knomit (backward compatible). KNOMIT_REPO still works as override for the repos path SPECIFICALLY. Config.Home field layered like other fields: default → TOML → env. This is the ONE backend change that enabled e2e test isolation: tests start the binary with KNOMIT_HOME=/tmp/knomit-e2e-<run-id> and KNOMIT_PORT=0 for full isolation — no risk of touching the developer's home knomit data. Anti-pattern: do NOT hardcode subpaths under ~/.knomit/ in code — always resolve them via Config.Home.
