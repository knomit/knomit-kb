# NormalizePath lowercases everything after the root prefix; BuildFactPath uses 8-char uuid filename

NormalizePath(ontologyRoot, path) ensures the ontology root prefix + '.md' suffix AND lowercases EVERYTHING after the root to prevent case-sensitive duplicates (e.g. 'kb/AI/foo.md' and 'kb/ai/foo.md' would otherwise be two facts). BuildFactPath(ontologyRoot, topic, category) constructs '<root>/<topic>/<category>/<uuid8>.md' where uuid8 is the first 8 chars of uuid.New().String(). Topic and category are lowercased; trailing/leading slashes trimmed from category. The 8-char ID convention is shared with synthesize/normalize-fact-path-uuid — LLM-emitted paths flow through that helper for consistency. Anti-pattern: passing mixed-case paths to NewFact and skipping NormalizePath — NewFact lowercases the WHOLE path but doesn't add the .md suffix or root prefix, so you'd end up with paths missing the .md.
