# Methodology facts are identified by type='methodology', NOT by path

The kb/meta/reasoning/ path convention for methodology facts is a SOFT norm — not load-bearing for any retrieval or filter. The canonical marker is the schema-validated `type: methodology` field. Reasoning: paths can be renamed/moved; type is schema-enforced. Anyone writing code that 'gets methodology facts' must filter by type, never by path prefix. The three universal domain markers ('meta', 'reasoning', 'methodology') still get applied alongside inherited tags but they're markers, not replacements — a methodology with only meta/reasoning/methodology domains has ZERO useful tag signal (28% of current methodology facts are in this state — only retrievable via vector similarity).
