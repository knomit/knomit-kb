# SerializeFact emits 'kind' only when Pragmatic and 'evidence_weight' only when > 0

SerializeFact emits the 'kind' key ONLY when kind == Pragmatic — epistemic facts omit the field entirely. This preserves BYTE-IDENTICAL round-trip for the entire pre-pragmatic corpus (every existing fact file authored before the kind discriminator was added). Same omission applies to 'evidence_weight' which is emitted only when > 0 — facts that haven't been through synthesis (no computed weight yet) round-trip byte-identical to pre-evidence-weight files. Field emission order is FIXED: kind (if pragmatic) → type → domain → confidence → sources → evidence_weight (if > 0) → entities → refs. Anti-pattern: reordering field emission 'for readability' — breaks byte-identical round-trip and pollutes git diffs for facts that were unchanged but happened to be re-serialized.
