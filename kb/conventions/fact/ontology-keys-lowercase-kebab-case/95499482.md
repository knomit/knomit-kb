# Ontology topic and child keys MUST match lowercase kebab-case regex; enforced by ParseOntology

Ontology topic and child keys MUST match validKeyRe = '^[a-z0-9]+(-[a-z0-9]+)*$' (lowercase kebab-case). Validated by validateKeys during ParseOntology. Examples valid: 'technology', 'ai-governance', 'go-concurrency'. Invalid: 'Technology' (capital), 'ai/governance' (slash — slashes are path separators, not key chars), 'ai_governance' (underscore), 'ai governance' (space), '' (empty). The constraint is load-bearing because ontology paths are URL segments AND git paths AND SQL keys — kebab-case-lowercased gives a single canonical form across all three. Anti-pattern: relaxing to allow underscores or capitals — the lookup in ValidatePath lowercases before comparing, so non-lowercase keys would never match anyway, and underscores would conflict with the chosen path-segment delimiter.
