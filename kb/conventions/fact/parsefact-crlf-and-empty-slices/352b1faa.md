# ParseFact normalises CRLF→LF and coerces empty domain/entities/refs to []string{} not nil

ParseFact normalises CRLF→LF before parsing. File MUST start with '---\n' and have a closing '\n---\n' — neither has whitespace tolerance (would-be '--- \n' is rejected). After YAML decode, empty/missing domain, entities, refs are EXPLICITLY coerced to []string{} (NOT nil) — load-bearing for round-trip fidelity because nil and [] would serialize differently (omitempty vs []). extractTitle requires a '#' heading on the FIRST body line; missing/empty title is a parse error. Body after title-strip is strings.TrimSpace'd. Anti-pattern: relying on YAML's nil-list default elsewhere in code — coerce to empty at the boundary so callers don't need nil checks downstream.
