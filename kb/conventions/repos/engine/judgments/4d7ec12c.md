# Every engine judgment is ONE knomit.model call with a named closed schema whose `reasoning` property is sent FIRST and additionalProperties false; a thrown call is recorded as `failed:` in the chain and read as its safe default, never ending the run as an error

Judgments and their schemas (schemaOf in engine_reason.js): relevant {labels:[{fact, yes|no}]}, support {verdicts:[{fact, supports|contradicts|restates|unrelated}]}, choose_move and backtrack_choice {choice 0..n}, synthesize {claim, consequence, misreading, carriers}, assess {answers|partly|not, missing}, hypothesize {claim, settlement, observable}, seek {search}; each with reasoning (maxLength 1200) first. The script passes `name`, which the host sends as response_format.json_schema.name (validated [a-z0-9_]{1,64}), and marshalReasoningFirst writes the top-level properties with reasoning first — Go sorts map keys, which would make a schema-to-grammar server emit e.g. `claim` before the reasoning.

One verdict per fact (fix-later 3): judgeRelevance and judgeSupport keep the FIRST verdict a reply gives an index and ignore later ones; support state is keyed by path, so a fact can never count twice in the posterior or the answer's sources (TestEngineOracle_DuplicateVerdictsDeduped).

Failures (fix-later 6): judge() catches the host's throw (truncated, off-schema, unreachable, a recovered Go panic), records {judgment, verdict: 'failed: …'} and returns null: relevant → not relevant, support → unrelated, choose → the top-ranked entry, synthesize → no claim, assess → not, hypothesize → a harness-built one. A deadline/cancel error is rethrown so the run ends `interrupted`. Engine.RunWith also reports `interrupted` when the script returns after its ctx expired.

Misreading to avoid: E07 §3's grammar-after-reasoning-block (R3) is NOT done here; the reasoning field is a schema field, not the model's think segment.
