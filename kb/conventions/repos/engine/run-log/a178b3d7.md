# Every engine run logs through zerolog with reason_run=reason-<8 hex> on EVERY line: `reason start`, one `reason step` per host call (step, state, move, facts ≤5, facts_read, judgment, verdict, posterior, model_calls, elapsed_ms), `reason done`; refused or truncated calls are Warn; briefings and raw model replies are Debug

Engine.Run mints the run key (reason- + 8 lowercase hex) and logs `reason start` and `reason done` (outcome, answer_facts, experiment, posterior, model_calls, elapsed_ms; Warn when interrupted or error). The Go wrappers around query, explain, learn, incoming, experiment and model each write ONE `reason step` line; the script never logs: it passes a `log` object ({step, state, move, from, arg, judgment, posterior}) inside the call's options, which the host strips before the tool sees it (so the tools' unknown-argument refusal never fires on it). A failing host call is the same line at Warn with `error`. `reason model request` (the full request body as `briefing`) and `reason model reply` are Debug. The run key is also the Knomit-Trace trailer of every commit the run makes and, where the ontology declares it, the answer facts' context.reason_run.

Consequence: filter one run with grep reason_run=<id> or the Logs viewer; a new host function must go through stepLine or its calls vanish from the run's log. The log is a view, nothing reads it back; ReasonResult is complete without it.
