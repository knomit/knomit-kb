# ReviewHandler constructs a fresh synthesize.Reviewer per call; logProgress is the universal sink

ReviewHandler constructs a FRESH synthesize.NewReviewer(ri, logProgress) PER CALL — never caches a Reviewer between calls. This honors the Reviewer-is-stateless contract from the synthesize layer (see synthesize/per-call-objects-no-session-state): any per-session cache on Reviewer would lose state across calls because the MCP handler doesn't memoize. logProgress (defined in review.go) is the universal progress sink for synthesize.ProgressEvent emissions — 'warn' phases (e.g. validation rejections from ApplyDistillDecisions, normalize/validate failures) log at WARN; everything else at DEBUG to keep server logs usable during long review sessions. Same pattern applies to any future per-call orchestrator wrapper: construct fresh inside the handler, pass logProgress (or an equivalent sink) for the onProgress callback.
