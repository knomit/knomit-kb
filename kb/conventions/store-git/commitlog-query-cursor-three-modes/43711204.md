# CommitLogQuery has three cursor modes (Before/From/After); LIMIT+1 detects hasMore

CommitLogQuery(branchID, path, cursor, limit) uses a three-mode cursor: CommitLogCursorBefore (rows strictly AFTER the cursor's commit — newer than), CommitLogCursorFrom (rows AT or before the cursor — inclusive seek), CommitLogCursorAfter (rows strictly BEFORE the cursor — older than). Each mode looks up the cursor commit's anchor via two helpers: lookupTS(hash) for committed_at, lookupMaxRowid(hash) for the max rowid (tie-breaker when multiple paths share the same commit). Pagination uses LIMIT limit+1 to detect hasMore — return the first limit rows and set hasMore based on whether the extra row was fetched. branchID == 0 means NO branch filter (used in test/special paths via branchCommitsJoin returning empty join + tautology where). Commits with multiple commit_log rows (multi-file commit) are folded via GROUP BY commit_hash + MIN(message) + MIN(operation) + MAX(rowid) aggregates.
