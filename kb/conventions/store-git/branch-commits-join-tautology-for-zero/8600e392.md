# branchCommitsJoin(0) returns empty join + '1=1' tautology so callers concatenate unconditionally

branchCommitsJoin(branchID) returns three strings + args: when branchID==0, returns ('', '1=1', nil) so callers can unconditionally concatenate '... <join> WHERE <where> AND <other_conds>'. When branchID > 0, returns ('JOIN branch_commits bc ON bc.commit_hash = cl.commit_hash', 'bc.branch_id = ?', []any{branchID}). Saves a branch in every query method (CommitLogQuery, CommitLogActivity, CommitLogWalkChanged) — they don't need separate 'with branch' / 'without branch' code paths. The tautology+empty-join pattern is a common SQL-builder idiom in this codebase; see also commitLogPathCond for the same shape applied to path filtering. Anti-pattern: introducing a `if branchID == 0 { ... } else { ... }` per query — the tautology branch keeps the common case clean.
