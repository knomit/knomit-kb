# commitLogPathCond: empty→1=1, .md→exact match, otherwise GLOB subtree

commitLogPathCond(path) returns three SQL fragment shapes depending on input: empty path → '1=1' (no filter); path ending in .md → 'path = ?' (exact match for a single fact); other path → 'path GLOB ?/*' (subtree match for a directory prefix). The GLOB pattern uses SQLite's GLOB operator (not LIKE) for performance — case-sensitive, simpler matcher, and indexed via commit_log_path_time. commitLogPathCondPrefixed(path, 'cl.') adds the table alias prefix when the column is cl.path (when commit_log is joined with branch_commits). This single helper is shared by CommitLogQuery, CommitLogActivity, and CommitLogWalkChanged — keeps path filter semantics identical across all three. Anti-pattern: rolling your own path filter inline — would diverge from the canonical exact-vs-subtree behavior and lose the .md disambiguation.
