# Storer.DB() is a TEST-ONLY escape hatch for integrity tests and verify tool

Storer.DB() *sql.DB exists as an escape hatch for INTEGRITY TESTS and the verify tool ONLY — read-only schema introspection (e.g. listing all branches, counting orphan rows, sqlite_master probes). Comparable to store.Service which deliberately has NO public DB() method (kb/decisions/store/no-db-getter-escape-hatch). The storer-level getter is preserved here because (1) low-level integrity probes need raw access; (2) Storer is package-internal-ish — most callers go through Service which forwards via Storer(). Anti-pattern: using DB() for normal reads/writes that bypass storer methods — losing the content-addressed-write guarantee. Use the named Storer methods or service-level facets instead. There is also DeleteObjectForTest — explicitly named to make it impossible to call it accidentally from production code.
