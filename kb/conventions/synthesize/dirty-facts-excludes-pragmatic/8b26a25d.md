# dirtyFacts filters seeds to kind=epistemic ONLY; pragmatic facts never enter the synthesis pipeline

dirtyFacts filters seeds to kind=epistemic ONLY — pragmatic facts (policy, heuristic) are EXCLUDED from the synthesis pipeline. Both code paths enforce this: (1) first run (no watermark) uses idx.Search(SearchOptions{IncludeKinds: []string{string(fact.Epistemic)}, Limit: 100_000}); (2) incremental (has watermark) skips parsed facts where f.Kind != fact.Epistemic after DiffFiles+ReadFact+ParseFact. WHY: the decision-application code (mergedFact, distillFact in types.go) does NOT carry Kind through. Letting a pragmatic fact in would cause it to be silently rewritten as kind=epistemic on commit and the original deleted — corrupting policies/heuristics. If you ever extend mergedFact/distillFact to carry Kind through prune/distill/reflect, this filter can be removed but must NOT be removed before that.
