# Methodology reinforcement is recorded by appending methodology path to TRANSITION fact's refs

Reflect's 'reinforce' action does NOT touch the methodology fact — it appends the methodology's path to the TRANSITION fact's `refs` (case-insensitive match, idempotent). No separate side-channel table, no SQLite reinforcement-counter column. Git is the single source of truth. Reinforcement count for a methodology emerges from the corpus: number of facts whose refs contain its path. Queryable from the corpus itself (facts whose refs contain the methodology path) or via git log; the former search_graph tool no longer exists. Consistent with how distill's computeWeight already treats local fact-path refs as first-class signals. Future derivable queries (no schema change needed): 'methodologies not reinforced in N sessions', 'most-reinforced methodology this quarter', 'which methodologies explain this transition'.
