# Evidence weight on synthesized facts uses SumProductNorm = sum(c*s)/(sum(c*s)+1)

Merged and distilled facts carry a machine-computed evidence_weight field in [0, 1). Formula: SumProductNorm = sum(confidence_i × sources_i) / (sum(confidence_i × sources_i) + 1.0), maps [0, ∞) → [0, 1). MUST be computed BEFORE source facts are deleted in ApplyPruneDecisions (for merges) and ApplyDistillDecisions (for synthesized facts). For distill, source paths are df.Refs filtered to local .md refs. Implementation lives in internal/corpus/synthesize/step/weight.go (moved from internal/corpus/synthesize/weight.go) as a WeightStrategy interface, entered through ComputeTransfer (merges) and ComputeWeight (derivations), which also walk the lineage of distilled or discovered sources rather than weighing only the direct ones; SumProductNorm is the default; alternative strategies can be added later without changing call sites. Fields: yaml frontmatter 'evidence_weight: <value>' (omitted when 0), Fact.EvidenceWeight float64, FactRecord.EvidenceWeight float64, SQL column facts.evidence_weight REAL NOT NULL DEFAULT 0. SerializeFact emits the field ONLY when > 0 — existing facts round-trip byte-identically. NO MIGRATION of existing facts (deliberate). Sources that fail to read or parse contribute nothing.

The only source type the weight skips is hypothesis. It does NOT skip pragmatic facts by kind or type: a signal or frame (confidence meaningless) cited as a source of a derived or merged fact would be weighed like any other fact, as confidence times sources. This does not mean they get weighed in practice; it means nothing in the weight code keeps them out, so a caller must not cite one as evidence (re-read at the PR #668 merge commit, 1eb481b6, where `frame` was added without touching weight.go).
