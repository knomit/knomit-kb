# GradeChain scores an engine run (the decoded repos.ReasonResult) against a question's gold with mechanical metrics where 0/0 = 1, reading answers from the host-written paths and judging every ref at the world head the run started from

Contract: ReasonChain/ReasonStep/ChainGap (scenario_chain.go) mirror repos.ReasonResult field for field with the same JSON tags, so a run's JSON decodes unchanged (TestGradeChain_DecodesTheEngineResult round-trips the engine's own result). When ReasonResult changes, these change with it; the graders conform to the engine, never the reverse.

Where facts come from (scenario_grade.go): answer facts are read from the paths the HOST wrote (chain.AnswerFacts) on chain.ExperimentBranch if set, else the world branch, plus ExistingAnswer on the world branch; hypothesis-type facts are split off as the gap hypothesis. Chain paths map to spec ids with LoadedWorld.IDOfPath. Every ref of an emitted fact is judged at the world head the run STARTED from (LoadedWorld.Head); a kb:// ref carries no commit, so there is no other commit to judge it at (local fact live at head, system file readable at head, external URL listed in external_sources).

Metrics, all ratio(n, d) with 0/0 = 1 unless noted: MoveAccuracy (run moves matching a gold step in partial order over run moves; forced 0 when the run made no moves), MoveRecall (required non-optional gold steps matched), ExtraMoves (count), RelevancePrecision and RelevanceRecall, SupportAccuracy (gold support labels reproduced exactly; last label on a fact stands), Misattribution (share of the run's `supports` labels on forbidden or distractor facts; 0 when there are no supports), ChainRecall and ChainPrecision (should_cite and partial_support facts are neutral), ForbiddenCited, AnswerValidity (checks passed over run: ontology path, ValidateFact, serialize, kind/type, populated fields, then type, topic, confidence band, must/should/must_not cite, entities, motifs), RefCorrectness, OutcomeCorrect, Correct, Brier. OutcomeCorrect replaces an assess label: gold gap needs a run `gap`; gold answer or partly needs a run `answer`. GapRates gives gap recall (0/0 = 1) and false-gap rate (0 when no answerable question); CalibrationECE is 0 for no scores.

The category check requires a path boundary: inCategory is true for the same category or a descendant ('/' boundary), so `storage-legacy` is NOT in `storage` (TestGradeChain_CategoryPrefixIsNotACategory). Judge-graded metrics (claim entailment, synthesis support rate, hypothesis premise match) are not here.

Consequence: a perfect score on a gap question needs no answer fact, a declared gap, a valid hypothesis and a named missing premise; do not read a 1.0 ratio as evidence the run did anything when its denominator is 0.
