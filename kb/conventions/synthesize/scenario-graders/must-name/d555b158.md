# Scenario gold names a fact the answer weighed against in answer.must_name (format v1.1), never in must_cite: the grader checks the answer BODY names it by path or title, a named support-set fact counts toward chain recall, and CheckGold refuses a fact that is both must_cite and must_name

knomit-scenario v1.1 (compatible addition), from local commit 20434db7 on feat/expert-eval-runner: GoldAnswer.MustName (`must_name`). The grader (scenario_grade.go namedIDs) folds case and whitespace and looks for each fact's path or title in the body of the answer facts (never the gap hypothesis), adds a `must_name` validity check, and in chain recall counts a support-set fact as recalled when it is cited OR named.

Why: the ruling that a contradicting fact is never in an answer's refs (refs are why we believe it); the answer names it in its body. F7 gold had listed the contradiction in must_cite, and citedIDs counts refs only, so a correct engine scored zero (review cause Z3). The data repo (expert-scenarios a3c84de) migrated every F07 world by script: each fact a question's chain labels `contradicts` (last label stands) moved from must_cite to must_name, and each other contradicts-labelled fact of the question's support set was added there; 18 of 22 worlds changed, all 22 re-validated with TestScenarioSpecDir; FORMAT.md records v1.1.

Consequence for world authors: a fact the answer must mention but not rest on (a contradiction, an outweighed value) goes in must_name. A question's support set may still list it, and the chain labels it contradicts. Graders and replay must read the chain's own label before support-set membership (see architecture/repos/engine/replay).

What this does NOT mean: must_name is not a softer must_cite. A named fact that is ALSO cited still passes must_name, but citing a contradiction is caught by must_not_cite or forbidden when the gold lists it there. A loader older than 20434db7 refuses the key (strict decoding), so compatible means existing specs stay valid, not that old loaders read new specs. Pinned by TestGradeChain_MustNameReadsTheBody and TestEngineEval_Z1Z2Z3_ContradictionIsNamedNeverCited.
