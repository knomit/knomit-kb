# Date.now() + Math.random() does NOT produce unique ids — float precision caps it at ~4096 values per millisecond, and React keyed on it dropped rows

web/src console entries were keyed on `id: Date.now() + Math.random()`. That looks unique and is not. Date.now() is ~1.7e12, where a float64's ulp is 2^-12, so the fractional part can only take ~4096 distinct values in a given millisecond. Measured: 197 unique ids across 200 entries logged in one tick.

The entries were React list keys, so colliding ids made rows DISAPPEAR from the rendered console — during exactly the event the console existed to capture, an SSE burst. Silent: no warning, no error, just missing log lines when you most need them. Fixed in P1.7 (2026-07-21) with a monotonic counter.

**Consequence — the general rule, which is why this fact is kept:** never build an id by ADDING a random fraction to a large timestamp. The magnitude of the timestamp destroys the precision of the random part. If you want time-ordered unique ids, use a monotonic counter, optionally paired with a timestamp in a SEPARATE field.

**Testing note that makes a regression test real:** asserting 'N ids are unique' is not enough on its own — it passes trivially if the burst happens to straddle milliseconds. The test must ALSO assert that the burst genuinely SHARES timestamps, so it reproduces the condition the old scheme could not survive.

**WHAT THIS DOES NOT MEAN.**

- *Not* "Math.random() is the problem", and not Date.now() either. The bug is the ADDITION — combining them into one float. Concatenating them as a string, or keeping them as separate fields, has no such collision.
- *Not* "there is code to go look at." The console panel was REMOVED (commit b27972ca, 'shorten ref labels, drop the console panel, collapse an empty rail'); `web/src/consoleStore.ts`, its test, `Console.tsx`, `ConsoleEntry` and `CONSOLE_LOG` no longer exist, and no `Date.now() + Math.random()` pattern remains anywhere in web/src. This fact survives as a transferable rule about float-precision id schemes, not as a description of live code. See [[console-panel-removed]] (kb/decisions/ui/console-panel-removed/ac15460b.md).
