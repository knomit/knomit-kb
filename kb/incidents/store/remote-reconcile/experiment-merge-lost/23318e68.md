# A committed experiment's work was lost on a rewind after ONE later write (and an agent write was lost behind an experiment sync plus fast-forward commit): the replay walk followed first parents only and skipped every merge

WHAT HAPPENED (gap probe on dev 6f241959, fixed by PR #535, merge 48e7d8d5). CommitExperiment writes a merge commit and deletes the experiment, so on the agent branch that merge's SECOND parent is the only reference to the experiment's commits. The rewind replay (unpushedCommitsDropping, run when the main was force-rewound) walks the agent branch's first-parent chain and skips merges. PR #531's fix for the empty-walk case (branch kept as it stands) saved the experiment ONLY while the walk was empty. ONE ordinary fact write after CommitExperiment makes the walk non-empty: the write is replayed, the merge is skipped, the experiment's commits are never collected, and the branch is rebuilt on the new upstream without them. Probe: exp.md kept:false, later.md kept:true. Realistic in any repository with an origin whose main is force-rewound.

THREE SHAPES, all fixed in #535 and pinned in internal/store/remote_reconcile_side_test.go:
1. Experiment commit, then a later ordinary write, then a rewind: the experiment's work vanished. Pinned by TestReconcileAgentRebase_ExperimentMergeSurvivesALaterWriteAndARewind.
2. SyncExperiment (merges the agent branch INTO the experiment), then CommitExperiment, which FAST-FORWARDS because the agent branch has not moved since the sync: the first-parent chain now runs through the experiment and the agent's OWN earlier write sits behind the sync merge's second parent, so a rewind lost it. Pinned by TestReconcileAgentRebase_ExperimentWithASyncMergeSurvivesARewind (requires ModeFF).
3. A regression of the fix's own first version (found by the PR review, B1): replaying the side's commits one by one resurrected the version a conflict resolution in the merge had dropped, or lost the body it wrote. Fixed by replaying a clean side as the merge itself. Pinned by TestReconcileAgentRebase_AResolvedExperimentMergeComesBackAsDecided (dst and body) and TestReconcileAgentRebase_AResolvedMergeOnlyDivergenceKeepsTheResolution.

FLEET: not affected by shape 1. The fleet repository refuses experiments (ErrFleetReadOnly), and what lies behind a hub master's merges is members' commits (foreign-signed) or old main; dropping those is the replay's general rule, not data loss (see the replay-stop fact's corrected EDGE note).

CONSEQUENCE: any change to the rewind replay's treatment of merges must be tested with a merge that has own work behind its second parent AND a later ordinary write, not only with a merges-only divergence.

MISREADING: 'the empty-walk no-op protects experiments' is true only for the walk that is empty; it never protected shape 1 or 2.
