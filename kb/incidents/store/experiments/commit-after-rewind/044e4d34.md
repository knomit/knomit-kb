# Incident: committing an experiment that was open across a rewind brought the scrubbed content back and made the scrubbed commit reachable from the agent branch, so the next push sent it to the origin that removed it (#538); the first fix, a commit-by-commit replay, then lost a sync merge's settlement

WHAT HAPPENED (fixed in #538, merge 3f254262; found while working on the rewind replay of #535). The agent branch is rewound onto an upstream that force-removed a fact or a secret (G6 scrub). An experiment forked before the rewind still held the scrubbed commits; experiment branches are not rebuilt with the agent branch. CommitExperiment merged it with the old common ancestor as base, so the three-way merge re-added the scrubbed content and the scrubbed commit became reachable from the agent branch. The next force-push then sent the removed content back to the origin that had scrubbed it.

THE FIX (kb/invariants/store/experiments/open-across-rewind/): record the pre-rewind agent tip per experiment before the rewind, rebuild at the next commit or sync as one squashed commit.

THE LESSON FROM THE REVIEW. The first fix replayed the experiment's own non-merge commits one by one onto the new tip and skipped the sync merges. Review probe: the experiment and the agent both edit one path, a sync merges with the parent winning, the experiment writes another file, a rewind runs, the experiment commits. The replay re-applied the experiment's PRE-sync change onto a tree that already carried the agent's version, so the commit was refused with base = ours = theirs (unreadable) and a retry with 'ours' landed a version the experiment no longer held, silently reverting the agent's edit. A commit-by-commit replay across a sync merge LOSES what the merge settled. The squash from base = merge-base(experiment tip, recorded tip) keeps it, because the settled path is equal at base and src. A second review finding: OpenExperiment racing the rewind could fork at the pre-rewind tip with no row to record (closed by the parent lock).

CONSEQUENCE. When rebuilding history that crossed a merge, do not replay the commits on either side of it; merge trees from the last point both sides agreed on. When reasoning about a rewind, include EVERY branch that forked from the rewound one, not only the rewound branch.

MISREADING. This did not leak through plain agent-branch rewinds: it needed an open experiment. Rewinds that ran before #538 are not covered (no record exists).
