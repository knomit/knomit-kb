# Re-cloning failed E4 when origin's agent branch had been fast-forwarded onto a forge merge already on main: the agent tip was judged although nothing lay beyond main (fixed in #442)

Incident (2026-10-08): the user re-added the agentic-engineering repo after its GitHub repo was recreated with identical branches. On origin, main == agent/<host> == a GitHub web-merge commit, GPG-signed by GitHub; the instance's sync had fast-forwarded its agent branch onto that merge. Every re-clone failed with: 'clone: InitFromRemote: origin's copy of this instance's agent branch holds commits this instance did not sign: origin's agent/<host> holds 1 commit(s) not signed by this instance, beyond origin's main: <sha>: commit signature is not an SSH signature'. The claim was false: nothing was beyond main.

Cause: walkHistory(st, start, stop, visit) (internal/store/verify_walk.go) checked the stop set only when descending to parents, never for the start commit. checkOwnLineage (verify_e4.go) walks from origin's agent tip with stop = every commit reachable from origin's main, so a tip that was itself on main was still visited and judged; a forge-signed (non-SSH) tip is never own-signed, so E4 refused it. Any instance whose agent branch was fast-forwarded onto a forge merge commit hit this on every clone, on every machine.

Fix (PR #442, merged as 3291e2f8): walkHistory returns without visiting anything when stop[start] is true. Only checkOwnLineage's behaviour changed — every other caller with a non-empty stop set (CheckRange, onlyMergeCommits, PushedBranches, E4's transitive-trust walk) already guarded stop[start] itself, and the audit and fleet/trigger walks pass no stop. E4 still refuses a commit genuinely beyond main that is not own-signed, accepted, or vouched; this fix does NOT relax E4 for foreign commits. Regression tests: TestE4_TipAlreadyOnUpstream (tip == main tip and tip behind main's tip, both forge-GPG-signed, adopted; an unsigned commit beyond a forge-merged main refused and listed alone) and TestWalkHistory_StartInStop.
