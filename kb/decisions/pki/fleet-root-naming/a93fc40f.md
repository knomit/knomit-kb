# The fleet root is never called 'master': its default directory is <home>/fleet (cmd fleetDirName), the command is `knomit identity init-root` (init-master removed, no alias), and help, errors and comments say 'fleet root'; signed OAuth decisions record decided_by as fleet-root:<fp8>

DESIGNER DECISION (2026-10-13, during the PR #513 review): instead of allowlisting the "master" literal that TestNoHardcodedBranchLiterals flagged (cmd/identity.go masterDirName, from PR #512), rename the role word. The test now passes with no new exemption.

CHANGES: masterDirName = "master" -> fleetDirName = "fleet"; resolveMasterDir -> resolveFleetRootDir; openMasterRoot -> openFleetRoot; `identity init-master` -> `identity init-root` (pre-release, no alias: `init-master` is an unknown command); 'master side / master passphrase / master directory / fleet master key' -> 'fleet root side / fleet root passphrase / fleet root directory / fleet root key' in cmd/identity.go, cmd/oauth.go, cmd/oauth_sign.go, internal/pki and internal/oauth comments; oauth.ApplySigned's decided_by/granted_by label 'master:<fp8>' -> 'fleet-root:<fp8>' (still deliberately not a principal spelling).

UNCHANGED: <home>/pki ([tls].dir), file names (root.crt, root.key, issued.jsonl, revoked.jsonl).

STILL TRUE AFTER PR #519 (merge 72919aa0): the default fleet root directory is still <home>/fleet (cmd fleetDirName, resolveFleetRootDir) and `identity init-root` is still the command; the root key in it is now a plain file (kb/decisions/pki/root-custody/plain-key-file/781b626f.md). The keychain account fleet-root/<RootID> and the helper openFleetRoot named above no longer exist (the keychain custody layer was deleted); the directory name and the 'fleet root' vocabulary are unaffected.

WHAT IT DOES NOT MEAN: 'master' as a GIT BRANCH name (stock git init) is untouched and still handled where branches are; no migration moves an existing <home>/master (pre-release: pass --dir to use it).
