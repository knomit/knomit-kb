# params holds every model's calibrated thresholds as data, and ForModel returns (Thresholds, bool) because a silent default would judge one model against another's geometry

`params` knew WHICH model ships (`DefaultModelID`) but not its GEOMETRY: embeddinggemma's cutoffs were an inline block on its descriptor in `internal/embeddings`, behind cgo. A cgo-free caller wanting the shipped band therefore had to import the ONNX-linked parent or retype the numbers, and a retyped copy goes stale silently at the next re-sweep. The calibration now lives in `params` as data, and the gemma descriptor references it exactly as the nomic descriptor already referenced `Defaults()`. `params` stays a dependency-free leaf: `TestParamsHasNoDependencies` bans non-stdlib IMPORTS, and a map of float64 adds none.

`ForModel(id) (Thresholds, bool)` — THE BOOL IS LOAD-BEARING. Never collapse it to "return the entry, or `Defaults()`": a silent fallback would judge an unknown or typo'd model id against NOMIC geometry with nothing red. That is what `kb/invariants/integrations/hooks/guards-fail-closed` forbids — a guard that cannot evaluate must distinguish absent from zero rather than proceed on a zero value.

PRESENCE IS A MAP-KEY PROBE AND MUST STAY ONE. Implementing it as `th == Defaults()` would report `nomic-v1.5` — a real, registered model whose calibration IS `Defaults()` — as missing. Absence does NOT license validating ids: false is for a genuinely absent entry, never for an id that merely looks unfamiliar.

The safe branch on absence is the NON-AGGRESSIVE one, and its surface reading inverts per caller: for the same-subject gate, "cannot evaluate" means DO NOT REFUSE the caller's write.

DELIBERATE TWO-SOURCE SPLIT, DO NOT "HARMONISE": `applyDedupMerge` reads `Dedup` from `store.EmbedderThresholds`, the same-subject gate from `ForModel`. They cannot diverge in production — descriptors read their thresholds from `params`, enforced by `TestEveryDescriptorReadsItsThresholdsFromParams` — and where `ForModel` has no entry the gate is OFF, so nothing is compared. Moving `applyDedupMerge` onto `ForModel` would be WRONG: dedup must keep working for embedders `params` does not know, so it would need a fallback, reintroducing exactly the silent nomic default removed here. Only a test embedder declaring thresholds its model id does not carry can observe the split.
