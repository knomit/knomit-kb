# All 6 absolute cosine thresholds become per-model fields on embeddings.Model; distribution-preserving port for soft knobs

DECISION (PR #72, pluggable embedder): the six absolute cosine thresholds scattered across the codebase are model-dependent (they were implicitly calibrated for nomic) and must travel with the embedding model. They move onto the embeddings.Model descriptor as per-model fields, exposed to consumers through the store.Embedder interface (mcp/store/synthesize already reach the embedder via that interface and none import the embeddings package directly, so the descriptor is the clean single source of truth). Each registered model carries its own values: nomic-v1.5 keeps today's literals, embeddinggemma gets calibrated values, qwen gets sensible defaults.

The six thresholds: (1) learn dedup 0.92 internal/mcp/learn.go; (2) synthesis dedup defaultDedupThreshold 0.92 internal/synthesize/dedup.go; (3) SIMILAR_TO knnThreshold 0.60 internal/store/search_graph.go; (4) search recall floor 0.40 internal/store/search_query.go; (5) rerank tiers 0.70/0.50 internal/store/search_query.go; (6) reflect novelty defaultReflectNoveltyThreshold 0.85 internal/synthesize/reflect_config.go.

OPTIONS CONSIDERED (via AskUserQuestion): (a) all six [CHOSEN]; (b) dedup + hard gates only (4); (c) just the two dedup (2). RATIONALE: all six are the same class of silent mis-calibration when the default model changed from nomic to embeddinggemma, not just dedup — so fixing only dedup leaves the rest quietly wrong. Dedup (#1,#2) is the load-bearing one because over-merge is DATA-LOSS (distinct facts collapsed at write/prune).

CALIBRATION METHOD: dedup/knn/novelty are gates calibratable from the corpus by measuring the doc-doc cosine distribution (distinct vs near-duplicate separation). The soft ranking knobs (#4 recall floor, #5 rerank tiers) CANNOT be rigorously calibrated without labeled query->relevant-doc judgments the corpus lacks; DECISION: distribution-preserving port — set embeddinggemma's value to the same percentile of its query->doc cosine distribution that the nomic value occupied. Existing env overrides (KNOMIT_REFLECT_NOVELTY_THRESHOLD) are preserved layered on top of the descriptor default.
