# Desktop icons are per-platform: macOS tray = monochrome template, Linux window icon via Options.Icon + .desktop launcher

Decision for the Wails v3 desktop app (tools/desktop) on how to give it icons across platforms.

**Options considered (macOS tray glyph):** (a) keep the full-color logo, (b) monochrome template image auto-tinted by the OS, (c) ship separate light/dark colored icons via SetDarkModeIcon. **Chosen: (b).** macOS menu-bar status items are conventionally template images — the OS ignores color and tints the alpha mask to match the menu bar (dark glyph in light mode, light in dark mode). A colored icon clashes with every other tray item. Wails exposes `tray.SetTemplateIcon([]byte)` which sets isTemplateIcon and calls `[image setTemplate:YES]` on the NSImage; the C side resizes it to menu-bar thickness, so a single crisp PNG suffices. The glyph (icon-template.svg → icon-template.png, 44px) is the diamond as a black OUTLINE plus the embedding-graph lines/nodes in black on transparent — the recognizable knomit mark rendered for tinting.

**Linux/Windows tray:** stays the COLORED icon.png (64px) via `tray.SetIcon` — those tray/notification areas have no monochrome-template convention and the full-color mark reads best. Wiring is split by build tag: trayicon_darwin.go (SetTemplateIcon, embeds icon-template.png) vs trayicon_others.go (`//go:build desktop && !darwin`, SetIcon, embeds icon.png); app.go calls `applyTrayIcon(tray)`.

**Options considered (Linux app/window icon):** (a) running-window icon only, (b) window icon + .desktop launcher. **Chosen: (b).** Root cause of 'Linux app has no icon': `application.New(application.Options{...})` set no Icon. On Linux Wails derives the window/taskbar/alt-tab icon SOLELY from `Options.Icon` (application_linux.go setIcon + webview_window_linux.go `w.setIcon(app.icon)`); unlike macOS there is no .app bundle to fall back on, so an unset Icon shows GTK's generic placeholder. Fix: embed appicon.png (256px colored, web/public/logo.svg) and pass it as `Options.Icon` (set on all platforms; harmless about-box icon on macOS). For the GNOME/KDE app grid, `make desktop-install` installs the binary to ~/.local/bin, appicon.png as the hicolor 256x256 app icon, and tools/desktop/linux/knomit-desktop.desktop (Exec substituted) to ~/.local/share/applications.

**Asset generation:** all committed PNGs are regenerated by `make desktop-icons` (rsvg-convert + iconutil) and //go:embed-ed into the binary.
