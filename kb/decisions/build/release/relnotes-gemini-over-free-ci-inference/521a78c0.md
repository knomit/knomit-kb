# Release-note distillation uses Gemini gemini-3.5-flash-lite with a GEMINI_API_KEY repo secret because GitHub Models — free CI inference, no secret — was fully retired 2026-07-30

**Why a repo secret at all, when CI could once do inference for free.** GitHub Models offered free inference from Actions via `permissions: models: read` and the built-in `GITHUB_TOKEN` — no secret to provision, no external account. That was the natural fit for distilling release notes in CI. It was closed to new customers in June 2026 and **fully retired on 2026-07-30**: playground, catalog, inference API, and BYOK all gone. GitHub's recommended replacement is Azure AI Foundry, which is paid, and there is no general-purpose Copilot inference API callable from CI.

So the choice was between a paid Azure path and a direct provider key. Gemini won on cost and on already being a dependency (see the genai invariant). `GEMINI_API_KEY` is a repository secret, provisioned 2026-08-05.

**Model tier.** `defaultModel = "gemini-3.5-flash-lite"`. Gemini's free tier narrowed in **April 2026 to Flash and Flash-Lite only — no Pro models** — which bounds the choice from below. It is also the right tier on merit: this is compression of prose a human already wrote, not a reasoning task. Measured cost is ~7,600 input tokens (30 KB of PR titles + bodies for 9 PRs) and ~200 output ⇒ **≈ $0.003 per release**. Cost is therefore NOT a constraint on model choice here; upgrading to `gemini-3.6-flash` is a one-line change if summaries read poorly.

**Consequence for a future maintainer:** do not "simplify" this back to `permissions: models: read` — that endpoint no longer exists, and the workflow would fail-open into producing no prose at all (silently, by design), so the regression would look like "the key is missing" rather than "the API is gone".

**Dates are load-bearing and will age.** Both the retirement and the free-tier narrowing are external vendor facts as of 2026-08. Re-verify before concluding that no free CI inference option exists today.
