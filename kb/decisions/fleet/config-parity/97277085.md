# Configuration parity: ANY configuration a regular repository has and the fleet repository needs must be reachable through the /fleet API (user ruling 2026-10-16); PR7c is building it, and until then forge credential rotation and forge URL changes are impossible

RULING (the user, 2026-10-16, verbatim): "ANY AND ALL configuration that is usually done for a regular repo and is needed for the fleet repo has to be available via the /fleet endpoint. "fleet" is a repo, but is a special one, so we have to isolate it and protect it appropriately, but outside of that it has similar needs with regular repos - change origin, update access tokens, etc."

RULE. The fleet repository is isolated from the generic repo routes (every mutation there is 409 fleet_repository; see the decision that the fleet repository is changed only through /fleet). So every setting a regular repository gets through its own routes and that the fleet repository also needs (origin, access tokens, and whatever a future repository setting adds) MUST have a /fleet equivalent. CONSEQUENCE for new work: when you add a repository setting, ask in the same change whether the fleet needs a /fleet equivalent; shipping the generic route alone silently leaves the fleet without it, because the gate refuses the route for the fleet.

KNOWN GAPS (true at merge e417fd76 of PR #528; each reads FALSE once PR7c lands, then update this fact): (N2) forge token rotation is impossible. PUT origin was how a member of a forge-hosted fleet rotated its token, and it is now refused; POST /fleet/follow accepts only a URL that classifies as a peer of THIS fleet (cert chains to this root) and answers 422 `not_this_fleet` for a forge URL, and a credential is refused for a peer (auth_invalid), so no route updates the origin's auth. Until /fleet/follow takes forge URLs and credentials (PR7c), an expired forge token on a member means every sync fails and the only recovery is Leave, a revoke by the master and a re-enroll. (Related) a forge-hosted fleet's origin URL cannot be changed either.

MISREADINGS. "Parity means the generic routes are reopened for the fleet": no, the gate stays; parity means /fleet routes. "Parity is already there because /fleet/follow exists": follow covers only repointing at a peer of this fleet.
