# F07 revision 2 approved WITH the causal-trace mechanism: three commit trailers (Knomit-Trace / Knomit-Cause / Knomit-Trigger) carry causality in the signed commits themselves; rejected a notify primitive, sessions(), stdio-binary recipes, a depth-counter trailer, and causality recorded only in the per-instance fire log

OPTIONS. For 'when X is observed on Y, do Z' declared in the ontology (F07 rev 2): (1) the design as written — triggers on ontology nodes, episodes derived from the tree diff of this machine's agent branch, `if` in the goja sandbox, actions emit/script/push/run, recipes as a trusted JavaScript tier with exec, PLUS a causal trace carried as commit trailers; (2) rev 1's shape with a `knomit-trigger-depth` counter trailer and no trace; (3) a `notify` primitive bound to one agent host's channel, a `sessions()` hint, or recipes as JSON naming binaries with a stdio contract (all raised and rejected while writing rev 2, recorded under D3); (4) causality kept only in the per-instance fire log (rebuildable cache, never synced).

RATIONALE (the user, verbatim, on why a trace): "all this async machinery to put tasks then have async executions that could write more facts that could trigger more actions and so on will make it very hard to stitch together the trajectory of a task through the system - essentially, what happened with each. Some kind of an execution trace, if you will." Trailers are inside the signed bytes and travel with the commit to every machine; a cause is a commit hash, identical everywhere, so the chain survives merges; a fire-log-only record does not sync and cannot be read back with plain git. The core names no agent host: 'wake a session' is a recipe's business, never a primitive.

CHOICE (user, verbatim): "agreed with F07 (triggers) including the trace mechanism you're proposing" (2026-09-27 ~10:00). Delivery: PR 1 reads Knomit-Trace and exposes change.trace (built, 1b); PR 3 stamps script writes; PR 5 passes the values to recipes and the MCP path.

NON-SCOPE: nothing in PR 1 mints or stamps a trailer; the PR 3 seam (a ctx-carried trailer set read at the three authored-commit builders) is documented, not built. Old commits can never be given a trace after the fact, which is why the shape was fixed now.
