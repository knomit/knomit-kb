# All times are UTC — 'all times MUST BE UTC - expire, due, everything': `expires` is normalised to Z at the write gate, the sweep clock is time.Now().UTC() once per run, fired_at is stored as Unix seconds and rendered RFC 3339 with an explicit Z; rejected keeping the input offset as written and the local-zone 'Local Unix seconds' fired_at integer

OPTIONS (F07 PR 2 brief, ruling 5, 2026-09-28). F03 kept `expires` AS WRITTEN (offset and all, 'so a round trip is byte-stable') and 1b documented trigger_fires.fired_at as 'Local Unix seconds, for the operator'. For PR 2: (A) keep both — instants compare correctly anyway (expires_at is Unix seconds), only the displayed strings differ by zone; (B) UTC everywhere: normalise an RFC 3339 input with an offset to the same instant in UTC with an explicit Z on write (SerializeFact; the REST PUT, which commits bytes verbatim, forced to rewrite when the normalised form differs), read the run's clock once as time.Now().UTC() at whole seconds, stamp fired_at with time.Now().UTC().Unix(), render every F07 timestamp (GET …/triggers fired_at) as RFC 3339 with a Z, and grep the 1a/1b code for local-time formatting.

RATIONALE: one zone removes a class of operator confusion across a fleet whose machines sit in different zones; instants were already UTC in the index, so the change is to the strings humans and scripts see. Reads stay lenient (an older `+02:00` still parses to the same instant and is rewritten on its next serialization).

CHOICE (maintainer, verbatim): "all times MUST BE UTC - expire, due, everything" → (B). Built in #337: fact.NormalizeExpires, store.UTCStamp, TriggerFire.FiredAt as a Z string, the PUT gate, a run under time.Local = America/New_York yielding identical stored values (TestDue_UTCEverywhere, TestTriggerFires_FiredAtIsUTCWithZ). The F03 tests that pinned 'offset kept' were flipped.

NON-SCOPE: offsets are still ACCEPTED on input (converted, not refused); nothing rewrites files nobody touches; the SSE `trigger` event carries no timestamp and the web UI renders no F07 timestamp yet, so neither changed.
