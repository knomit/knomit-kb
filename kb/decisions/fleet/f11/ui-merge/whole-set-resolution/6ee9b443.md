# A conflicting pushed-branch merge is refused, both versions of each fact are shown, then the operator keeps the host's or takes the peer's version for the WHOLE set — a knowing departure from the 2026-09-20 no-repair experiment dialog (user ruling D3, F11 UI merge)

USER, VERBATIM (2026-09-29): "1) agreed 2) agreed 3) agreed 4) no, no warnings - remember the principle, we should operate like a chain of trust ? If I trust this agent A and  agent A trusted agent B and it accepted its commits then we should trust them." This fact records answer 3.

OPTIONS (open decision 3): (a) refuse, show each conflicting fact's host and peer versions, then offer 'Keep this host's version' / 'Take <peer>'s version' for all of them, or Cancel; (b) refuse and report only, as the experiment conflict dialog does; (c) resolve silently with LocalWins.

CHOICE: (a). The merge is StrategyRefuse; the 409 carries conflicting_paths plus base/host/peer commits; the UI fetches each fact at host_commit and peer_commit before the choice; the retry sends resolution host|peer, applied to every conflict detected under the dst lock. Wire vocabulary is host/peer; ours/theirs are refused (400) because for this asker git's 'ours' is the host, the reverse of knomit_experiment's.

DEPARTURE, AND WHY: the 2026-09-20 ruling (kb/decisions/experiments/ui) made the experiment conflict dialog offer NO repair because a Sync button 'silently overwrites the experiment's version of exactly the facts under discussion', and an agent can resolve an experiment properly through knomit_experiment with all three versions. For a pushed branch there is NO agent-side path (knomit_experiment cannot merge a peer branch), so report-only would leave a conflicting peer branch unmergeable by anyone. Showing both versions first makes the whole-set overwrite a SEEN one.

REJECTED: report-only conflicts; silent LocalWins.

NON-SCOPE: does not revise the experiment dialog; no per-fact mixed choice or merged body in the UI. Known limit: only the peer tip is pinned, so if the host's agent branch changes between the 409 and the click, a newly conflicting fact takes the chosen side unseen.
