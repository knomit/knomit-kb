# receive-pack is knomit's own code over go-git's codec, not go-git's built-in transport/server — as upload-pack already was

OPTIONS (F11 RCA Q2): go-git v5.19.2's `plumbing/transport/server` receive-pack session, or knomit's own handler over go-git's codec pieces (ReferenceUpdateRequest, packfile.Parser, ReportStatus, sideband) as upload-pack already is.

CHOICE: knomit's own handler (approved with the proposal).

RATIONALE: go-git's server (1) writes the pack into the storer BEFORE any ref is judged, so a refused push's objects would be retained; (2) advertises every ref plus HEAD, the raw view the curated-advertisement decision forbids; (3) advertises delete-refs; (4) ignores the command's old hash (no compare-and-swap) and applies commands one at a time. Each contradicts F11's rulings.

REJECTED: go-git's built-in receive-pack server.
