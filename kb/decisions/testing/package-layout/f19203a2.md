# Go test tree extracted from internal/ into a sibling test/ dir (testenv, storytests, archtest)

Decision (2026-07-01): the Go test framework and its suites were moved OUT of internal/ into a NEW sibling top-level directory test/ (same level as internal/), so the internal/ tree holds only production software and the test scaffolding no longer blurs where the product begins and ends. Motivated by the maintainer disliking test code intermixed with shipping code under internal/.

WHAT MOVED (via git mv, history preserved): internal/testenv → test/testenv (the harness — Storyboard DSL, gitserver fault front-ends, assertions, bare remotes; package testenv), internal/storytests → test/storytests (integration/story + build-tagged contract suites; package storytests), internal/archtest → test/archtest (architecture-boundary guard). Import paths, the archtest `forbidden` string literals, doc comments, and the 5 ci.yml invocations were rewritten internal/<pkg> → test/<pkg>. Unit _test.go files that live INSIDE production packages STAYED put (standard Go colocated unit tests) — only the three whole test-only packages moved.

WHY IT'S SAFE: no production code imports testenv (imported only by _test.go files), so pulling it out of internal/ changes nothing in any shipped binary. testenv still imports internal/{config,fact,mcp,repos,retrieval,store} — Go's internal-visibility rule permits this because test/ is rooted at the module root (parent of internal/), so knomit/test/... may import knomit/internal/.... The archtest guard TestHarnessNotLinkedIntoShippedBinaries still enforces the harness never links into a shipped binary; its forbidden list now reads knomit/test/testenv and knomit/test/storytests.

OPTIONS CONSIDERED — dir name: test/ (CHOSEN — Go-idiomatic singular top-level non-shipping test tree) vs testing/ (clear but visually collides with the stdlib package name) vs qa/ (distinct vocabulary, non-idiomatic). Scope: move all three test-only packages (CHOSEN) vs move only the testenv harness (rejected — would leave storytests/archtest mixed into internal/, defeating the boundary goal).

VERIFIED green after the move: go build ./..., go vet ./test/..., and the full CGO suite (storytests 8.8s, testenv 2.6s, testenv/gitserver 1.9s, archtest pass).
