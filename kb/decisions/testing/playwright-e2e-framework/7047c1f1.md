# E2E tests use Playwright across all layers; priority UI > MCP > API

End-to-end test suite uses Playwright (TypeScript) for ALL three test layers: UI, MCP, API. Single framework managing the whole tree. Priority order: UI → MCP → API — UI tests implicitly cover most API endpoints, so they're the highest leverage. Test layout: e2e/tests/ui/ (browse, fact-view, fact-edit, search, recent, history, origin, status-bar, repo-selector), e2e/tests/mcp/ (learn, query, update, explore, explain, retract, profiles), e2e/tests/api/ (edge cases not covered by UI), e2e/tests/journeys/ (multi-step user journeys). Lifecycle: `make dist` once per run, start binary with isolated KNOMIT_HOME and a free port, poll GET /api/v1/repos until 200, seed fixture data via PUT /api/v1/knomit/fact. Default browser headless Chromium; all browsers in CI. Helpers: e2e/helpers/mcp-client.ts is a thin HTTP-streamable transport MCP protocol helper.
