# knomit_review steals cycles from calling model for KB maintenance; additive to headless pipeline

knomit_review is a work-stealing MCP tool that opportunistically uses the calling model's cycles for KB maintenance — NO separately configured LLM adapter needed. Flow: model calls with no session_id → tool creates session, computes dirty facts, builds scoped clusters, returns highest-priority work item with {prompt, response_schema}; model reasons, returns JSON decisions via session_id+response; tool applies, returns next item; repeat until done. Stays ADDITIVE to headless pipeline (POST /synthesize) — both share core domain logic (ClusterBuilder, PromptRenderer, DecisionParser, DecisionApplier extracted from prune/distill). On first run (no watermark) the full KB is clustered as today; subsequent runs use scoped clustering: dirty fact detection via git diff against watermark, then find candidate neighbors via SearchIndex.Search() + same-category co-location, build subgraph containing seeds + neighbors only, run existing Louvain over scoped input. ABANDONED sessions don't advance the watermark (only completed sessions do); decisions already applied during the abandoned session remain committed (they were valid).
