# The motif matching cascade ships as a monotone exact → token-2 ladder with the embedding tier DEFERRED — and the deferral is a measured verdict, not an unfinished feature

**The shipped cascade.** Mechanical alias resolution (stemmed token multiset as grouping key) + a durable judge overlay with membership-fingerprint expiry. Effort ladder is MONOTONE — each level's candidates are a strict subset of the next's: normal = verbatim canonical-id equality only; medium = tight point, near lane only; high = exact ∪ token-2, both lanes.

**Measured recall (Phase 2, cross-author, pack 2 — four models independently naming the same sixteen mechanisms):** exact 15%, stem 15%, token-2 35%, **token-1 permissive 72%** against a ≥60% target. The figure is a FLOOR: no LLM judge ran, and the judge only ever merges clusters the mechanical layer kept apart. `exact` and `stem` agreeing is a design property, not a coincidence — the alias layer's grouping key IS the stemmed token multiset, so they differ only where a judge merged clusters string similarity kept apart.

**The `motif_match=soft` embedding tier is DEFERRED, on a pre-registered criterion.** Measured over 192 blind-labelled pairs: 1 in-band positive against a floor of 20, with controls valid in both directions. Transform settled (centered, per-model stored mean); rendering settled (name+def). **Designer framing: corpora stay at hundreds of facts, and that IS real-world scale — so this deferral is likely the PERMANENT, correct state, not a waiting room.** Un-defer trigger: a vocabulary reaching ~20 genuine in-band synonym pairs.

**The named misreading.** `soft` being unavailable is not a gap to fill in. It is declared, gated, and answers with WHY it is unavailable rather than returning an empty set. Building it without that population would have meant inventing a number and calling it calibrated.

**Cross-tier suppression amendment:** an exact-match group is never displaced by a token-2 family that contains it (measured live doing exactly that). Within a tier the superset still wins; across tiers the exact group wins. Cost: 289 → 187 served pairs on the fixture, by design.
