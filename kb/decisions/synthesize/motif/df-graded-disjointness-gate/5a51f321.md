# The subject-disjointness gate is df-GRADED, not strict — a shared label blocks only when specific, and this is the motif campaign's one directly evidenced positive finding

GATE rider 1. A shared subject label blocks a motif bridge candidate only when that label is SPECIFIC — df below a per-corpus percentile operating point — with umbrella awareness, and strict behaviour below a 50-label validity floor (where only the universal-label tautology exemption survives).

**Why it replaced the strict any-shared-tag test.** The strict criterion measurably rejected 4 of 5 genuine cross-domain windows in the gate annex. The graded gate recovers them while still rejecting the same-event near-duplicate fixture.

**This is the campaign's one piece of direct positive evidence.** On the single pair a blind judge called MECH, the gate had permitted FOUR shared subject labels — df 284 (universal, = LiveFacts), 66 (umbrella, > 56), 26 and 28 (both above the cut of 5). Each was let through by a DIFFERENT arm of the criterion. The old strict test would have killed the pair on any one of them. The phase's positive finding is the GATE, not the yield.

**Every threshold is a percentile of the corpus's own distribution** — no absolute constant anywhere (MN13). Operating point on the 443-fact research corpus: cut df 3, umbrella df 88, band ceiling 12.

**Two measured caveats to carry.** (1) p90 is confirmed only as HARMLESS: cuts move 2→9 across p80–p95 and candidate/served counts are identical at every setting — the data cannot distinguish p90 from any value in that range. (2) The 50-label floor measured INACTIVE, which is NOT the same as confirmed correct; real corpora carry 1512–3234 labels, so nothing has exercised it. A strict fallback closes the adjacent hole where a derived cut below 2 is unsatisfiable by any shared label and so is no gate at all.
