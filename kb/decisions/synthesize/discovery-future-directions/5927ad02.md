# Emergent-discovery roadmap lives in .claude/future/ as 14 best-solution proposals under three pillars

**Options considered:** (a) proposals framed as retrofits riding existing infrastructure, ranked by integration effort (quick wins first, side tables to avoid schema changes, watermark tricks to avoid state fields); (b) proposals describing the best end-state design, treating current architecture as mutable per the pre-release solution-quality principle.

**Rationale:** The designer explicitly invoked kb/principles/anti-patterns/solution-quality-pre-release: pre-release there is no migration penalty (the SQLite index rebuilds from git), so effort-ordered tiers and minimum-change designs are anti-patterns. First-draft proposals were rewritten after violating this.

**The choice:** The roadmap at .claude/future/ (00 storyline + 14 proposals) is organized as one target architecture with three pillars: (1) one structure substrate — an anchor graph in the existing property graph (proposals 01-03, 05, 07, plus 14's model-extracted typed assertions); (2) local judgment primitives — the ONNX runtime designed for N small local models producing replayable scores: cross-encoder entailment (04, 08, 09), link prediction / structural embeddings / soft community membership (13), relation extraction (14), ontology-placement classification (05); (3) epistemic lifecycle as first-class state — verification, structured settlement, methodology calibration (06, 10-12). Proposals 13-14 were added on designer request for out-of-the-box local-model signal generators; 13 carries a baseline discipline (learned models must beat non-learned graph heuristics on held-out edges before earning their place). Cross-peer bridges and usage-graph seeding from the original brainstorm were explicitly de-scoped by the designer. Status: drafts pending refinement with a different model; nothing implemented yet.
