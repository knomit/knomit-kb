# Methodology injection into prompts — server NEVER auto-cites, LLM does

Methodology application was broken: 40 methodology facts on an active agent branch had ZERO incoming refs (Louvain clustering never surfaced methodology; nothing cited it). Fix: at the relevant injection sites (knomit_hypothesize work-items, knomit_review reflect prompt, synthesize distill prompt) the server calls RelevantMethodologyForFact(ctx, branch, factPath, sourceDomains, sourceEntities, k, minScore) and INJECTS the top matches into the prompt context as 'Applicable methodology' sections containing full title+path+body. SIGNATURE NOTE: the function was originally named `RelevantMethodology(branch, sourceBody, sourceDomains, sourceEntities, k)` — it was renamed to `RelevantMethodologyForFact` and the signature changed to take (ctx, branch, factPath, sourceDomains, sourceEntities, k, minScore). The minScore comes from ri.MethodologyMinScore(). The server records NOTHING automatically — every authoring decision (what to cite, how to tag) stays with the LLM. This preserves the meaning of refs as 'evidence the agent actually used' and gives honest empirical feedback signals (organic cite rate, organic tag-coverage rate). If retrieval is empty, the section is OMITTED entirely from the prompt — no empty heading, no placeholder text. Risk if LLM ignores: prompt tuning is the next lever, not algorithm changes.
