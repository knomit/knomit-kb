# Dedup merge tiebreak: non-hypothesis always wins; then confidence; then sources. Union domains+entities

mergeFacts (internal/synthesize/dedup.go) tie-breaks merge pairs in this strict order: (1) non-hypothesis ALWAYS wins over hypothesis regardless of confidence (hypotheses carry uncertainty, can't beat observed/derived facts); (2) within same category: higher Confidence wins; (3) Confidence tie: higher Sources wins. After the winner is chosen: Domain and Entities are merged as UNION via fact.UnionStrings (dedupes and orders); Sources = a.Sources + b.Sources (sum both). applyGreedyMerges sorts candidate pairs by similarity DESC and enforces 'each fact participates in AT MOST ONE merge per pass' — preventing transitive merges within a single dedup round (transitivity would require re-running dedup until fixpoint, which we explicitly don't).

Anti-pattern: implementing your own merge ordering somewhere — always go through mergeFacts.

WHAT THIS DOES NOT MEAN — THE THRESHOLD IS NOT A CONSTANT (corrected 2026-07-22): this fact previously said `defaultDedupThreshold = 0.92`. There is NO such constant in internal/synthesize at HEAD, and 0.92 is the WRONG number for the active model. The dedup cutoff is CALIBRATED PER EMBEDDING MODEL and read at call time via `store.EmbedderThresholds(emb).Dedup` — for the current model that value is 0.82 (internal/embeddings/model.go). Every live consumer sources it that way: internal/mcp/learn.go, internal/synthesize/review_strategy.go, and internal/synthesize/discovery.go (DedupThreshold field).

Why this matters operationally: 0.92 was nomic's cutoff, and the per-model thresholds were deliberately ported DOWN by preserving the percentile each occupied on nomic. Hardcoding 0.92 against a model calibrated to 0.82 sets the bar roughly a tenth too high — near-duplicates sail through and dedup silently stops merging almost anything. The failure is invisible: no error, just a corpus that quietly accumulates duplicates. Never write a literal similarity cutoff; always read it from EmbedderThresholds for the embedder in hand.
