# The scenario loader and graders live in internal/synthesize, not internal/mcp, because internal/mcp imports synthesize — so the loader takes its write path as a repos.ScriptTools parameter; tests are package synthesize_test and no new package was created

scenario.go, scenario_load.go, scenario_chain.go and scenario_grade.go are in package synthesize. The loader needs knomit's own learn/update/retract handlers, which live in internal/mcp (mcp.NewScriptTools), but internal/mcp imports internal/synthesize; importing mcp from synthesize would be a cycle. So ScenarioLoadOptions.Tools is a repos.ScriptTools the caller builds (and Embedder must be the same embedder Tools was built with) rather than something LoadScenario constructs. The tests (scenario_load_test.go, scenario_grade_test.go) are package synthesize_test, the external test package, which is what lets them import mcp and call mcp.NewScriptTools. The graders mirror the engine's result types instead of importing them (scenario_chain.go) for the same reason: synthesize stays free of the engine's runtime. No new package was added for the scenario code.

Consequence: new scenario code that needs an mcp handler takes it as a parameter or goes in an external test; it does not import internal/mcp from non-test synthesize code.
