# WeightStrategy is pluggable via DefaultWeightStrategy var; hypothesis sources are EXCLUDED from weight

WeightStrategy is an interface in weight.go (Compute(sources []SourceWeight) float64). The default implementation is set via 'var DefaultWeightStrategy WeightStrategy = SumProductNorm{}' — swap the package-level var to change the formula globally without touching any call site. SumProductNorm.Compute = sum(confidence_i × sources_i) / (sum + 1) — maps [0, ∞) → [0, 1) with diminishing returns as evidence accumulates. CRITICAL: computeWeight SKIPS hypothesis-type sources entirely — they carry uncertainty and can't contribute evidence weight to synthesized facts. Sources that fail to read or fail to parse contribute nothing (skipped silently). MUST be called BEFORE source facts are deleted (ApplyPruneDecisions/ApplyDistillDecisions both call it pre-delete — if you reorder so delete happens first, weights become 0 because ReadFact fails). Empty source list returns 0.
