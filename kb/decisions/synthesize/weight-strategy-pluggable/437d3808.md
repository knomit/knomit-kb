# WeightStrategy is pluggable via DefaultWeightStrategy var; hypothesis sources are EXCLUDED from weight

WeightStrategy is an interface in internal/corpus/synthesize/step/weight.go (package step; the file was previously internal/corpus/synthesize/weight.go) with Compute(sources []SourceWeight) float64. The default implementation is set via 'var DefaultWeightStrategy WeightStrategy = SumProductNorm{}' — swap the package-level var to change the formula globally without touching any call site. SumProductNorm.Compute = sum(confidence_i × sources_i) / (sum + 1) — maps [0, ∞) → [0, 1) with diminishing returns as evidence accumulates. CRITICAL: the weight computation (ComputeTransfer for merges, ComputeWeight for derivations; both reach DefaultWeightStrategy through collectEvidence) SKIPS hypothesis-type sources entirely — they carry uncertainty and can't contribute evidence weight to synthesized facts, and a hypothesis is not traversed at any depth of the lineage walk. The weight composes through the lineage of distilled or discovered sources (authored facts are terminal), so it is not only the direct sources' confidence times sources. Sources that fail to read or fail to parse contribute nothing (skipped silently). MUST be called BEFORE source facts are deleted (the ComputeTransfer doc comment says so; the callers are in internal/corpus/synthesize/decision.go, dedup.go and discovery/ — if you reorder so delete happens first, the sources read as unreadable and the weight is 0). Empty source list returns 0.
