# A fact's value is two-layer: truth governs corpus existence, per-reader effect governs emission

Decided 2026-07-04 during the stochastic-target roadmap rethink (the LLM consuming context is stochastic and has priors, unlike a CPU — so the compiler analogy's emit semantics break).

Options considered:
1. Corpus truth is the semantics — calibrated truth defines value; delivery to the stochastic reader stays a peripheral presentation concern. Rejected: nothing pressures the corpus toward usefulness; inert-but-true knowledge accumulates unpriced.
2. Behavioral effect is the semantics — a fact means what it does to readers; inert facts are pruned; truth is instrumental. Rejected: prunes insurance facts (rare-trigger knowledge measures as inert), effect is reader- and time-relative (models churn), and Goodhart risk — facts would be selected for persuasiveness over correctness.
3. Two-layer (CHOSEN) — 'library + librarian': the corpus layer optimizes calibrated truth (existence, verification, dedup, settlement are truth-governed); the emit layer optimizes expected reader improvement per token (selection, ranking, phrasing, dosage are effect-governed, per reader profile, using prior-delta and measured effects).

Rationale: model succession (the truth layer survives reader churn; only the emit layer recalibrates per new model); Goodhart containment (persuasiveness can never buy existence — effect data feeds back into priorities and ranking but can never delete a truth); insurance facts survive (kept on the shelf, emitted only when trigger context matches); the existing bench scorecard already implies the split — Trustable is the corpus layer's axis, Actionable is the emit layer's.

Consequences: prior-delta (what the reader already believes / gets wrong) becomes a first-class emit-layer measurement; recall output optimizes for smaller, sharper, reader-aware emission; the two layers get separate report cards in knomit-bench.
