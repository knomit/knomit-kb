# Upsert uses INSERT OR IGNORE + SELECT (atomic), NOT SELECT-then-INSERT (TOCTOU)

Index.Upsert was rewritten from SELECT-then-INSERT (which had a time-of-check-to-time-of-use race) to INSERT OR IGNORE followed by SELECT. Single statement, atomic at SQLite level. Distinguishes COW hit from COW miss by checking if junction tables are already populated (entities, domain). Two concurrent upserts for the same (path, blob_hash) no longer both enter the miss path and trip a UNIQUE constraint error. Delete was wrapped in a single transaction (read fact_id → delete branch_facts → check refcount → delete fact) so another thread cannot insert a branch_facts row between the refcount check and the fact delete. CreatePipelineSession wraps abandon-old + create-new in one transaction.
