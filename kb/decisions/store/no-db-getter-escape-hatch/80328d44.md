# Index.DB() and Service.DB() are DELETED — no escape hatch to raw *sql.DB

Both Index.DB() and Service.DB() getters are DELETED. There is NO public escape hatch to the raw *sql.DB. Replacements: (1) Add proper domain methods for what callers needed via DB (Index.LastCommitForPath returns commit hash for path, Index.CommitTimestamp returns committed_at for hash). (2) NewFactsIter takes *Index instead of *sql.DB. (3) Web test helpers that did raw INSERT INTO facts rewritten to use Index.Upsert(FactRecord{...}) via the public API. (4) Store-internal tests are SAME PACKAGE (package store) so they access idx.db / svc.db directly — no public getter needed. Anti-pattern (FORBIDDEN): adding a new DB() method or other raw-SQL escape hatch — if a caller needs raw SQL, add a proper domain method to Index/Service instead. The single exception is GitReader-style internal interfaces that already have access via package privilege.
