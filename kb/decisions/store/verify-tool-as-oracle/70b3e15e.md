# Verify is debugging tool plus test oracle for store invariants

Service.Verify(ctx, opts) returns an IntegrityReport that both the knomit-verify CLI and the invariant test suite use. Seven categories of checks: git-reachability (full walk from each branch ref, every tree entry resolves); commit-log (bidirectional parity between git history and the two-table commit index); facts-coherence (three-way branch_facts/facts/tree blob_hash triangle); embeddings-coverage (when embedder configured, every facts row has facts_vec row and vice versa); branches-table (SQLite branches table has exactly one row per git branch ref); graph-coherence (every facts row has cypher Fact node keyed by (path, blob_hash) and vice versa, catches graphSyncFact silent failures); fact-format (Warning, Deep:true only). Verify is never atomic across branches.
