# Verify is production debugging tool AND test oracle for 8 store integrity categories

Service.Verify(ctx, opts) returns an IntegrityReport that BOTH the knomit-verify CLI and the invariant test suite use. EIGHT categories (constants in internal/store/verify.go:59-66): (1) git-reachability — full walk from each branch ref, every tree entry resolves; (2) commit-log — bidirectional parity between git history and the two-table commit index; (3) facts-coherence — three-way branch_facts/facts/tree blob_hash triangle; (4) embeddings-coverage — when embedder configured, every facts row has facts_vec row and vice versa; (5) branches-table — SQLite branches table has exactly one row per git branch ref; (6) branch-facts-table — branch_facts integrity (added since the original 7-category design); (7) fact-format — Warning severity, Deep:true only; (8) graph-coherence — every facts row has cypher Fact node keyed by (path, blob_hash) and vice versa (catches graphSyncFact silent failures). Verify is NEVER atomic across branches — locks per branch, releases before next. Take repo offline for definitive results on a busy repo.
