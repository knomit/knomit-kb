# Verify is production debugging tool AND test oracle for 7 store invariants

Service.Verify(ctx, opts) returns an IntegrityReport that BOTH the knomit-verify CLI and the invariant test suite use. Seven categories: (1) git-reachability — full walk from each branch ref, every tree entry resolves; (2) commit-log — bidirectional parity between git history and the two-table commit index; (3) facts-coherence — three-way branch_facts/facts/tree blob_hash triangle; (4) embeddings-coverage — when embedder configured, every facts row has facts_vec row and vice versa; (5) branches-table — SQLite branches table has exactly one row per git branch ref; (6) graph-coherence — every facts row has cypher Fact node keyed by (path, blob_hash) and vice versa (catches graphSyncFact silent failures); (7) fact-format — Warning, Deep:true only. Verify is NEVER atomic across branches — locks per branch, releases before next. Take repo offline for definitive results on busy repo.
