# Verify is production debugging tool AND test oracle for all 7 store invariants

internal/store/verify.go Service.Verify(ctx, opts VerifyOpts) returns an IntegrityReport that BOTH the production knomit-verify CLI and the invariant test suite use. Seven categories (all Error-severity unless noted): (1) git-reachability — full walk from each branch ref to root, every tree entry resolves to blob/subtree; (2) commit-log — bidirectional parity between git history and the two-table commit index for each branch; (3) facts-coherence — three-way triangle branch_facts ↔ facts ↔ tree blob_hash consistency; (4) embeddings-coverage — only when embedder configured; every facts row has facts_vec row and vice versa; (5) branches-table — SQLite branches table has exactly one row per git branch ref; (6) graph-coherence — every facts row has a cypher Fact node keyed by (path, blob_hash) and vice versa (catches graphSyncFact silent failures); (7) fact-format — Warning, Deep:true only — every .md under kb/ parses as a valid Fact. Verify is NEVER atomic across branches (locks per branch, releases before next) — take repo offline for definitive results on busy repo.
