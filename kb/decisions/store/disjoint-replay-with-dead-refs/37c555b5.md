# Disjoint origin connect replays via cursor + dead-ref resolution (1-level only)

When two repos connect with DISJOINT histories (no shared commits), origin connect REPLAYS local facts onto remote: (1) branch agent/<hostname> from remote's default branch tip; (2) iterate local facts from SQLite in REVERSE-CHRONOLOGICAL order via cursor (NEVER bulk-load — ListAll loads into memory and is forbidden for this path), deduplicated by path so only the latest version of each fact is replayed; (3) for each fact, resolve DEAD REFS — if a local ref points to a fact that no longer exists locally (e.g. was subsumed), look up the dead fact's last version, extract its EXTERNAL refs (URLs, source files), graft them onto the referring fact, drop the dead local ref. If the dead fact has no external refs, just drop the dangling ref; (4) write fact into temp branch, commit (index builds incrementally). CRITICAL: dead-ref resolution is 1-LEVEL DEEP ONLY — do NOT recurse — preserves provenance without resurrecting retracted knowledge. Because the agent branch is created from the remote's default branch tip, the resulting branch is a DESCENDANT of the remote, which guarantees post-connect Sync() will find a common ancestor and work normally.
