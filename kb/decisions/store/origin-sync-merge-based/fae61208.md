# Agent branch reconciles via real git merge, NOT by replaying every commit

Origin sync was reworked from replay-based to merge-based reconciliation. reconcileAgent(agentBranch, strategy, mainRewound) dispatches: mainRewound=false (steady state) → mergeIntoBranch('main', agentBranch, StrategyLocalWins), producing FF / no-op / single merge commit — O(1) work regardless of how many commits main absorbed; mainRewound=true (origin/main force-rewound) → watermark-based replayOntoUpstream fallback so G6 scrub semantics still work on disjoint histories. Hash rewriting ONLY happens on the rebase path. The watermark is still seeded by all bootstrap paths but only consulted on the rewind branch. Push is unchanged (force-push agent branch — only this machine writes to agent/<host>). The rework fixed the O(N) re-replay disaster when a remote squash/rebase merge absorbed an agent's commits back to main (G9 regression test pins the fix).
