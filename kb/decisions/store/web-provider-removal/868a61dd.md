# W0g2 deleted factSubProvider: explainFact, incomingAtCommit, outgoingAtCommit, factLiveAtCommit and factExistsAt are package functions in internal/edge/web, and the fact sub-resource tests read a real store

W0g2 (PR #614, merged as 99e0d3a5; re-read there) deleted factSubProvider, defaultFactSubProvider and the storeProviders.factSub member (storeProviders now has 3 members: factReader, factWriter, origin). The old default bodies are package functions in internal/edge/web/handlers_fact_sub.go with the same bodies: ri.WithRead, a nil svc (repo not open) yields the zero value and a nil error, and a store error is returned unchanged. They are explainFact, incomingAtCommit, outgoingAtCommit, factLiveAtCommit and factExistsAt. The /commits sub-resource calls W0g1's logPaginated (handlers_commits.go). handleHALFact, handleCommitAnchoredFact and handleHALLensFact take (b, reader) only; factPresentAtCommitOr404, the dispatchers and the three sub-resource handlers lost their provider parameter. webInterfaceAllowlist went from 5 to 4 names: FactReader, FactWriter, originProvider, RefResolver.

TESTS: the sub-resource tests read a real store (newFactSubFixture and newFactCommitsFixture in handlers_fact_sub_test.go). Failure paths fail the read through index.Facade.SetReadFaultForTest (ReadExplainFact, ReadFactLiveAtCommit). 'Must not be called' checks count index.Overrides.Reads probes (FactLiveAtCommit, FactExistsAt, IncomingAtCommit, OutgoingAtCommit) and assert 0. The FactReader stub in the commit-anchored and lens sub-resource tests (tripwire and gate) was replaced in W0g3 (PR #615, merged as abcd5536) by ReadFact faults on the real store (kb/decisions/store/web-provider-removal/b3269a9a.md).

CONSEQUENCE: a new sub-resource test builds on newFactSubFixture or a real lens mount; it does not reintroduce a sub-resource seam.

DOES NOT MEAN: that every sub-resource failure path is pinned. IncomingAtCommit, OutgoingAtCommit, FactExistsAt and LogPaginated have no fault hook (W0a did not build them and no base test failed them through the stub). Nor that every branch argument is observable: see kb/gotchas/store/anchored-read-ignores-branch/2b146823.md for the reads whose branch is not. The per-fact /commits cursor repeat is a known store defect, not a web one (kb/gotchas/store-git/commitlog-path-filtered-cursor-repeat/bd527dbe.md).

UPDATE (12f, PR #630, merge 33eb0307; re-read there): the functions above are in internal/edge/web/api/kb/handlers_fact_sub.go, and handleHALLensFact is in api/kb/handlers_lenses_read.go. Two clauses describe the W0g2 state and are no longer true: (1) they return ri.WithRead's error as-is (a store that cannot be reached is an error answered 503 through httpx.WriteStoreError, not a zero value and a nil error); (2) handleHALFact, handleCommitAnchoredFact and handleHALLensFact take the URL builder ONLY, because W0g3 removed the reader parameter.
