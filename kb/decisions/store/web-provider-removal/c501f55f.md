# Deleting the 13 web provider interfaces ships as 9 serial PRs (W0a to W0i), the user merging each, with a shrinking web-declares-no-interface guard

USER RULINGS 2026-10-22 (follow Q3 of 2026-10-21, 'delete the 13 web provider interfaces'; the pluggable-provider design is described in kb/architecture/web/handler-providers-interface-injection/ae74d907.md and goes away). Recorded after W0a (PR #598) landed; W0b to W0i are NOT built.

OPTIONS for the ~60 failure-path tests (30 on the per-lens-mount) that injected errors through provider stubs: (a) widen index.Overrides so Reads errors on every read; (b) per-owner-package fail-only test hooks; (c) real failures only. CHOSEN (b), see the fail-only hooks fact (kb/decisions/store/web-provider-removal/, W0a): mustBeTest setters in the owner's testseams.go, inside the archtest B2 scope, for index, vocab, facts and remotesync. REJECTED (a): it would undo E8's deliberate observe-only narrowing (0272840a, 44ec3b17). REJECTED (c): closing the store can take the 503 acquire-refusal path instead of the 500 read-error path and lose coverage.

PR SPLIT, 9 PRs, serial, the user merges each: W0a owner fault hooks (done); W0b trivial deletions (BearerVerifier, gitHTTPProvider, branchesListerFunc/branchRootReaderFunc, completionsProvider, domainsProvider) plus an archtest 'web declares no interface types' guard with a shrinking, stale-key-failing allowlist; W0c stats/activity; W0d search/factsCollection; W0e motifs; W0f TopicLister; W0g FactReader/factSub/commits/RefResolver; W0h FactWriter; W0i originProvider and delete providers.go (allowlist empty). Plan section 5 step 12c no longer exports provider interfaces.

SCALE (approximate, measured at 6c0f1a78): 270 tests in about 38 test files, about 9-10k test lines; each interface had one production implementation (a zero-size default* struct in package web). RATIONALE: one interface and its tests per PR keeps each reviewable and keeps the allowlist shrinking monotonically. NON-SCOPE: this does not authorize deleting an interface in the same PR as another, nor widening index.Overrides; the sizes are a sizing estimate, not a property of the code.

PROGRESS: W0b landed (PR #600, merged as fa631358): BearerVerifier, gitHTTPProvider, branchesListerFunc/branchRootReaderFunc, completionsProvider and domainsProvider are gone, and the guard exists with a 12-name allowlist (kb/conventions/go/package-boundaries/web-no-interfaces/d36fa222.md). Names in the PR split above are plans, not rulings on later PRs; read the allowlist in test/archtest/web_no_interfaces_test.go for what remains.

PROGRESS: W0c landed (PR #602, merged as 58949ece): statsProvider and activityProvider are gone (kb/decisions/store/web-provider-removal/ W0c fact) and the allowlist is down to 10 names.
