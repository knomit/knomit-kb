# Store parent slimming: step 16 as a final PR, accept ~3.0k LOC after A-D, local OpenRepo/InitRepo stay in the parent, Due guard scope fixed in PR A

Ruled by the user 2026-10-20 after the store split (hier steps 05-11) left the parent package store at 29 non-test files / 4,590 LOC (counted as every non-_test.go file in internal/engine/store, children excluded), against the ~2.5k facade the hierarchy proposal projected.

OPTIONS AND CHOICES.
(1) Step 16, outside callers import store children directly instead of store.X re-exports. Options: not now (keep re-exports that have users); yes for the 9 importable children as a final PR E; per consumer later. CHOSEN: yes, as PR E after PRs A-D. Cost known up front: ~225 files outside store (96 production, 129 test) for ~590 LOC of seams; callers will mix spellings because the vcs, sessions and sqlite names are internal children and must stay store.X.
(2) Target size. Options: accept ~3.0k after A-D; push to 2.5k with PR E; move Service contract docs into the children (~300 LOC). CHOSEN: accept ~3.0k after A-D, with E taking it to ~2.5k; each Service method keeps its contract doc. RATIONALE: methods on *Service can only be declared in package store, so ~1.1k LOC of service_*.go forwards plus seams, replay.go and interfaces.go cannot move; the proposal's number did not count them.
(3) Local repo creation. Options: all of repo.go moves to remotesync; or OpenRepo/InitRepo stay in the parent and only the remote bootstrap moves. CHOSEN: local OpenRepo/InitRepo stay in the parent; only the remote bootstrap (InitFromRemote, InitSubscription, CloneFrom and helpers) moves to remotesync in PR C. RATIONALE: remotesync should not own repos that have no remote; local construction is the single site that builds the one *vcs.Repo.
(4) TestDue_SweepNotReachableFromWritePath skipped every directory named web, leaving internal/edge/web outside the scan. CHOSEN: fix in PR A by skipping only the repo-root web/ frontend.

PR ORDER: A (dead code, parent-only test helpers, Due guard) then B (consensus_branch.go and service_sync bodies to remotesync), C (remote bootstrap), D (merge/facts/vcs orchestration and test seams), D2 (pure-unit tests into children), E (step 16).

NON-SCOPE: this does not authorize removing a re-export that has an outside user before PR E, nor moving any Service method out of package store, nor loosening a source-scanning guard to make a move pass.
