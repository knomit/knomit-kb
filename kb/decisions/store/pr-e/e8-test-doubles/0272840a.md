# E8 replaced the synthesize search-index test doubles by seeding real facts and graph edges in a real store; index.Overrides only observes, fails and wraps, plus one clustering-edge replacement

DECISION (PR E8, refactor/store-e8-interfaces, #580, merged into dev as 0c24a7ab; re-read at 0c24a7ab). When E8 deleted the store's restating interfaces, the synthesize tests lost their hand-written fakes of them. OPTIONS: (a) a real store with seeded data (CHOSEN for every similarity-graph, document-frequency, reverse-dependent and FactExistsAt case); (b) per-method canned-answer hooks in the owning child (built first, REJECTED in review: it was a hand-written gomock restating six provider signatures whose real store was never consulted, and it lost the 'any other call fails' property of the 28-method gomock fakes); (c) a consumer interface in synthesize (banned by kb/conventions/go/package-boundaries/no-facades/44ec3b17.md).

WHAT EXISTS (internal/synthesize/graph_env_test.go): graphEnv seeds facts in one BatchWriteFacts commit, DERIVED_FROM edges from the facts' real refs, SIMILAR_TO edges through index.GraphMergeEdgeForTest on storetest.RawDB, and document frequencies from the facts' own entities, domains and motifs. guardReads installs a strict read policy (Allow, AllowAll, Fail, and a readLog). overridesOf composes the Search wrapper, the SubgraphEdges replacement and the Reads hook into one index.Overrides, because SetOverridesForTest replaces the whole set. Fixture rule: a bare path such as a.md is not a fact (only kb/... paths index), so seeded fixtures use kb/a.md.

REMAINING OVERRIDES AND WHY: Reads (observe, fail, inject); Search (capture the context in TestDedupCluster_RespectsContextCancellation, return canned scored hits in dedup and reflect tests where no embedder exists, record calls); SubgraphEdges (fixes a community PARTITION for the BridgeComponentReport and BuildBackwardBridges tests while the same SIMILAR_TO table holds cohesion edges ACROSS those communities, and one real table cannot be both; also captures the node order in cluster_determinism_test).

STRICT BY DEFAULT: newGraphEnv installs an empty read policy, so graphEnv.idx() fails the test (t.Errorf 'unexpected read of <method>') on ANY index read until the test widens it with .allow(...), .allowAll() or guardReads. The strict check is applied before an injected Fail error is returned. guardReads refuses (t.Fatalf) a Fail entry for a read that cannot hand an error to its caller: only SimilarityAdjacency, ReverseDependentPaths, TokenDF and SubgraphEdges can fail. internal/store/index/probe_guard_test.go asserts all 28 public reads of FactQuery, GraphStore, HistoryQuery and MethodologyMatcher call their probe, so every read can be seen at all (kb/architecture/store/index-child/2342682b.md).

FALSIFIABILITY (sabotage run by the E8 worker against the E8 head, restored with git restore; reported in the PR, not re-run by the curator): an extra LiveFactCount read in buildScoredBridges before bridgePathCommunities fails 13 tests under the strict default (the same 13 the 28-method gomock fakes failed on the merge base; it failed only 1 before the default became strict). A SubjectLabelDF read added before the motif-free short circuit fails TestBuildMotifBridges_MotifFreeCorpusDoesNoWork; the same read before the effort gate fails TestBridgeSeeds_NormalEffortEmpty and TestBuildScoredBridges_EffortNormal_Nil. ReverseDependentPaths returning empty fails TestDerivationGap_ThreeMembers_OnePairLinked; TokenDF returning 1 fails TestSpecificity_DF4_Returns0_25 and TestScoreBridgeCandidate_CrossCommunity_Kept; SimilarityAdjacency returning no edges fails TestBuildScoredBridges_SmallCohesiveCrossCommToken and TestBuildFilteredBridges_TwoDisjointClusters_TwoBridges; FactExistsAt returning false fails TestApplyReflect_AppliesReinforce; ignoring the SubgraphEdges replacement fails TestBridgeComponentReport_CrossCommunity_Kept; ignoring the Search wrapper fails the TestDedupCluster_* and TestNeighborKinds_* set; dropping probe errors fails the *ErrorPropagation* and *Error tests.

MISREADING: a strict policy that lists Allow reads is only as strict as its list; a test that needs every read allowed uses AllowAll and should say so. Nor does the Overrides hook let a test fake graph answers: seed real data.
