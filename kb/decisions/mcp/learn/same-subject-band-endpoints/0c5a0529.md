# A similarity BAND's two endpoints must be calibrated against the SAME distribution — [SimilarTo, Dedup) mixed docDocAll with docDocSame and was wrong at every model

The same-subject band was first specified as `[SimilarTo, Dedup)`. That is incoherent at EVERY model, not merely mis-tuned at one: `tools/calibrate` derives `Dedup` and `ReflectNovelty` from `docDocSame` (distinct facts in the SAME category) but `SimilarTo` from `docDocAll`. An interval whose endpoints come from two different populations does not describe a region of either.

It looked sane only because the nomic-era numbers happen to bracket plausibly: `[0.60, 0.92)`. On the SHIPPED model (embeddinggemma) the same two fields give `(0.18, 0.82)`, while that model's calibration records distinct same-category pairs at mean 0.48 and p99 0.77 — so nearly every unrelated pair falls inside. `SimilarTo` is by its own definition a floor applied ON TOP OF a top-K nearest-neighbour cap, never a standalone floor, which is the second reason it cannot bound a band on its own.

The band is `(ReflectNovelty, Dedup)`: `(0.69, 0.82)` on embeddinggemma, `(0.85, 0.92)` on the nomic fallback. Both endpoints come from `docDocSame`, and `ReflectNovelty` is already a REJECTION floor ("too similar to an existing one"), which is the right semantics.

CONSEQUENCE: before using two `params.Thresholds` fields as the ends of one interval, check in `tools/calibrate` which distribution each was swept against. Two fields being cosines on the same model is NOT sufficient; they must answer the same question about the same population.

Residual, deliberately accepted: distinct p99 (0.77) sits ABOVE `ReflectNovelty` (0.69), so a few percent of genuinely distinct pairs can still land in band. The non-generic-entity anchor and `distinct_from` bound that, and the refusal log events make the real rate measurable rather than assumed.

WHAT THIS DOES NOT MEAN: not "`SimilarTo` is a bad threshold". It is correct for the job it was calibrated for — drawing SIMILAR_TO graph edges under a top-K cap. The defect was using it outside that job.
