# Context merges: learn dedup and review pairwise dedup keep the WINNER's whole map; prune keeps only keys every member carries with the same value AND the merged topic declares; distill/reflect/discovery carry none; F20 merges two versions per key; judges see context only as JSON data

Follows the expires merge rule: a merge never invents a value and never pools values from facts that disagree.
- learn dedup (mergeFacts): merged.Context = the winner's map, copied whole. When the EXISTING fact wins and the caller sent context, the learn result says "context not applied; set it with knomit_update" (contextNotAppliedNotes, mirroring expires).
- review pairwise dedup (dedupCluster) re-serializes the parsed winner, so the winner keeps its own map by construction and none of the loser's keys appear.
- review prune merge (agreedContext): the merged fact is NEW. It carries only the keys every member carries with the SAME value AND that the merged fact's own topic allows (Ontology.ContextKeyAllowed — the judge picks the directory and review runs no other ontology check). Each key not carried is named (never its value) in a warn. An unreadable member, or no ontology, means nothing is carried.
- distill, reflect, discovery: fact.NewFact, no context.
- F20 MergeVersions (mergeContext): two versions of ONE fact merge per key, three-way, and absence is a value. A key one side changed (including deleting it) takes that side; a key both changed differently goes to the strategy's winner and is recorded in Decided as "context.<key>" — names only, so the Knomit-Merge/Conflict trailer never carries a value. A version whose map ParseFact dropped is "lossy", so the site falls back to its side-pick.
The asymmetry is deliberate: dedup joins two DIFFERENT facts, and mixing their keys would describe neither.

Judges see context as DATA only: factForLLM.Context (omitempty) inside the work item's facts JSON for prune and distill members, cousins, the in-flight refresh and the restatement shortlist; hypothesize seeds marshal fact.Fact; bridge and discovery seeds and freshly distilled facts carry none. No prompt template or Go prompt builder interpolates it (TestPrompts_NeverInterpolateContext), and the pager counts its bytes (TestFactPages_CountContext).
