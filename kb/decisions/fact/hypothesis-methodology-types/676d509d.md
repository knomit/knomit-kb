# hypothesis and methodology types are FABRICATED — distinct from the 7 observed/derived types

Two new epistemic types: 'hypothesis' (a prediction derived from synthesis facts; carries inherent uncertainty) and 'methodology' (a reasoning-process lesson from hypothesis outcomes, lives in kb/meta/reasoning/). Both are FABRICATED — distinct from the existing 7 types (observation, concept, process, principle, pattern, reference, synthesis) which represent observed reality or sound derivations from it. CRITICAL: knomit_learn batch type validation REJECTS batches mixing observed types with fabricated types in a single call — a single cognitive operation cannot span both. TYPE SAFETY INVARIANTS: (1) hypotheses must NOT be evidence for other hypotheses; (2) distill must NOT synthesize from hypotheses; (3) RAPTOR ScopedCluster EXCLUDES hypothesis-type facts via ExcludeTypes; (4) distill of methodology-only inputs MUST preserve type=methodology; (5) confidence inherits on promotion, NOT recomputed from scratch; (6) embeddings are type-blind (title+body only) so dedup MUST be type-aware to compensate; (7) Upsert's default type='observation' MUST NOT silently downgrade hypothesis/methodology; (8) review dedup pairs: observations ALWAYS win over hypotheses regardless of confidence.
