# Public API is fact-level (ReadFact/WriteFact/DeleteFact); generic file methods are unexported

*store.Service exposes a FACT-LEVEL API to external callers — the generic file-level methods are UNEXPORTED. Public: ReadFact(ctx, branch, path, *ReadFactOpts), FactExists, WriteFact, DeleteFact, BatchWriteFacts. Internal: readFile, writeFile, deleteFile, batchWrite, readFileWithHash, readFileAtCommit, readFileLastCommit, fileExists, Grep (deleted as unused). ReadFactOpts unifies four read modes via opts: nil = HEAD, &{WithHash:true} = HEAD with blob hash, &{AtCommit:hash} = specific commit, &{BeforeCommit:hash} = last version before commit (retract walk). ReadFactResult returns Content + optional BlobHash + optional FromCommit. WriteFactResult returns CommitHash + BlobHash. DeleteFact returns (commitHash, error) — the retract tool needs the hash. The internal gitReader interface uses UNEXPORTED method names — enforces same-package-only implementations (only *Service can satisfy it).
