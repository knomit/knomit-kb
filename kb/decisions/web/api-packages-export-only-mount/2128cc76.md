# DECISION (2026-10-24): each internal/edge/web/api package exports one Mount with positional parameters and no exported Deps type, and owns its route table; origins.Mount owns the session manager, so Server.SessionManager goes away

Rulings by the user on 2026-10-24 for the web split (step 12), enforced in code from 12a (PR #621, merged on dev as 7dccaa09) by guard M, kb/invariants/testing/web-api-exports.

DECIDED: (1) Resource packages (api/kb, api/manage, api/jobs, api/origins) each export ONE func Mount and keep their own route table, so about 4 handler exports are needed instead of about 102. The route table leaves router.go for each package; router.go just mounts them. (2) Mount takes positional parameters; there is no exported Deps type. If a package needs more than about 5 parameters, its PR flags that to the user. (3) api/origins' Mount creates and owns the session manager, including its cleanup; the Server.SessionManager field is removed (done in 12d, PR #624; the test files that set it moved to origins). (4) Consequence: every api/* package exports exactly Mount and every per-package allowlist in guard M is empty.

OPTIONS REJECTED: exporting about 102 handlers from the resource packages; an exported Deps struct passed to Mount; keeping the session manager as a Server field with an api/origins type exported for server.go.

BUILT vs PLANNED. At 7dccaa09 (12a, PR #621) only the guards (M, R, F, generalised W) were built. At 01e405e4 (12d, PR #624, merged on dev; re-read there) also built: internal/edge/web/api/origins, whose only export is func Mount(r chi.Router, rm *repos.Manager, agentBranch string) with no results and which creates and owns its session manager; its route table left router.go and router.go mounts it; Server.SessionManager is gone, with no SessionManager or Shutdown reference left in server.go or internal/app. BUILT in 12c (PR #627, merge 97ae7c19, re-read there): internal/edge/web/api/jobs, whose only export is func Mount(r chi.Router, rm *repos.Manager, llmAdapter llm.LLMAdapter) with no results; the job route table left router.go and router.go calls jobs.Mount(r, s.Manager, s.LLMAdapter); the job registry ruling is recorded in kb/decisions/web/jobs/taskhub-is-the-only-job-record/c514ec1b.md. BUILT in 12e (PR #628, merge a8bf8d7a, re-read there): internal/edge/web/api/manage, whose only export is func Mount(top, repoOuter, repo, branch, lens chi.Router, rm, agentBranch, embeddingsEnabled, expiryDays, operator) with no results; the user ruled that router.go builds the shared route tree and the subrouters are passed in (kb/decisions/web/route-tree-built-by-router/ab86ee4f.md), so for api/manage the 'owns its route table' wording in DECIDED (1) holds for the routes it registers, not for the subtrees or their middleware. STILL PLANNED, not built: api/kb (12f). Until each lands, guard M only logs the package as pending; after 12f pending becomes an error. 12d, 12e and 12f are not plain moves, so each gets an Opus review and a user merge.

NOT RECORDED HERE: the ruling on the job registry (it is in kb/decisions/web/jobs/taskhub-is-the-only-job-record/c514ec1b.md).

DOES NOT MEAN: that all four api packages exist. At a8bf8d7a api/origins, api/jobs and api/manage exist; api/kb does not (12f). Server.SessionManager, by contrast, IS already gone.
