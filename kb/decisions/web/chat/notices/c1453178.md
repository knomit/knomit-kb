# The price-tier warning line has no 'New chat' link and no hover sentence (user, 2026-11-09: a new chat starts uninitialized, so the link was useless; the line is enough); the context-full line keeps its New chat action

TurnNotices draws the price-tier warning (testId chat-notice-price) as ONLY the line: '<used> of <tier>' then '<model>'s higher price tier is next (<mult>×)' — text unchanged. It passes no `action` and no `title`, so there is no 'New chat' button and the server's sentence ('This chat is nearing … Start a new chat to save.') is no longer a tooltip on it. The fallback branch (a warning with no warning_info) also lost its action and title; its visible text is still the server sentence.

What stays, because other callers use it: the context-full notice (chat-notice-full, 'Chat is full · … · New chat') still takes `onNewChat`, so ChatPanel.onNewChat, ChatFacet's onNewChat wrapper and NEW_CHAT_ERROR ('New chat hit an error'), App's onNewChatLike, and NOTICE_NEW_CHAT all remain. Do NOT read this decision as 'remove New chat from notices' — it is the price-tier line only.

The server still sends the full warning sentence in the event; only the UI stopped showing it.
