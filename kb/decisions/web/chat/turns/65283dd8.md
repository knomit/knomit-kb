# The chat activity summary wording lives in one chatCopy function; a turn footer's per-row cost is not shown because the server sends one summed cost and no prices

Chat UX v2 PR 1: activitySummary(calls) in chatCopy.ts words the collapsed activity line (Bound to <t> / searched N× in <t> / read N facts / used N tools, joined with ' · '); a call with no wording counts toward 'used N tools'. The cost hover card shows the four token counts but NOT per-row costs: the snapshot has one summed cost_usd per turn and /chat-providers has no prices until the start-screen PR, so a split would be invented. Its totals (this turn, session = sum of turn costs) are real. A live tool_call event carries no arguments yet, so a live row shows no key argument and the collapsed line falls back to the summary until a snapshot read. Not meant: the missing per-row costs are a data gap, not a design choice to hide them.
