# The chat activity summary wording lives in one chatCopy function; a turn footer's per-row cost is now shown, computed by the server (see the cost-split fact)

Chat UX v2 PR 1: activitySummary(calls) in chatCopy.ts words the collapsed activity line, and is still the ONE place it is worded. It now names calls by their titles, counted per (title, target) and joined with ' · ' (e.g. 'Bind demo-kb · Query 2× in knomit'); the earlier wording 'Bound to <t>', 'searched N× in <t>', 'read N facts' and 'used N tools' is gone (see kb/conventions/web/chat/activity-line/dee02e91.md). The cost hover card shows the four token counts but NOT per-row costs: the snapshot has one summed cost_usd per turn and /chat-providers has no prices until the start-screen PR, so a split would be invented. Its totals (this turn, session = sum of turn costs) are real. (Superseded: a live tool_call event now carries its arguments when they are no larger than maxApprovalArgs, in internal/edge/web/api/chat/chat.go, so a live row can show its key argument; an oversized argument set is still omitted from the live event and appears on the snapshot read.) Not meant: the missing per-row costs are a data gap, not a design choice to hide them.

Superseded in part: the per-row cost is no longer withheld. The server now sends the turn's cost split by token kind (cost_rows) and the card shows it; see kb/decisions/web/chat/turns/268482d1.md. Only the claim that activitySummary in chatCopy.ts is the one place the activity line is worded still stands; the wording itself is superseded by the titles rule in dee02e91.
