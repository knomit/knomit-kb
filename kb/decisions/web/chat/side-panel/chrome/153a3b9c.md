# The chat side panel's footer no longer shows the 'Esc close' hint (user, 2026-11-09); Esc itself is unchanged, and a result entry's footer holds only Find ⌘F

PANEL_KEY_CLOSE was removed from chatCopy and the keycap from ChatSidePanel's footer. The footer now shows, for a result entry with a JSON view mounted, one button: magnifier, 'Find', kbd '⌘F' (FIND_LABEL, FIND_KEY), which opens that view's find bar (ChatResultPanel reports the view's handle through onFinder). For a materialize result, a fact or a commit the footer is empty.

Esc behaviour is the same as before: a running turn takes Esc for Stop; otherwise Esc closes the panel unless focus is in a field. Consequence: do not read the missing hint as 'Esc no longer closes the panel'. The shortcut label is ⌘ on every platform, as the app draws ⌘K and ⌘B; the key itself is CodeMirror's Mod-f (Cmd on macOS, Ctrl elsewhere).
