# The chat start screen selects a model on a card click and creates nothing; only Enter or Start chat creates, with the first message; unavailable and no-tools models are shown dimmed with the server's reason; the Default is the first listed model that can be started

ChatStartForm: a card is a radio; usable(m) = available && tools. The Default (tag and preselection) is the first listed usable model across providers, so when every Anthropic model is unavailable the Default is the first Ollama model. A model that is unavailable (provider says so: no key, not pulled, unreachable) is dimmed and unselectable with the server's reason, not hidden: hiding them left the picker empty with no hint why. Prices and windows on a card come from /chat-providers only; costTier (chatState.ts) is $ under $1/MTok input, $$ under $3, else $$$, from the first tier. Composer: Enter (not Shift+Enter) or Start chat, with non-empty text. Does NOT mean Default is the first model in config order when that one is unusable.
