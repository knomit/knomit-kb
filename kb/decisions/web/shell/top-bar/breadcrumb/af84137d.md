# The top bar reads knomit / target | tabs on one row (knomit | server tabs over the server pages); the dropdown-looking label in the Browse toolbar is the branch picker, not a host picker

Row, left to right: rail toggle, the word mark (`bar-brand`: green mark plus 'knomit'), a `/` separator, the target crumb (`target-label`, with `target-label-chip` for states such as archived or mount missing), a 1px divider (`bar-divider`, drawn only when there are tabs), the facet tabs (Browse, Activity, Settings, as `facetsFor` returns), the gear. Over the server pages the target crumb and separator are omitted: `knomit | Fleet Logs Authorizations`, with no 'Server' word and no second crumb.

History: PR G first drew a host crumb (`localhost:port`) in place of the word mark; the user directed 2026-10-12 that the bar read literally 'knomit / <repo>' (GitHub-style), so the host crumb, `serverHost()` and the `RAIL_WIDTH` alignment were removed. The crumb flows after the word mark and does NOT line up with the content column under the rail.

WHAT THIS DOES NOT MEAN: no host or API URL appears anywhere in the bar. The `<host> v` dropdown at the left of the Browse toolbar is the BRANCH picker (`toknomitr-branch`; the agent branch is `agent/<host>-<fp8>`), so the host name there is not a server picker and the bar's crumb is not a duplicate of it.
