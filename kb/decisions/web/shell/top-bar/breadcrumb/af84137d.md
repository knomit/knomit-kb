# The top bar reads knomit / target | tabs on one row (knomit | server tabs over the server pages); the dropdown-looking label in the Browse toolbar is the branch picker, not a host picker

Row, left to right: rail toggle, the word mark (`bar-brand`: green mark plus 'knomit'), a 1px vertical rule (`crumb-sep`; it was a `/` before 2026-11-06), the target crumb (`target-label`, with `target-label-chip` for states such as archived or mount missing), a 1px divider (`bar-divider`, see the divider rule below), the facet tabs (Browse, Activity, Settings, as `facetsFor` returns), the gear. Over the server pages the target crumb and separator are omitted: `knomit | Fleet Logs Authorizations`, with no 'Server' word and no second crumb.

History: PR G first drew a host crumb (`localhost:port`) in place of the word mark; the user directed 2026-10-12 that the bar read literally 'knomit / <repo>' (GitHub-style), so the host crumb, `serverHost()` and the `RAIL_WIDTH` alignment were removed. The crumb flows after the word mark and does NOT line up with the content column under the rail.

WHAT THIS DOES NOT MEAN: no host or API URL appears anywhere in the bar. The `<host> v` dropdown at the left of the Browse toolbar is the BRANCH picker (`toknomitr-branch`; the agent branch is `agent/<host>-<fp8>`), so the host name there is not a server picker and the bar's crumb is not a duplicate of it.

Update 2026-11-06 (feat/chat-ux-fidelity): the slash is gone for every target kind. crumb-sep is now a 1px #1e1e1e full-height vertical rule between the word mark and the target label, the label is weight 500 (was 600). Repo and lens bars changed with it, to match the chat mockup. (The divider rule is the one in the next paragraph; an earlier version of this note said the divider was server-pages-only, which is wrong.)

Crumb colour (review 2026-11-06, from mockup.html computed styles): only the chat DRAFT 'New chat' title is amber #e8c27a. An OPEN chat's title is cream #f1e6cc (weight 500) with the provider mark in amber (mockup app2). The 18px bar-divider hairline between the crumb and the tabs stays for repo, lens and fleet bars and the server pages (TopBar draws it when there are tabs and the target is not a chat, or when a server page list is non-empty); a chat's bar has none (the mockup's chat frames put the tabs right after the title).
