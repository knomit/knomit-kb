# The archived repo's danger-zone button reads 'Purge <name>...' rather than the spec's 'Purge...'

Context (PR E verdict, deviation 9): the spec says 'Purge...'; the built button reads 'Purge <name>...' (`Purge {info.name}...` in ArchivedSettings). Purge requires typing the name, and naming the target on the button is clearer on a page that may be reached by a rail pick.

Choice: keep the longer label, cosmetic, CONFIRMED by the user on 2026-10-12 ('ok').

WHAT THIS DOES NOT MEAN: the confirmation still requires the typed name; the label does not replace it.
