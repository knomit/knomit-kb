# The origin-session idle sweeper runs only while the manager holds a session; since PR #626 the manager's own lifetime (Mount's ctx) removes sessions and their run on shutdown

Options were: start the cleanup goroutine in Mount (lives forever; one leaked goroutine per router a test builds), start it lazily with sync.Once on first Create (lives forever after), or tie it to a context (none exists at Server.Handler()). Chosen: the sweeper runs only while the manager holds at least one session. Create stores its session and THEN calls ensureSweeper, which starts the goroutine when none is running; cleanupLoop exits on the first tick (every cleanupInterval, 60 s) after which the map is empty. The exit check (stopIfEmpty) and the sweeping flag are under the manager's one mutex (sm.mu; the former sweepMu was folded into it in PR #626), so a concurrent Create is never left unswept. Expiry is unchanged (sessionExpiry, 10 min idle, checked every 60 s). A manager with no sessions owns no goroutine, so a dropped one leaks nothing.

The exported Shutdown and Server.SessionManager were removed in PR #624, which left session folders uncleaned on shutdown (a known defect at that point). FIXED in PR #626 (merge c3c293b0): origins.Mount takes a ctx, and when it ends (App.Close ends it first) the manager retires every session, waits for those in use to finalize, then removes its run directory and lock; stale runs of dead processes are reclaimed at the next start. See kb/architecture/web/origin-sessions/57c881e2.md (wiring) and kb/invariants/web/origin-sessions/8bab8ef0.md (runs and locks). DOES NOT MEAN: that the idle sweeper now runs for the process's life. It still runs only while the manager holds a session; the lifetime cleanup is a separate path. Also DOES NOT MEAN cleanup is guaranteed at exit: it is asynchronous, so a process exiting right after Close can leave its run for the next start to reclaim.

Tests that create sessions point TMPDIR/TMP/TEMP at t.TempDir() (isolateOriginSessionTemp) or drain the manager (origins tests).
