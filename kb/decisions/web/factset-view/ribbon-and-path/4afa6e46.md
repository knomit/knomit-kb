# FactSet unit ribbon + sticky section path (user, 2026-11-03, from book design §5; supersedes Q-UI8's numbered unit heading): the unit number sits in a ribbon in the gutter on the root's row, the heading is the title only; the path reads 'unit X of N · <root ≤28> › … › <current>' on ONE line; a Recent list longer than the FactSet gets a notice

ORIGIN: the user's book design (plan book-materialize-design.md §5, 'Unit start = ribbon in the gutter' and 'Sticky path' bullets; prototype notes items 2 and 5). Q-UI8 had shipped numbered unit headings with a 2px rule instead (#710); the user ruled on 2026-11-03 to follow the book design. Built in PR #738 (branch feat/factset-ribbon-path).

RIBBON:
- A FactSet unit root (Section with fs and td 0) renders `fs-ribbon` inside its gutter, holding fs.unit. The heading has NO number. Sections inside a unit keep their numbers.
- Width = 10 + 6.6px per digit (ribbonWidth, the prototype's numbers: 16.6 / 23.2 / 29.8px for 1 / 2 / 3 digits). 6.6px is 0.6em of the 11px mono font.
- In the 44px gutter the ribbon ends where the ticks end (the gutter's 12px padding, 32px free). In the 34px narrow gutter (<1100px) the root's gutter padding is 3px (31px free), so '130' fits both.
- The 2px unit rule is gone; units keep margin-top 18px.
- A lens unit root keeps the repo name as the FIRST item of its meta line, under the title-only heading (the master asked the worker to choose; this was the choice, reported in #738).

STICKY PATH:
- The single-fact view's path component (SectionPath, midTruncate, clipTitle, pathBudget in materializeOptions.ts) is shared; the FactSet path is built by fsPathTo (factsetAnchors.ts) from node.parent within the unit.
- The unit root is always first, clipped to PATH_UNIT_CHARS = 28, unnumbered. The current section is always last. Middle truncation drops only ancestors between them as one '…'. Others are clipped to 30. The budget follows the pane width minus the lead.
- At the unit root the path is the root alone.
- PROGRESS IS MERGED: the lead of the path line is 'unit X of N' (the unit at the top, ruling unchanged; data-testid fs-progress). It is no longer in the bar's meta row. The design's '5/12' form is superseded by that wording.
- Path item clicks scroll to the section and record NO Back origin.

RECENT BEYOND THE FACTSET (ruling (c)): Library pushes the Recent list's server total (the header's data-count) into factsetView.setListTotal (undefined for every other list). FactSetView shows a PLACEHOLDER notice 'Showing the first {units} of {total} results.' when listTotal > env.units.

CONSEQUENCE: do not reintroduce a number in a FactSet unit root's heading, or a second progress line in the bar. Change the path in SectionPath/materializeOptions, not with a FactSet-only copy.

WHAT THIS DOES NOT MEAN: link stub headings are unchanged (ruling 4, meta line kept). The single-fact MaterializeView keeps its own path form: no progress lead, and its root clipped to 30 like any title.
