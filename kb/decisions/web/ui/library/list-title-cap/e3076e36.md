# Browse list titles are capped by character count (120) in EntryRow; the detail heading is not capped; LensFactRow and ChronoRow ellipsise in CSS instead

Decision (user ruling 2026-10-29): fact titles in the Browse list are capped by CHARACTER COUNT, not by CSS line clamp. The master picked 120, which is about three lines at the list's width.

Scope: EntryRow (web/src/Library.tsx), which serves both the per-repo list and the lens tree, calls clampTitle(fullTitle) for non-directory rows. The fact detail heading is NOT capped. LensFactRow (flat lens union) and ChronoRow (Recent) are not clamped: they are single-line rows that ellipsise with CSS text-overflow, so they never wrap.

Consequence: when adding another list that wraps titles, use clampTitle; when it is a nowrap single line, CSS ellipsis is the chosen mechanism. Do not cap the detail heading. The contract of the clamp itself is in the clampTitle contract fact.

Introduced by PR #679; edge cases fixed by PR #681.
