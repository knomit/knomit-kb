# knomit's OAuth issuer has NO Dynamic Client Registration (RFC 7591): no /oauth/register, no registration_endpoint advertised — because the one client it was for, Claude Code, uses CIMD whenever the issuer advertises it, and a public unauthenticated registration endpoint would be attack surface with no consumer

OPTIONS (F19 phase 3b, master ruling R1, 2026-09-24): (a) build DCR as the design said, as 'the fallback Claude Code needs today'; (b) drop it.

CHOSEN: (b). The design's premise was measured false. Q4 of the phase 3b worker priming ran Claude Code 2.1.281 against a throwaway `knomit serve`:
- With CIMD advertised (3a advertises client_id_metadata_document_supported: true), Claude Code sends client_id=https://claude.ai/oauth/claude-code-client-metadata and never calls /register.
- It fell back to DCR only when a rewriting proxy HID the CIMD advertisement and advertised a registration_endpoint, and only for a server it had no cached client for (a server it had logged in to before kept the cached CIMD client_id although the metadata no longer advertised CIMD).
That matches the MCP 2026-07-28 priority (pre-registered, then CIMD, then DCR; kb://bc6eac5f37df/kb/conventions/ai/agents/tools/mcp/authorization/client-registration/00fd386c.md), which also demotes DCR to a compatibility fallback.

WHAT BLOCKED CLAUDE CODE WAS NOT REGISTRATION but redirect matching: it presents http://localhost:<random>/callback. That is fixed by making localhost a loopback any-port host (kb/invariants/oauth/authorize-errors-and-pkce/140c9ec0.md), which serves CIMD and pre-registered clients alike.

WHY NOT BUILD IT ANYWAY: /oauth/register would be public and unauthenticated on the listener a reverse proxy exposes; every bound it needs (row cap, expiry, consumed-row retention, text safety, self-asserted client_name marked as such at consent) is surface kept for no client that exists.

CONSEQUENCES: the AS metadata carries no registration_endpoint; oauth.Resolver resolves pre-registered then CIMD, else invalid_client. A client that ONLY speaks DCR cannot connect; the operator pre-registers it in [[oauth.client]].

REOPEN WHEN: a real client needs DCR and cannot use CIMD or a pre-registered id. The captured Claude Code DCR body (application_type native, redirect http://localhost:<port>/callback, token_endpoint_auth_method none, plus scope, response_types, client_name) is recorded in the phase 3b worker notes as the fixture for that day.
