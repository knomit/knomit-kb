# The motif vocabulary is a FOURTH summary-panel block ('Shapes'), not a nav entry — and client-absence is a distinct state beyond resolved/loading/error

Options: a nav destination vs a fourth block beside Domains/Entities/Types in the summary panel. The block won via the ways-of-looking invariant: motif vocabulary is per-repo (no cross-mount cluster identity), so a nav entry would go dark whenever a lens is selected — 'an entry live for two of the four things above it is a feature with a switch, not a way of looking.' The block borrows the sibling grammar (ranked rows, share bar, overflow row opens the full-width browser, pick closes and adds a chip→pivot) but NOT the data source: motifs are deliberately out of /stats, which is also why each row can show a definition and the sibling columns cannot.

Shipped particulars (PR #177): singleton tail folded into one plain-text band (36 of 73 clusters here — the modal case — not N rows of empty bars); health strip authored-facts-only and NEVER narrowed by the search, while the header count IS narrowed — the contrast is stated in the UI; search reaches names AND definitions with placeholder 'Search names and meanings…' (the latency visibly buys what sibling boxes can't do); singleton pivot suppressed ('only this fact', plural grammar via carrierLabel so '1 carriers' is unrepresentable); browser search/picker row carry full three-state treatment (a failed load must never render as an empty vocabulary — that would claim the corpus has no shared shapes).

The /explore lesson: the vendored read-only build swaps only api.ts, so `typeof api.motifs !== 'function'` is the seam — and CLIENT-ABSENCE is a fourth state distinct from error: the Shapes block and picker row absent themselves without layout holes rather than erroring, because reporting a fault in a build working as intended would be false. The pivot survives there (filtering is navigation, not an edit); ShapesBlock wraps the CALL not just the promise, so a synchronously-throwing client cannot take down a dashboard whose other three blocks don't depend on motifs.
