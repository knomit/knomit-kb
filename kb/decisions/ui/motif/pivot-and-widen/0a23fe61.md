# The pivot's subject is PATH SEGMENT 3 (never the domain field), its widen rungs carry measured deltas and render inert when empty, and the shape-heading appears only at exactly one motif chip with no free text

Three bindings/behaviours settled for the landed pivot (Library state after clicking through a motif), all shipped in PR #177:

1. SUBJECT = the fact path's third segment (kb/<topic>/<SUBJECT>/…), explicitly NOT the domain field: domain[0] diverges from it on 209 of 1,183 facts (18%), is an arbitrary pick from a multi-valued field (mode 3 domains, up to 7), and is absent on 82 facts; using ALL domains gave 53 distinct labels over 26 carriers — more variety than facts, inverting the spread indicator. motifSubject.ts also strips the kb://<id12>/ lens prefix first, or every lens row would shift by one segment. The spread summary uses whole-names-or-none + '+N more', computed from the full landed rows, never the capped carriers[] preview.

2. The widen control (exact→stem→token-2) shows each rung's MEASURED delta before the click; an empty rung renders inert (grey, not a button) — on a young vocabulary stem≡exact everywhere (stem differs only where a judge merged clusters; this corpus had 0 merges of 73), and a dead-looking control reads as broken, poisoning trust in the pivot beside it. Nothing is hard-coded (corpus-property-constants principle): stem's delta derives FREE from the already-fetched aliases[] (any method:"judge"), token-2 needs one count-only request fired after rows land, and a FAILED measurement leaves the rung LIVE — a rung isn't declared empty until something looked. Tier change is one intent-named action, one history push, both NAV_BACK arms restore it.

3. The cluster heading replaces the location line ONLY at exactly one motif chip and no free text — two chips are an OR-union with no honest single name; free text is a search WITHIN the pivot, a different question. And PIVOT_MOTIF is the only chip operation that clears the path chip (a shape cuts across the ontology; folder-scoping a pivot contradicts it) — no other chip op drops path, so don't cite one as precedent.
