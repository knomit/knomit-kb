# Local ref clicks open ExplainView at parent's commit, NOT history-mode

Clicking a non-HTTP reference inside a fact body opens the existing ExplainView modal anchored at the PARENT fact's commit, with the referenced fact's path — NOT history-mode. Rationale: the previous history-mode path triggered CommitPanel's auto-select rescue (RightPanel.tsx:200-205), which stomped the explicit selection because the parent's commit only touched the parent's own file, so the referenced fact's path was not in detail.files and detail.files[0] was the parent. ExplainView already does the right thing: fetches a fact at (path, commit), has an internal back-stack. Both ExplainView's and RightPanel's FactBody pass `{ fallback: 'before' }` to api.fact so retracted/missing referenced facts walk back to the most recent ancestor where the fact existed. HTTP refs (http://, https://) keep external-link behavior. FactBody's old `navigate` prop was replaced with a focused `onRefClick(refPath)` callback.
