# A chat commit link opens the commit in the chat's side panel, chosen over Browse as of the commit and over building a repo-at-commit list for Browse

Decision (user, 2026-11-07, replacing the choice shipped in PR #788): clicking a commit chip in a chat answer opens that commit in the chat's existing side panel, the panel a fact or a tool call opens in, and the reader stays in the chat. The panel shows the commit's hash, time, message and author and the facts it affected; a fact row opens that fact in the same panel as it read at that commit. The panel has no back (kb/decisions/ui/chat/panel-browse-chrome/64aa3076.md): the way back to the commit is its chip in the answer. Commit data is EXACTLY as it was at that commit (user's words): row titles, the fact's text and everything in its band; an empty commit shows like any commit with no facts.

Options considered: (1) the side panel (chosen); (2) Browse as of the commit, which #788 shipped; (3) build a repo-at-commit list so option 2 has something to show. Why not 2: Browse cannot list a repo at a commit (kb/architecture/ui/temporal/4d80b64a.md: the anchor governs only the open fact, the Library is HEAD-only, and the topics-at-commit route answers 501), so the landing had a blank left column and a right panel of latest-version stats, which misled. Why not 3: it is a new temporal surface, and the question a chip asks (what was this commit, and what did it change) does not need one: the commit-detail read already answers it and the commit-anchored fact read already serves each fact.

Consequences. There is no way to Browse from the commit itself, which Browse could not show. From a fact read at a commit, the band's version, cited by, cites and motif each land in Browse on that fact AT that commit (fact and anchor, which Browse does support), never its latest version. This decision does NOT mean Browse gained a repo-at-commit view, and it does not change which hashes resolve: a chip still exists only when the turn worked in exactly one reachable repo (a hash names no repo). How it is wired is in kb/architecture/web/shell/chat/fact-links/6c5f579f.md.
