# A chat commit link opens Browse of that repo as of that commit, chosen over the Activity view and over the cited fact as of the commit

Decision (user approved, PR #788): clicking a commit chip in a chat answer calls onCommit(repo, commit), which opens that repo in Browse with asOf = history at that commit, with NO fact open. Options considered: (1) Browse as of the commit (chosen), (2) the Activity view filtered to the commit, (3) the cited fact as of the commit. Why: a commit hash names no fact (the resolver answers a commit item with only handle, repo, branch and commit), so option 3 has no fact to open; the Activity view lists changes rather than the corpus state the reader asked about. Consequence: this view is a Browse as-of state with factPath empty. It does NOT mean the chip opens a fact, and a chip for a commit resolves only when the turn worked in exactly one reachable repo (a hash names no repo).
