# Global time-anchor: AsOf union (live | history | diff) on AppState

The web UI has a single global time-anchor on `state.asOf` with three modes, named exactly (`web/src/state.ts`):

```ts
export type AsOf =
  | { mode: 'live' }
  | { mode: 'history'; commit: string }
  | { mode: 'diff'; from: string; to: string };
```

It replaced the prior `historyCommit`/`factCommit` fields. `factPath` stays — it is orthogonal: factPath answers WHICH fact, asOf answers AS OF WHEN, and they have different invalidation rules. `SET_AS_OF` is the single reducer mutator for the anchor (no navStack push); `APPLY_NAV` / `AMEND_NAV` accept `asOf` in place of the old commit fields. The fact's loaded-at SHA reads off `Fact.commit_hash` (the API's `as_of.commit`) directly — no mirror in reducer state, which removed a redundant double-fetch on first load. The `FACT_LOADED` action is removed. `selectAnchorCommit(s)` and `isLive(s)` are exported from state.ts and are the read surface.

**WHAT THIS DOES NOT MEAN.**

- *Not* "the middle mode is `scrubbed`." It is **`history`**. This fact said `scrubbed` until this audit, and no such mode exists — a reducer case or type guard written against `'scrubbed'` silently never matches, which for a union like this fails as a missing branch rather than a type error at the call sites that widen.
- *Not* "there is a `VITE_TEMPORAL_ENABLED` kill-switch." It does not exist at HEAD — `web/src` contains no `import.meta.env` reference at all. Temporal navigation is unconditional; there is no build-time flag that makes `selectAnchorCommit` return null or bypasses `at:`/`vs:` parsing. Do not write code that branches on it.
