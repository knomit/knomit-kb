# Global time-anchor: AsOf union (live | scrubbed | diff) on AppState

The web UI has a single global time-anchor on state.asOf with three modes: {mode:'live'}, {mode:'scrubbed', commit}, {mode:'diff', from, to}. Replaces the prior historyCommit/factCommit fields. factPath stays — it's orthogonal: factPath answers WHICH fact, asOf answers AS OF WHEN. They have different invalidation rules. SET_AS_OF is the single reducer mutator for the anchor (no navStack push); APPLY_NAV / AMEND_NAV accept asOf in place of the old commit fields. The Fact's loaded-at SHA reads off Fact.commit_hash (api's as_of.commit) directly — no mirror in reducer state (removes today's redundant double-fetch on first load). FACT_LOADED action is removed. Feature flag VITE_TEMPORAL_ENABLED (Vite build-time) acts as a kill-switch: when false, selectAnchorCommit returns null, isLive returns true, and at:/vs: parsing is bypassed.
