# FactBody is a shared component used by both RightPanel and ExplainView

The read-only fact body renderer is extracted into web/src/FactBody.tsx as a shared component. Props: fact, navigate, dispatch?, readOnly. Used by both RightPanel (live editing context, readOnly=false, calls dispatch on tag clicks) and ExplainView (modal context, readOnly=true, navigate is no-op). When readOnly=true: tag clouds render but don't dispatch; LOCAL refs are OMITTED from the body (shown only in the outgoing strip at the bottom of explain view) but EXTERNAL (http/https) refs are still rendered in the body. Header buttons (retract/explain) and retracted-version badge stay in RightPanel — they only apply to live editing and are NOT part of FactBody. The shared component is what enables Explain view to reach visual parity with RightPanel (markdown body, type badge, confidence/sources stat boxes, domain/entity tag clouds, commit-hash badge) without duplicating renderers.
