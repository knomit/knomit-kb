# internal/ is restructured into seven enforced layers (platform, domain, foundation, engine, corpus, edge, app); a layer is an import rule checked by TestLayers

Ruled by the user 2026-10-20. Context: internal/ had 22 top-level entries and four packages (store, repos, web, synthesize) holding 67% of non-test lines; the tree did not show the dependency ordering the import graph already has (a clean DAG).

OPTIONS (D1). (a) Full plan: layer directories plus splitting the giant packages. (b) Split the giants only and keep internal/ flat. (c) Amend layer names or membership. CHOSEN: (a). (b) remains the fallback if the layering stalls, since the giant splits are independent of it.

THE LAYERS (D4, names as proposed). A package may import its own layer and any layer below, never above; same-layer edges between distinct packages must be listed. Order low to high: platform (OS and binary, nothing about knomit), domain (pure concepts: fact, okf, model params; no I/O, SQLite, git or cgo), foundation (config, auth, pki, serverkey, serveraddr, client sessions; no corpus), engine (store, embeddings, llm: one external resource each), corpus (repos, refs, federate, resolutions, synthesize: operations on mounted repositories), edge (mcp, web, oauth: protocols facing the outside), app (composition root). internal/testsupport is exempt (only _test.go may import it).

RATIONALE (D2, D3). The #191 objection to grouping subsystems was 'a level with no enforceable property'. TestLayers (test/archtest) is that property: it checks direct imports for the default GOOS, -tags desktop, linux, windows and darwin, fails on empty listings and missing sentinels, and reports any package mapped to no layer. Until the directories exist it maps today's flat paths to their target layer through a table that shrinks as packages move; it ships report-only behind the single constant enforceLayers and is flipped to enforcing by the PR that finishes the moves. Measured on the tree at PR 0: zero upward imports and zero unmapped packages; 15 same-layer edges, all listed. The no-new-top-level-packages convention is amended to 'only the listed layer dirs, enforced by TestLayers'; the group-by-what-a-package-knows decision is superseded in part.

SEQUENCING (D5). The store split (store back-edge cuts, then children sessions, sqlite, vcs, fleetrec, verify, facts, merge, index, vocab, sync, gitserve, fsck) lands BEFORE the layer directory moves, so its value lands even if layering stalls. D6 model budget: haiku for mechanical moves, opus for vcs and fleet, sonnet elsewhere.

CONSEQUENCES. embeddings/params moves to domain/modelparams (config in foundation imports it; leaving it under embeddings would be an upward edge). New packages go inside a layer directory, never a new top-level entry.

NON-SCOPE. This does not authorize new top-level directories beyond the seven layers, does not make the layer rule enforcing before the moves land, and does not by itself split any package.
