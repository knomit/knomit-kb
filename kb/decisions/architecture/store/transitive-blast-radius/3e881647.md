# BlastRadius = transitive reverse-DERIVED_FROM live-at-HEAD count; retracted intermediates still transmit reach

SearchIndex.BlastRadius(ctx, branch, path) is the keystone-impact metric: how many distinct LIVE facts would be invalidated if `path` were false. Chosen (D5) as TRUE transitive reverse-reachability over a cheap in-degree proxy — cites principles/anti-patterns/solution-quality-pre-release. reverseDependentPaths walks DERIVED_FROM in reverse (edges point source→target, so 'who derives from me' = collect source where target is in the frontier) via a recursive CTE with UNION (dedupes node ids, terminates on cycles); BlastRadius then keeps only paths LIVE on branch HEAD (branch_facts) and excludes `path` itself.

LOAD-BEARING SUBTLETY: the walk seeds from EVERY historical version of `path`, and the historical graph keeps a retracted intermediate's nodes+edges — so a retracted intermediate STILL transmits reach to its dependents. A leaf, or a path whose dependents are all retracted at HEAD, returns 0. Used to rank backward (keystone) discovery and as a Plan-04 gate: a backward proposal's seed-anchor must reach ≥ DiscoveryBlastRadiusThreshold.
