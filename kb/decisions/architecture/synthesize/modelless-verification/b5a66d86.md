# Discovery verification is model-less: a strict default-skip prompt + an ingest gate chain, no adversarial model

There is NO adversarial verifier model (D6). Two layers keep discovered facts high-signal. (1) The work-item prompt is strict default-SKIP: 'DEFAULT TO NO; propose only if ALL conditions hold; empty refs means non-engagement' (forward demands strict entailment, backward strict requirement). (2) applyDiscoveredProposals runs every proposal through an ingest gate chain, cheapest-first: type-vs-direction → validateOutputPath/Type → refs MUST cite every bridge seed (engagement proof) → confidence ≥ DiscoveryConfidenceThreshold → embedding dedup vs the live corpus (skipped when the embedder is nil) → backward-only BlastRadius ≥ threshold. Survivors are written origin=discovered through the normal weight + serialize + WriteFact path. Each rejection is a NON-FATAL logged 'warn' ProgressEvent: discovery is enrichment, so a bad proposal or a malformed agent response never aborts the host review/hypothesize session.
