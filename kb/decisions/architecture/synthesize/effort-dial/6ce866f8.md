# Discovery is an `effort` dial (normal|medium|high) on existing ops, not a new tool; effort doubles as a budget

Emergent-fact discovery is gated by an `effort` argument threaded through knomit_review and knomit_hypothesize — NOT a new tool (D2). Vocabulary `normal|medium|high` (synthesize.Effort, mirrors fact.Origin). `normal` (default) reproduces pre-discovery behaviour byte-for-byte; `Effort.Discovers()` is true only for medium/high.

When the seed pool is UNFILTERED, effort also acts as a BUDGET (D8): bridgeSeeds truncates the strength-ranked bridge set to effortBudget(eff) — medium=12, high=48 — never the whole corpus. A scope-filtered pool is already bounded by the agent's request and skips truncation. effort is persisted on pipeline_sessions.effort (CreatePipelineSessionWithEffort) so ContinueSession recovers the dial; the default resolves through DiscoveryConfig.EffortDefault / RepoInstance.DiscoveryEffortDefault().
