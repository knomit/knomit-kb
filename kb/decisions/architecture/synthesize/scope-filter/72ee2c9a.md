# Optional domain/entity ScopeFilter bounds the discovery seed pool; empty = whole-corpus, applied first-run AND incremental

knomit_review and knomit_hypothesize accept optional `domain` / `entities` array args → synthesize.ScopeFilter (D7). An EMPTY filter (zero domains AND zero entities) = whole-corpus, the historical default — explicitly NOT a 'match nothing' footgun. A non-empty filter restricts the seed pool, applied FIRST at search time (SearchOptions.Domain/Entities) and AGAIN on the incremental (post-watermark) path via ScopeFilter.Matches on each changed fact — in BOTH the review and hypothesize pipelines, so a caller-supplied scope is honored on every code path. Matches is the single definition of membership: UNION semantics — a fact is in scope if it touches ANY requested domain OR entity (not all). A non-empty scope also signals 'already bounded', so the bridge engine skips effort-budget truncation.
