# Discovery direction maps to operation: consequences→knomit_review (synthesis), keystones→knomit_hypothesize (hypothesis)

The discovery engine produces two emergent-fact shapes, routed to preserve the existing type/operation boundary (D3). FORWARD (deductive consequence) runs inside knomit_review's pipeline and writes type=synthesis — a fact strictly entailed by a cross-cluster bridge that nobody wrote down. BACKWARD (abductive keystone) runs inside knomit_hypothesize and writes type=hypothesis — an unstated premise that would explain why the bridged facts are simultaneously true, ranked by BlastRadius. Both carry origin=discovered. A gate enforces type-vs-direction (forward MUST be synthesis, backward MUST be hypothesis). This keeps knomit_review = 'maintain / derive what is entailed' and knomit_hypothesize = 'predict forward', exactly as before discovery.
