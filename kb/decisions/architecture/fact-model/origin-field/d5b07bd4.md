# origin is an orthogonal provenance axis (authored|distilled|discovered), not a new type or kind

Every fact carries an `origin` recording HOW it came to exist: `authored` (hand-written via knomit_learn), `distilled` (synthesis-pipeline output — today's type=synthesis facts), `discovered` (emergent — surfaced by the discovery engine). It is ORTHOGONAL to kind (epistemic/pragmatic) and type (the leaf): emergent facts stay *kinds of* synthesis/hypothesis; origin just stamps provenance. Chosen (D1) over a new type or kind because it is the smallest schema blast radius.

Wiring: `fact.Origin` field, serialized ONLY when != authored (byte-identical round-trip for the entire pre-origin corpus). The legacy default is TYPE-AWARE — a file with no origin resolves to `distilled` for type=synthesis, `authored` otherwise — so no file rewrites. Indexed as `facts.origin` (migration 000012, immediate backfill synthesis→distilled) + index; FactRecord.Origin; SearchOptions.IncludeOrigins filter; knomit_query `origin` param. Git stays the source of truth — the column is a rebuildable cache.
