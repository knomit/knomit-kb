# The embedding model REGISTRY (descriptors, Lookup, IDs, ModelPaths, ModelCached) lives in cgo-free internal/embeddings/params/registry.go, and internal/embeddings aliases it - so anything that only needs to know ABOUT a model imports params and links no ONNX or tokenizers

Done in PR #503 (merge 8be999a0). The desktop's boot caption ('downloading models') needs to know whether the configured model is cached, and `ModelCached` lived in internal/embeddings, which links the ONNX runtime binding and the tokenizers static library. Importing it cost the desktop binary 18.2 MB (50,676,626 to 32,492,898 bytes, darwin/arm64) and blocked cross-vetting the package for Windows. The registry moved into the EXISTING cgo-free child package internal/embeddings/params (new file registry.go, stdlib only; no new directory, consistent with kb 3446559d's no-new-top-level-package rule): the Model and Pooling types, the descriptor table, Lookup, IDs, ModelPaths and ModelCached.

SHAPE: internal/embeddings keeps `Model = params.Model` and `Pooling = params.Pooling` as type ALIASES, re-exports the Pool* constants, and wraps Lookup, IDs and DefaultModelID, so every existing `embeddings.X` use still compiles. EnsureModel (the download) stays in internal/embeddings and calls params.ModelPaths. `embeddings.ModelCached` no longer exists; its only caller, the desktop, calls params.ModelCached.

CONSEQUENCE: code that only needs a model's name, paths, dimensions or thresholds imports params; code that runs a model imports embeddings. test/archtest/desktop_no_server_test.go forbids knomit/internal/embeddings (exact), onnxruntime_go and tokenizers in knomit-desktop but allows params. TestParamsHasNoDependencies keeps params stdlib-only, so adding a non-stdlib import to registry.go fails there.

NOT MEANT: params does NOT load, run or download models - it only describes them and answers 'are the files on disk' (presence check on graph, tokenizer and weights; a graph and tokenizer without the weights file is NOT cached, TestModelsCachedPicksTheCaption).

PATH NOTE (layer move step 01, PR #588): internal/embeddings/params is now internal/domain/modelparams (package modelparams); registry.go lives at internal/domain/modelparams/registry.go and the qualified names read modelparams.Model, modelparams.Lookup, modelparams.ModelPaths, modelparams.ModelCached. The decision text above uses the old path and package name.
