# The bridge executable `kb` (knomit-bridge) is dual-purpose: stdio MCP proxy + 'claude init' scaffolder

The bridge — executable `kb` since PR #218 (2026-09-18), previously `knomit-bridge`, which remains its descriptive program name — serves two roles. **Primary:** a stdio MCP proxy spawned by an MCP client (Claude Code, Claude Desktop, Claude Cowork) at session start — reads JSON-RPC from stdin, forwards to the server's MCP endpoint, writes responses to stdout (tools/bridge/main.go default mode). **Secondary:** Claude Code scaffolding + hooks under a `claude` subcommand namespace: `kb claude init` drops integration files (.mcp.json, .claude/settings.json, CLAUDE.md are merge-required; .claude/skills/** are owned/overwritten) via //go:embed templates, and `kb claude hook <event>` runs the editor hooks. An `antigravity` namespace does the same for Antigravity. Knomit-side repo creation stays separate (server-side). NOTE: the command moved from the old top-level `knomit-bridge init` to `knomit-bridge claude init`, and then with the rename to `kb claude init`; `claude` also dispatches `version`.
