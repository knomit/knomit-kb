# knomit-bridge is dual-purpose: stdio MCP proxy + 'init' scaffolder

knomit-bridge serves two roles. Primary: stdio MCP proxy spawned by Claude Code at session start (existing tools/bridge/main.go behavior). Secondary: one-shot scaffolding tool invoked as 'knomit-bridge init' that drops integration files (.mcp.json, .claude/settings.json, .claude/hooks/*, .claude/skills/*, CLAUDE.md block) into a codebase via //go:embed templates. Knomit-side repo creation stays in 'knomit init' — the bridge owns ONLY CC-side scaffolding, nothing touching the knomit repo. Files are intended to be checked into git so contributors inherit the integration.
