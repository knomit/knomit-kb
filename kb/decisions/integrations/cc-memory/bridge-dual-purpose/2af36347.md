# knomit-bridge is dual-purpose: stdio MCP proxy + 'init' scaffolder

knomit-bridge serves two roles. **Primary:** a stdio MCP proxy spawned by an MCP client (Claude Code, Claude Desktop, Claude Cowork) at session start — reads JSON-RPC from stdin, forwards to the server's MCP endpoint, writes responses to stdout (tools/bridge/main.go default mode). **Secondary:** Claude Code scaffolding + hooks under a `claude` subcommand namespace: `knomit-bridge claude init` drops integration files (.mcp.json, .claude/settings.json, CLAUDE.md are merge-required; .claude/skills/** are owned/overwritten) via //go:embed templates, and `knomit-bridge claude hook <event>` runs the editor hooks. Knomit-side repo creation stays separate (server-side). NOTE: the command moved from the old top-level `knomit-bridge init` to `knomit-bridge claude init`; `claude` also dispatches `version`.
