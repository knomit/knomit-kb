# Four CC hook events: session-start, post-edit, post-ask, pre-compact

The knomit Claude Code integration registers FOUR hook events, each run via `knomit-bridge claude hook <event>` and wired in the generated `.claude/settings.json`:

- **session-start** (SessionStart): pre-warms the session — emits known principles, recent facts, and the per-area TOC. Plain stdout (CC auto-wraps it as a system reminder).
- **post-edit** (PostToolUse Edit|Write|MultiEdit): when an edited file matches a fact's entities, nudges `/knomit-update` or `/knomit-retract` for possibly-stale facts.
- **post-ask** (PostToolUse AskUserQuestion): after a resolved AskUserQuestion with non-obvious tradeoffs, nudges `/knomit-decided` BEFORE the authorized work starts.
- **pre-compact** (PreCompact): scans a wider window for capture-worthy moments and nudges `/knomit-remember`.

An earlier design had THREE hooks (no post-ask); post-ask was added so AskUserQuestion tradeoff resolutions get captured. SessionEnd is deliberately unused (its output is discarded by CC). All hooks NUDGE; none auto-write facts. Hooks other than session-start emit `{"hookSpecificOutput":{"additionalContext":...}}` JSON.
