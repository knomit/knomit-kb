# Three CC hook handlers after pruning: SessionStart, PostToolUse(Edit|Write|MultiEdit), PreCompact

The integration ships THREE hook handlers in tools/bridge/claude/hook.go after PR #66 pruning. The original design called for four; the set briefly expanded to six during the integration; field testing showed four of the six were noise generators (0 emits across dozens of fires) and were removed at 89e652e+.

Kept (each earns its slot):

(1) SessionStart — pre-warms context with the top invariants (kb/invariants/*) + recent facts via GET /api/v1/repos/{repo}/branches/{agent}/facts?sort=recent&limit=200. Plain-text stdout (CC auto-wraps as system reminder). HIGH SIGNAL: the only hook that injects information Claude doesn't already have.

(2) PostToolUse on Edit|Write|MultiEdit (post-edit handler) — when the edited file's relpath appears in any fact's entities[], emits a list of those facts with /knomit-update / /knomit-retract nudges. REAL DRIFT DETECTION: fires meaningfully when a tracked fact's anchor file is touched.

(3) PreCompact — last-chance capture-candidate sweep before the transcript is summarized away. Tail-reads up to 50 messages, regex-matches each for intent patterns (correction/discovery/decision/fix-bug/gotcha), dedups same-sentence hits, emits quoted moments with a /knomit-remember nudge. SAFETY NET: rare to fire (the matchers want stereotyped phrases), but when it does it rescues discoveries.

Removed at 89e652e+:
- UserPromptSubmit nudging /knomit-recall on design-intent prompts — duplicated CLAUDE.md guidance; regex too narrow for real prompts (7 fires, 0 emits in field test even after one positive test).
- PostToolUse on Bash filtering for 'git commit' to nudge /knomit-remember — 12 fires, 0 substantive emits in field test; matcher mis-scoped (fires on every Bash to filter for the ~1% that are commits).
- Stop per-turn capture sweep — redundant with PreCompact's wider window and previously rate-limited via the discredited /tmp/knomit-stop-rate counter (see [[no-global-tmp-state]]).

PostToolUse still fires on every Edit/Write/MultiEdit; only the Bash sub-matcher was removed. settings.json.tmpl now registers exactly three hooks (down from six). The Go intent matcher in intents.go is unchanged — PreCompact still uses all five intents.
