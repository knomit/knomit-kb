# Capture hooks nudge CC; they never auto-write facts

PreCompact and Stop hooks (and the post-commit hook) emit a system reminder listing capture-worthy moments — they do NOT write knomit facts directly. Rationale: CC has the conversation context needed to compose a coherent fact body; the /detect endpoint only tells the hook WHICH moments to surface. Auto-write via subagent (Shape D+) is listed in §5 as a future extension for when nudges miss too many real captures. The hook also includes similar_facts from /detect so CC can update an existing fact instead of creating a duplicate.
