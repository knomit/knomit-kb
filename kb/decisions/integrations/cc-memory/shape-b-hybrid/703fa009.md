# Shape B chosen for knomit-as-CC-memory integration

The knomit-as-Claude-Code-memory integration uses Shape B: a balanced hybrid model where hooks automate the obvious moments (SessionStart pre-warm, post-commit capture nudge, PreCompact and Stop safety nets), skills handle deliberate moments (six /knomit-* slash commands), and CLAUDE.md carries philosophy/when-to-use guidance. Explicitly rejects PreToolUse auto-injection of facts (listed in §5 as opt-in extension Shape C+). Rationale: hooks catch what CC forgets to write, skills give CC deliberate control, no auto-injection keeps the surface area predictable. Bootstrap is structured per-area /knomit-kickoff-area, then organic accumulation thereafter.
