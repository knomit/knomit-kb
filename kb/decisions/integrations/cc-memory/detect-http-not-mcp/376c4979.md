# Capture-worthy signal detection is HTTP, profile-scoped, not MCP

PreCompact and Stop hooks POST recent transcript blocks to POST /api/v1/profiles/{profile}/detect (for source-code repos {profile} is 'code'). The endpoint scores each block for capture-worthiness using the existing embedder: max cosine similarity to canonical phrases per intent ('intent score'), plus 1 - max similarity to existing facts ('novelty'). Profile-scoped because capture-worthy signals differ between code/chat/generic. The detect endpoint is server-side machinery the hooks need — it does NOT belong in CC's tool surface. Exposing knomit_detect as an MCP tool is an opt-in extension listed in §5, not part of the initial build.
