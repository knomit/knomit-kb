# Claude Cowork integrates via the generic stdio MCP bridge (no Cowork-specific code)

Claude Cowork connects to knomit through the SAME stdio MCP bridge every other MCP client uses — there is no Cowork-specific code in the repo. Setup: register knomit-bridge as an MCP server in Cowork's config file (per Claude Cowork's own docs for the config location/schema), exactly like a Claude Desktop .mcp.json server entry: {"command":"/path/to/knomit-bridge"}, optionally with args like ["--repo","trunk","--profile","chat"]. Requires a running server (simplest: the desktop app, which writes the server.json lockfile the bridge auto-discovers) and the knomit-bridge binary on disk. Unlike the Claude Code integration, Cowork does NOT use `knomit-bridge claude init` (no project skills/hooks) — it is purely MCP server wiring. For a conversational surface, profile=chat usually fits better than the default code.
