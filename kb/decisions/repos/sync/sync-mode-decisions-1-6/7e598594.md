# Sync mode decisions 1-6: object shape; pull = the existing full round; GitHub allowed with limits documented and no URL guard; subscriptions ignore sync; F08 template follow-up after; the host's round cadence follows pull (user, 2026-10-01)

**The user's rulings, verbatim (2026-10-01), on design rev 2's six decisions:** "1) yes. 2) yes 3) yes 4) explain 5) yes. 6) yes." Then, once decision 4 was explained: "4) agreed."

**The six decisions and what lost:**
1. **Shape `sync: {push, pull}`** — over two flat keys or one scalar.
2. **Pull is the existing full round** (fetch, merge, push when ahead) every realtime_pull_interval. **Rejected: a fetch-only pull** — it needs a second code path, and this instance's own commits would then wait for push: realtime or the 300 s round; an idle full round already costs no push network, so fetch-only saves nothing.
3. **GitHub is allowed, limits documented, no URL guard.** **Rejected: a URL guard** (warn or refuse when the origin is github.com) — the "magic guess" the 2026-09-28 ruling forbids. The 1 s floor, the circuit breaker and the docs (GitHub recommends at most 6 pushes/min per repository; realtime push under steady writing exceeds it from one instance) stand in for a guard.
4. **Subscriptions ignore `sync`.** **Rejected: subscriptions honouring pull** — every subscriber of a public repo that turned realtime on would fetch it every few seconds; a subscriber is not a participant in the repo's coordination, and push is moot for it.
5. **The F08 mission template follow-up comes after** (set `sync`, drop the four `do: push` triggers, X ≈ 15 s, which holds only while every participant's origin is healthy). It ships as its own small PR after #382.
6. **The host's (no-origin) round cadence follows `pull: realtime`** (the local loop waits N instead of local_reconcile_interval; no fetch, it advances the consensus branch and carries the on: due sweep). **Rejected: host pull as a no-op** with the operator lowering local_reconcile_interval instead — that key is instance-wide and would speed up every repo on the host to serve one mission. With local_reconcile_interval = 0 there is no local loop and neither key does anything.

**Non-scope:** these rulings do not make sync a mid-flight knob (set it once and forget it), and do not add per-instance config beyond the one toml key.
