# Manager.Rescan() is discovery-only — adds new repos, never removes or replaces

POST /api/v1/repos:rescan globs <home>/repos/*.db and registers any *.db file not currently in the Manager. It does NOT detect removed .db files and does NOT detect replaced .db files (same name, different content) — explicitly out of scope. rescanMu sync.Mutex on Manager serialises concurrent Rescan calls to prevent the same .db being opened twice in a race. No ctx parameter: Manager.Add/openOne don't take one and the operation is short. No auth on the endpoint — knomit API is unauth'd by design (localhost only); rescan can't do anything more destructive than the existing `knomit init` CLI. The endpoint is the only safe runtime way to discover repos created via `knomit init` against a running server (auto-discovery only runs at startup).
