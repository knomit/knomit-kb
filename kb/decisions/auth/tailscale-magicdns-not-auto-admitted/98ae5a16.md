# Same-host proxies are admitted by listing their name in [auth].loopback_hosts by hand — NOT by auto-admitting this node's Tailscale MagicDNS name, which is rebinding-safe but couples the auth path to Tailscale and silently exposes a Funnel-ed name

CONTEXT: after #281, a same-host proxy that forwards the browser's Host unchanged gets 421 unless its name is admitted. The maintainer's own path, Tailscale → code-server → /proxy/<port>/, is one of these.

OPTIONS (the proposal's 'Automatic admission' section, raised by reviewer2's M1):
- (1) list the name by hand in [auth].loopback_hosts, adding it BEFORE upgrading; older binaries only warn about the unknown key;
- (2) auto-admit this node's own Tailscale MagicDNS name, read at boot from `tailscale status --json` (Self.DNSName) or tailscaled's local API. It is rebinding-safe because Tailscale's resolver, not attacker-controlled DNS, answers that name;
- (3) a report-only release before enforcing.

CHOICE: (1). The user decided on 2026-09-25, after asking for context first. Auto-admission was NOT built. If the user later wants it, it is a follow-up PR.

RATIONALE AGAINST (2):
- COUPLING: Tailscale-specific code in the auth path, plus a process exec or local-socket call at boot. It also creates a start-order failure mode: tailscaled down or logged out at boot means the name is not admitted.
- SILENT EXPOSURE: if the operator enables `tailscale funnel` for that name, the public internet reaches the plain port through it and holds [auth].loopback_default (admin by default), and nothing ever asked the operator. An explicit loopback_hosts entry is where that acknowledgement happens.

(3) was rejected: it keeps the gap open for a whole release, and adding the key before upgrading already gives zero breakage.

NON-SCOPE: this does not rule on other automatic sources. Those were judged UNSAFE on different grounds, not merely rejected: os.Hostname(), .local mDNS names and search-domain names can be answered by a hostile LAN resolver or an mDNS reply, and must never be auto-admitted.
