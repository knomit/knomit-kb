# An experiment is a LOCAL exp/<name> branch forked from the agent branch that a session reads AND writes on; never pushed, no agent slug, name plus a local description, 30-day inactivity expiry measured by commits, and every MCP tool works there unchanged

**Options considered (design session 2026-09-20, user ruling):** (a) the F17 fleet proposal: `exp/<agent-slug>/<name>`, push opt-in per experiment, reads stay on the lens while writes go to the experiment, review on experiments deferred; (b) the user's ruling: one local branch that is an isolated world.

**Rationale:** Experiments exist so a task's knowledge work can fail without leaving half-formed facts on the agent branch. That needs an isolated world, not a write redirect: a session inside an experiment must SEE what it wrote, so reads and writes land on the same branch. Local-only removes push opt-in, the refspec work in configureRemote, and the agent slug (which only existed to namespace experiments on a shared origin). The `/git` curated advertisement already hides non-upstream/agent refs, so nothing leaks. "Every operation works on an experiment" was stated as a requirement: query, explain, learn, update, retract, review and hypothesize all run on the bound branch; the review engine reads the binding's write branch once at session start instead of ri.AgentBranch(). Fork copies the parent's pipeline_watermarks so review on the experiment seeds only its delta.

**The choice:** ref `exp/<name>`, kebab-case, unique per repo; description stored locally in the repo DB experiments table (never in git); parent recorded explicitly (branch-roles invariant); writable iff the recorded parent is this instance's current agent branch AND both sides are non-empty; expiry is ONE global setting `experiments.expiry_days` (default 30, 0 = never), activity = any commit on the experiment (binding or reading does NOT refresh it), a sweeper rolls back expired ones; two sessions may bind the same experiment (the branch lock serializes writes, no refusal); subscriptions (no agent branch) cannot open experiments.

**Non-scope:** does not decide nested experiments, experiments on a lens with several write repos, or an archive namespace for dropped experiments (the hook is left; not built). Does not authorize a sweep-interval setting: the cadence is a code parameter, not configuration, so the UI shows exactly one control.
