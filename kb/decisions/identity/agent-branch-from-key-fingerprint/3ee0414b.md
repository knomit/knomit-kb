# Agent branch is 'agent/<hostname>-<fingerprint8>'; fingerprint replaces hostname-only naming

Agent branch naming: agent/<hostname>-<fingerprint8>, where fingerprint8 is the first 8 hex chars of SHA256(public_key_bytes). Example: agent/laptop-a7f3c2b1. Hostname is sanitized — chars invalid in git refs (spaces, tildes, ~, :, ^, ?, *, [, \) replaced with -; falls back to 'local' if os.Hostname() fails. Hostname-only naming (agent/<hostname>) was REPLACED because it collides in containerized/CI environments. Key generation: ~/.knomit/id_ed25519 (private 0600) + .pub (public 0644). On first knomit serve/init, EnsureKeyPair atomically writes via os.MkdirAll + temp file + os.Rename (avoids races on concurrent starts), prints the pubkey to stderr so the user can register it. Per-repo override via RemoteAuthConfig.SSHKey or KNOMIT_REMOTE_SSH_KEY env. ssh-keygen -l uses base64; we chose HEX for branch-name readability.
