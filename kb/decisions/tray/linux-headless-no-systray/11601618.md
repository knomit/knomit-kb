# On Linux, knomit-tray runs headless — no systray, window via .desktop launcher

knomit-tray on Linux is a headless background supervisor for knomit serve (NO systray icon). The companion command `knomit-tray window` opens a webview, triggered via a generated .desktop file from the user's DE app launcher (Activities, KRunner, rofi). Both GNOME and KDE are first-class targets — no DE-specific code needed because tray is skipped entirely. Implementation: trayui/*.go has //go:build darwin so the package becomes non-existent on Linux (any accidental import fails the build — compile-time guard against systray creeping in). Each platform file (tray_darwin.go for macOS runTray with systray.Run, tray_linux.go for headless runTray) provides its own runTray; Go build tags ensure exactly one compiled per GOOS. Paths follow XDG: $XDG_STATE_HOME/knomit/server.json (default ~/.local/state/knomit/). Optional autostart via systemd user unit. Webview backend is WebKitGTK on Linux (requires libwebkit2gtk-4.1-dev) and WKWebView on macOS.
