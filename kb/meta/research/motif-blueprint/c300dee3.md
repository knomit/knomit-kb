# Motif blueprint: the Memora-derived mechanism-bridging design, fully measured, lives in .claude/plans with its harness

The 2026-08 research spike on Memora-style mechanism bridging produced an implementation blueprint at .claude/plans/2026-08-18-memora-bridging-analysis.md (Part I = build spec with verbatim SHIP prompt blocks, Part II = condensed evidence from five measurement rounds, §13 = design-to-evidence traceability) and a reproducible experiment harness at .claude/plans/memora-harness/ (blind bridge harness, four motif eval packs with model outputs, matching dry-run scripts, seed 42 throughout). Headline design: an optional motifs: field (0-3 mechanism names per fact, names-only at write time), derived-state vocabulary lifecycle (LLM-judged alias clustering with carrier context, blind per-name definitions), a permissive-prefilter->rank->budget->discover-agent matching cascade (~68% cross-author recall at high effort), effort-bound operating points including a verbatim-only tier at normal (cap 2), and retrieval surfaces with a motif_match strictness knob. Implementation phases 0-2 are unconditional; phases 3-4 sit behind an explicit go/no-go gate. Per repo policy, the design DECISIONS are not recorded as facts until the code lands — this reference exists so future sessions find the blueprint instead of re-deriving it.
