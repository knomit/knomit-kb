# Following kb refs transitively (depth cap 4) from 25 question-matched facts on agentic-engineering pulled in 89 more facts (114 total, ~126k tokens, 331 HTTP calls); a cold reader judged only about 20-25% of the document relevant, while a changes-feed set of 40 facts gained 1 context fact

Measured 2026-10-25 (materialize research spike, first build; evidence in the git-ignored .claude/future/materialize/spike/REPORT.md, spike/COLD-READ-FINDINGS.md and spike/out/run1/run.json, repo-relative, not pinned).

Run 1, question 'what are the latest trends in agentic development?' on the agentic-engineering repo: the semantic search union was 60 unique hits, the top 25 became the matched set, and a closure that followed each fact's kb refs to the commit-pinned target, depth cap 4, added 89 context facts: 114 facts in all, 168 edges among them, 59 facts with kb edges, 15 edges cut by the depth cap and 26 cycle breaks. The export was 507,059 bytes (about 126k tokens) and took 331 HTTP calls in 47 s on localhost, because the REST surface has no bulk read.

Run 2, changes feed of the last 14 days on cyberai-kb, 40 most recent live changed rows kept: the closure added 1 context fact (41 total, about 10k tokens), because those facts cite mostly URLs rather than other facts.

Cold read (a Haiku reader with no knomit access, one read per run): on run 1 it estimated relevance at about 20-25%, i.e. roughly 80 of the 114 facts were context pulled in by the closure (security forensics, evaluation methodology, LLM-judge bias, CVE write-ups) rather than answers to the question; it read all 8 chunks and still concluded 'the document does not answer directly'. On run 2 it needed about half the document.

CONSEQUENCE: reference closure is reachability, not relevance. How much it inflates a document depends on how densely the starting set cites other facts: about 4.6x here for question-matched facts, about 1.0x for a changes feed. WHAT THIS DOES NOT MEAN: the 20-25% is one cold reader's estimate, not a graded measurement; the depth-capped closure was not graded against a relevance-gated one; one KB, one question, one branch. It does not say refs are useless to a reader: the same cold reader liked explicit scoping and 'does not mean' blocks that came from the facts themselves.
