# Measured Claude Haiku 5.5 cost to write ingestion facts through claude -p (Oct 2026): about $0.001-0.0025 per selected passage, $0.005 per whole page for title/body facts, and $0.0069-0.0109 per whole page for complete knomit_learn inputs; output is about 73% of the bill

DATED SNAPSHOT, measured 2026-10-26/27 (Haiku ingestion spike, rounds 1-9; evidence in the git-ignored .claude/future/ingestion/haiku/round5/examples/COST-PER-DOC.md and each round's RESULTS.md, repo-relative, not pinned). Prices: Haiku 5.5 list $0.10 input / $0.50 output per MTok; the CLI bills input at the 1-hour cache-write rate ($0.20). 'Billed' = claude -p total_cost_usd per document, Haiku generation only (judges excluded).

Per selected passage (up to three sections): round 1 $0.00103 billed ($0.00071 at plain list rates minus the CLI's ~545-token overhead); round 3 main-points prompt $0.00154; round 4 $0.00249. Per whole page (7-28 chunks), title/body facts with --json-schema: $0.00512 (round 4). Whole page with all placement fields (topic, category, kind, type, confidence, domain, entities, motifs): $0.00694 (round 5); with anchoring and caveat rules $0.0080-0.0090 (rounds 6-8); $0.0109 in round 9, of which about 20% was three anomaly re-generations (seen 20 pages: $0.0102). Output tokens per page rose from about 6.9k to 13.4k across those rounds as facts got longer.

Structure (round 5, per page): CLI overhead ~545 tokens, system prompt ~2,400, JSON schema ~600, knowledge-base block (topics, category tree, domain vocabulary) ~2,750, page text ~5,200. Output was about 73% of the clean bill. Caching the static prefix (~5,755 tokens) would save about $0.00052 per page (~8%; ~12% if internal re-turns re-read it); caching does nothing for output.

Operational consequence: cost levers for this task are output length and avoiding repeated turns, not input caching. These are CLI costs; a single-shot API call (no internal structured-output turn, see the sibling structured-output fact) and the Batch API discount were NOT measured, so do not quote API costs from this fact. Re-check prices before reuse; this fact expires.
