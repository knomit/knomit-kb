# On the spike-12 ingestion test set, zero-shot Claude Haiku 5.5 given the same reader prompt and passages wrote 99.5% supported sentences (core80) vs 69.3% / 79.4% for the LoRA-fine-tuned 4-bit LFM2.5 350M / 1.2B, with almost no misattribution, but it writes 4-7x more text and never returned an empty answer

Measured 2026-10-26 (Haiku ingestion spike, round 1; evidence in the git-ignored .claude/future/ingestion/haiku/RESULTS.md, repo-relative, not pinned). Setup: the 363-record spike-12 test set, the identical spike-12 SYSTEM prompt and user text (document title + up to three selector-chosen sections), Claude Haiku 5.5 zero-shot through claude -p, judged by the unchanged spike-12 Sonnet judge on the same core80 and ae30 sets. The LFM numbers are the stored spike-12 verdicts; re-aggregating them reproduced the spike-12 report exactly.

Results (fine-tuned 350M 4-bit / fine-tuned 1.2B 4-bit / Haiku): supported sentences core80 69.3% / 79.4% / 99.5% (1,612 Haiku sentences judged); ae30 66.7% / 68.6% / 99.3%. Misattributed sentences on core80: 63 / 32 / 3. Main reference claim stated per document (yes / partly / no, core80, empty counts as no): 16/45/19, 21/33/26, 56/21/3. Empty output on the 19 real negatives: 8 / 13 / 0. Lessons per document (core): 0.94 / 0.81 / 5.30. An Opus re-judge of 30 documents agreed with Sonnet on 99.5% (core) and 98.7% (AE) of Haiku sentences and kept the ranking.

How to read it. (1) Haiku writes about 20 sentences per document against 3-4, so supported-% is saturated and claim coverage is partly an effect of volume; the supported gap says Haiku rarely misattributes here, it is not a number to rank precision by. (2) The LFMs were LoRA-tuned on about 1,250 examples and quantised to 4-bit (the 350M lost about 11 points to 4-bit); this comparison does not show what an LFM with far more training data would do. (3) Haiku is not selective: it summarised all 19 'negative' pages (pages for which the KB wrote no fact; several are real content pages), so a pipeline that must skip boilerplate pages needs its own gate.

What this does NOT mean: it does not mean Haiku's facts were knomit-ready in this round; the output was title/body lessons only, with no placement fields, anchoring or validation (later rounds measured those, see the sibling facts under kb/meta/research/ingestion/).
