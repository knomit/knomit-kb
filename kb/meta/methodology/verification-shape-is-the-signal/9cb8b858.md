# A verification that emits nothing must be PROVEN to have run; and when its SHAPE changes (a count moves), reconcile your expectation against the anomaly, never the anomaly against your expectation

Two coupled failure modes of trusting a verification's OUTPUT instead of its execution, both live in the backfill rip-out campaign:

**Silence is not success.** A check whose clean result is 'no output' can produce that same clean-looking output by NOT RUNNING. `go test ./... 2>&1 | grep -vE '^ok' | head -25` merged stderr in, JSON logs filled the window, and `head -25` truncated the stream BEFORE any `FAIL` line could appear — reading as 'no FAIL visible' = 'no FAIL'. Same shape as an unquoted zsh loop variable that never word-splits and greps nothing across 32 symbols, printing zero hits that read as 'no consumers'. Rule: a check that outputs nothing must be shown to have executed — a proven control hit, an asserted count, an explicit positive assertion — not assumed clean. This is the sabotage 'show your diff' discipline one level up, applied to the verification's own tooling.

**Shape IS the check.** What actually caught a genuinely RED suite (a test failing `open motif_backfill.go: no such file`) was NOT a failure message — it was **48 packages printing `ok` where 49 had all session**. When a verification's shape changes — package count, symbol count, row count, line count — that shape is itself the signal. The trap is explaining the anomaly away as noise ('probably nothing'); the discipline is the reverse: reconcile your EXPECTATION against the anomaly (here: `go list` proved both trees have 49 test-bearing packages → one package never printed `ok` → the gutted one silently failed). The count was the only honest signal in a window that otherwise read clean.

Consequence: report a suite as stdout-only + explicit `FAIL` grep + an ASSERTED package/row count — never 'no FAIL in the visible output', which is `head`-truncation waiting to lie. Sibling of instrument-reads-truncated-values (a contradiction with a previously recorded number is the catch) generalized from measurement to verification-output; and of build-the-merge-result (verify the result, not the plan). Grounded in a disclosed near-miss during the backfill rip-out (PR #161): the reporter nearly handed over a RED branch as green, caught only by the count anomaly.
