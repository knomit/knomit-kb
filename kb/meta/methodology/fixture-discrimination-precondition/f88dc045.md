# A fixture only discriminates if the values it must distinguish are asserted to DIFFER, as a precondition, in the test itself — and this is found by sabotage, never by reading

Reviewer's sharpening, adopted at the motif campaign's close.

**The rule.** *A fixture only discriminates if the values it must distinguish are asserted to differ, AS A PRECONDITION, IN THE TEST ITSELF.* The enforcement mechanism is the precondition assertion — that is the part to write down, not the intention.

**Why the assertion and not care.** When two things a test must tell apart happen to hold the SAME value in the fixture, the test passes under both the correct and the broken implementation, and it goes on passing for the lifetime of the code while reading as coverage. Nothing about the assertion looks wrong; the FIXTURE is the defect. A precondition assertion converts that from an invisible property into a failing test the day the fixture drifts.

**Three instances in one phase, all found by sabotage, none by reading.**
1. *The member-count filter.* An equivalence test meant to prove the instrument measures what production serves stayed GREEN after a production-only member filter was installed — every served group in the fixture had exactly two members, so a size filter was invisible.
2. *The L-4 tier/lane crossing.* The fixture paired verbatim-with-near and family-with-far, so classifying by the family flag gave identical answers to classifying by lane; the sabotage passed. Tier and lane are now CROSSED, with the difference asserted as a precondition.
3. *The M-8 `Served` rows.*

**Relation to reddening a regression test.** `kb/meta/methodology/prove-the-regression-test-fails/d321b280.md` says: break the implementation and watch the test go red. This fact says WHY that keeps finding things — in these cases the assertion was correct and the inputs could not reach the code path that would break it. Reading tells you what a test claims; sabotage tells you whether its inputs can reach the claim.

**Scope.** Applies to any test distinguishing two behaviours, most sharply where a fixture is small enough for values to coincide by accident.
