# A regression test never seen RED is unverified — construct the broken implementation, watch it fail, then restore

Three of the six defects caught in review of PR #68 were TESTS THAT PASSED UNDER A BROKEN IMPLEMENTATION. All three came out of the same implementation plan's own fixtures, which makes it a systematic habit rather than three slips:

1. An ordering assertion whose fixtures ALL parsed, so the branch it existed to guard was never reached.
2. A guard that shipped with no coverage at all.
3. A "canonical wins over legacy" precedence test that seeded ONLY the canonical file — with nothing to lose to, the precedence it asserted was never exercised.

**The common shape:** the test asserts the RIGHT thing about a state the broken implementation ALSO produces. Green tells you nothing — and it goes on telling you nothing for the lifetime of the code, while reading as coverage to every later reviewer.

**The practice.** When a test exists to pin a SPECIFIC regression, prove it fails against that regression before trusting it. Concretely: write the test, then break the implementation in exactly the way the test is meant to catch — delete the guard, flip `sort.SliceStable` back to `sort.Slice`, remove the precedence branch — run it, SEE IT RED, then restore. It is cheap, and it caught all three of these the moment it was applied.

**What it diagnoses that a review reading cannot.** In two of the three cases the assertion was correct and the FIXTURE was the defect. Reading the test tells you what it claims; reddening it tells you whether the inputs can reach the code path that would break the claim. Only the second question is the one you need answered.

**Scope.** This is for tests written to pin a named regression or guard, not a blanket rule for every test.

**Not the same as TDD's red-green.** TDD reddens against MISSING code. This reddens against the SPECIFIC WRONG code you fear regressing to. A test can pass a clean red-green cycle and still be blind to the regression it is later repurposed to guard — the implementation exists by then, so "it went red once" no longer means what it meant at birth.
