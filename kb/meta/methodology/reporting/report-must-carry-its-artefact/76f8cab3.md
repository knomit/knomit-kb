# A report that SUMMARISES its verification cannot be wrong in public — paste the output and name the failure, or a wrong number survives review

REINFORCES kb/meta/methodology/testing/mutation-must-name-its-failure, and is deliberately a separate fact: that one governs THE RUN (a mutation counts only when it produces a named failure; it protects you from fooling yourself while sabotaging). This one governs WHAT HAPPENS TO A RESULT ONCE IT IS WRITTEN DOWN (the report carries the artefact, so a wrong NUMBER is catchable by a second party; it protects everyone else from a report that is confidently wrong). A run can satisfy that fact completely and still be written up as "sabotage confirmed the fixture is falsifiable", at which point nobody downstream can check it.

Across three PRs in one session, three separate numerical claims in reports were wrong, in both directions and by both parties:

1. A single sabotage run written up as a rate ("fails both tests"). Real figure: 5 in 30.
2. One batch of 30 written up as "every time". Real figure: 119 in 120.
3. On the REVIEWER's side, 29/30 from a single batch written up as the rate; it took four batches to establish the real one.

Every one was caught by the other party. What made them catchable was not care — all three were written down by someone who believed them. It was FORMAT: the brief required pasted test output, named sabotage failure messages, and the pushed SHA beside a clean `git status`. Each wrong claim therefore appeared next to the artefact that contradicted it, or next to a number a second party could re-run.

The same three claims in the ordinary register — "sabotage confirmed the fixture is falsifiable", "verified green", "the suite passes" — would have shipped intact AND LOOKED BETTER. A summary offers no surface to catch.

WHAT THIS DOES NOT CLAIM, and the misreading to guard against, because the slogan "paste output = accurate" is one compression away: THE FORMAT PREVENTS NOTHING. It caught zero of the three at the moment of writing. What it does is convert private error into public error, which is the only kind anybody else can fix. Adopt it for that, and do not let it substitute for the discipline in the fact above — a pasted output still has to be a NAMED failure, or it is silence with more lines.
