# An instrument that compares two values produced by the LOSSY step it is measuring reports zero loss, confidently — and a contradiction with a previously recorded number may be the only thing that catches it

**The failure.** The Phase-4 entry-12 audit decided whether an origin change was harmless by comparing `reparsed.Origin` to the PARSED fact's `Origin`. Both are `ParseFact` output. The loss happens AT parse — so both sides already said `authored`, and the audit reported all 61 `core` cases as semantic no-ops. The instrument written to measure the truncation class was blind in exactly that class's way.

**The general shape.** A guard or measurement that reads two values on the SAME SIDE of the transformation it is checking cannot see that transformation. It does not error, it does not look suspicious, and it returns the reassuring answer. Ask of any instrument: *which side of the lossy step does each of my two values come from?* If the answer is "the same side", the instrument measures nothing.

**What actually caught it — the transferable part.** The result CONTRADICTED a number the corpus had already recorded. A contradiction with a prior recorded measurement is worth RESOLVING rather than adopting, even when the new number is yours and the pipeline is fresh. Without the corpus's own prior measurement the wrong answer would have been reported confidently.

**Three sibling instrument errors from the same phase, same lesson:**
- A bare test instance left `MaxMembers` at 0, gating out every candidate; the first run reported "0 near, 0 far" on every corpus — which READS as a finding about the corpora and was a finding about the harness.
- A double-counted class made a rendering difference look structural (the same 157 facts reported under two names).
- A commit landed with a red suite because the verification command printed "(green)" unconditionally after a grep that had matched nothing. **Verify by EXIT CODE, never by a message printed beside one.**

**Corollary for re-verification harnesses.** RE-DERIVE the harness; never trust it from a path. A stale script that reports five greens is telling you it is stale, not that the guards hold. (Measured: a stand-down script scripted 5 sabotages where 7 existed.)
