# Evaluating cross-item matching with same-item agreement inflates results ~2x — and aspect selection is driven by the item, not the author

Three transferable lessons from the 2026-08 motif-matching experiments. (1) PROXY INFLATION: measuring whether two annotators' labels for the SAME item match (pack-1 design) gave 45%; measuring whether labels for two DIFFERENT items sharing the target property match (pack-2, the production condition) gave ~20% for the same machinery. Same-item agreement overestimates cross-item matching roughly 2x, because same-item annotators see the same text. Always evaluate matching machinery on cross-item planted pairs with an adversarial trap and a random-floor control arm. (2) ASPECT SELECTION IS ITEM-DRIVEN: one model annotating everything scored identically to mixed authorship (54% vs 53% ceiling) — an annotator names what each item's text foregrounds and never compares items, so single-model deployment buys nothing and multi-model deployment costs nothing. (3) SEMANTIC vs MECHANICAL CONVERGENCE: independent LLMs cold-converge on mechanism NAMES at ~70% judged semantically (six exact cross-model strings measured), but mechanical string/embedding matching sees only 8-22% of that; the gap is closed by cascading a very permissive mechanical prefilter into an LLM pair-judge, never by tightening the mechanical stage. WHAT THIS DOES NOT MEAN: same-item agreement is still fine for measuring annotation QUALITY — it is only wrong as a proxy for cross-item MATCHING.
