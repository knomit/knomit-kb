# A refused fleet sync is classified from the recorded error AND this instance's own installed material (no peer asked): revoked = the host refused, with the bad_certificate alert, a certificate that is VALID here (or the installed CRL lists it); moved = THIS instance refused the host (pki.ErrUntrustedRoot); other = refused and not valid here either, or another alert

RULE (fleet PR8, branch feat/fleet-tick-duties; GET /fleet `last_error_refusal`). `classifyFleetRefusal(lastErr, own)` where own is `pki.InstalledStanding([tls].dir, now)` (valid | revoked | expired | untrusted | none, by VerifyInstanceChain against the INSTALLED root and CRL):
- a commit refused by the host's judge (store.CommitRefusedByJudge / CommitRefusedByValidation in the text) is never a TLS refusal, whatever it quotes: "";
- text has pki.ErrRefusedByPeer: `revoked` when own is revoked, or own is valid AND the text has "tls: bad certificate"; else `other`;
- text has pki.ErrUntrustedRoot (this instance's own verdict on the host's certificate): `moved`;
- else "".

WHY IT IS SOUND. crypto/tls sends alertBadCertificate for EVERY VerifyConnection refusal (handshake_server*.go; it cannot carry the reason). But this instance verified the host's certificate under its OWN installed root before the host judged it, so the host is of the same root; such a host refuses a certificate that chains, is in validity and is not on this instance's CRL only for its own (newer) CRL. A host whose trust material is uninstalled presents no certificate and fails with another alert, so it reads `other`, not revoked. The texts are pinned in internal/pki gittransport tests (RevokedClient: sentinel + "tls: bad certificate"; OtherRootServer: ErrUntrustedRoot, not ErrRefusedByPeer).

CONSEQUENCES.
- `revoked` is an INFERENCE for a hub member, which cannot read main's CRL once refused: if this instance's clock is wrong by more than the remaining validity, a host-side expiry would read as revoked. Renewal in the final third of a leaf's life keeps that window large.
- FleetStatus.Revoked = not a root holder AND (record_state revoked OR installed CRL lists the installed leaf OR the error classifies revoked). Never on a root holder (`<home>/fleet/root.key` present).
- `moved` does not stop the rounds; only revoked does.

MISREADING. "last_error_refused means revoked": no; it is any ErrRefusedByPeer (revoked or other). Read last_error_refusal.
