# GET /chat-providers key_source is the NAME of the env var, shown only when that env var is the key source in effect and is a valid variable name; a key pasted into api_key_env, an api_key_file or a plaintext api_key all give no key_source

The provider list's key_source (llm.keySource) is p.APIKeyEnv only when api_key_file and api_key are both unset AND api_key_env is a valid environment-variable name. A value that is not a variable name (the user pasted the key into api_key_env) yields an empty key_source, never the value; a provider whose key comes from api_key_file or a plaintext api_key also has none. host (Ollama) is shown with any userinfo stripped (displayHost). Consequence: a new provider field that carries config text must go through the same gate; never copy a config string into /chat-providers without asking whether it can be a secret. Enforced by TestRegistry_KeySourceIsNeverTheKey (sabotage: return p.APIKeyEnv unconditionally -> the pasted key is returned).
