# TestChatPrefix_Hooks1to3ByteIdenticalAcrossInstances pins the fleet cache: same permission set ⇒ hooks 1-3 byte-equal across instances and runs (Anthropic bytes taken from the received HTTP body); across sets hooks 2-3 equal and hook 1 differs by exactly the six write tools; the real hostname, home, working dir, temp root and user are forbidden needles — other values equal on one machine are still invisible

internal/edge/mcp/chat_prefix_test.go builds two server instances that differ on every axis (home dir, agent branch agent/host-a-1111 vs agent/host-b-2222, AgentHost host-a vs host-b, repo alpha vs beta, principal bridge:uid:501@socket vs bridge:uid:1000@socket), both with Read+Write grants, and per instance two runs of NewServer + in-process client + LoadPrefix + AddPrefix. It asserts all four CanonicalPrefix(HookRepo) byte slices are equal and all four Anthropic prefixes are equal, where the Anthropic prefix is the "system" and "tools" raw bytes of the HTTP body an httptest server RECEIVED from AnthropicChat.Stream (wirePrefix), each checked byte-equal to llm.AnthropicPrefixJSON; non-vacuity (13 tools = len(toolRegistrations(nil)), knomit_query and "## No repo bound yet" present); and negative needles (both homes, hosts, branches, principal ids, `\balpha\b`/`\bbeta\b`, "agent/host-", today's UTC date, and any 20YY-MM-DD date other than the allowlisted example 2026-10-01). Subtest "permission sets": two read-only principals on two more instances get byte-equal prefixes; hooks 2-3 equal the writer's; hook 1 lacks exactly knomit_experiment, knomit_hypothesize, knomit_learn, knomit_retract, knomit_review, knomit_update and equals the reader's own tools/list read independently.

Real machine needles (requireNoMachineBytes → realMachineNeedles), on canonical and Anthropic bytes of writer and reader: os.Hostname() as a substring and its short form (before the first dot) as a case-insensitive word; os.UserHomeDir() and $HOME; os.Getwd(); os.TempDir(); user.Current().Username as a word, except generic account names (root, runner, user, admin, build), which are logged and covered by the home-directory needle. Each needle is asserted non-empty, so an empty one cannot pass vacuously. Sabotage at ee04e654 (working-tree mutation, reverted, tree clean after): hook 2 = ChatSystemPrompt + os.Hostname() → red "real machine value (os.Hostname)"; hook 3 = instructions + $HOME → red "real machine value (os.UserHomeDir)"; hook 2 + short hostname only → red "real machine name (short hostname)". Before this, the reviewer showed the first two mutations GREEN at c43453ac.

Earlier sabotage results at the commit: appending mgr.AgentID() to the unscoped instructions → red ("canonical prefix of run 2"); appending today's date → red (date needle); making permissionFilter a no-op → red in "permission sets".

WHAT IT DOES NOT GUARANTEE: (1) a value that is the SAME on both instances because both run on the test machine passes the equality check; only the explicit needles catch it. The hostname, home, working directory, temp root and username are now needles, but any OTHER machine-derived value (an IP, a mount path outside those roots, a machine id, a date in a format other than YYYY-MM-DD) is still invisible to the test. (2) It covers the unscoped endpoint kind only, which is the one chat uses. (3) It does not exercise CanonicalJSON's re-sorting: encoding/json already sorts the maps mcp-go marshals, so that is pinned separately by TestCanonicalJSON_StableAcrossMapOrder. (4) Ollama's render is added by PR3, not here.
