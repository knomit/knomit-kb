# Guidance text reaches a hypothesize/review prompt ONLY from files read at ONE consensus-tip commit (with the ontology at that commit) — never the agent branch, an experiment, or ri.Ontology(); and only file text, validation name/message and the DECLARED topic path enter the section, placed before every fact-derived string in review prompts

Enforced by `repos.ConsensusGuidance` (`internal/repos/guidance.go`) and the renderers in `internal/synthesize/guidance.go`.

SOURCE: `UpstreamTip(svc.UpstreamBranch())` ONCE, `OntologyAtCommit(tip)` parsed with ParseOntology, then `GuidanceAt(tip, file)` for every declared path — the SAME commit. No fallback when the consensus branch is missing, has no ontology, or the ontology does not parse: no guidance (nil), warned. `sess.Branch` (agent branch or exp/*) is never consulted for guidance, and neither is the open-time `ri.Ontology()` (read from the READ branch) — the validations listed next to the guidance come from the tip's ontology too (review finding R3).

WHAT ENTERS THE SECTION: the guidance file's text; `name: message` of each validation on the walk (message folded to one line); `Ontology.DeclaredTopic(...)` as the label (never the fact's freeform category — finding R2); the path as the ontology writes it; branch and short commit. No fact title/body/path, task, context value or tool argument is interpolated. `knomit_hypothesize` and `knomit_review` declare no `instructions` argument and refuse one as unknown (`rejectUnknownArguments`).

PLACEMENT: hypothesize = methodology section (if any) -> guidance -> fixed WORKFLOW (WORKFLOW byte-identical; design-bound order — methodology bullets each start `• score=`, so a forged title cannot start a line). Review prune/distill: the `PromptData.Guidance` slot right after the role line; reflect: first, before `{{.Facts}}` (finding R4: a fact body printed earlier could forge the header). Motif alias/define and discover get none.

TRUST: the same as skills and recipes — whoever can change the consensus branch. That holds on a repo with NO origin (where the local reconcile fast-forwards main to the agent tip every 30 s) only because F25 closed `.knomit/` to every fact tool; F23 adds no guidance-specific reservation. Tests: `TestGuidance_FactToolsCannotWriteGuidance` (MCP) and `TestGuidance_RESTCannotWriteGuidance` (REST) try every door then one reconcile round and read ConsensusGuidance.

MISREADINGS: (1) "never the agent branch" does NOT survive reopening `.knomit/` to the fact tools — sabotage verified: with closedToFactTools AND learn's artifact-path check both opened for .knomit/guidance/, a learned file reached main after one reconcile and became guidance. MCP learn has TWO layers there (closed-path, then IsArtifactPath); opening one alone still refuses. (2) Under `consensus: auto`, any admitted peer's pushed branch reaches main, so "consensus branch" means "any admitted peer" there — the accepted skills/recipes trust ruling. (3) Review guidance is ADVICE: review's own writes are not validated.
