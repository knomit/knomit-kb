# A scenario world is materialised ONLY through the knomit_learn/update/retract handlers (repos.ScriptTools from mcp.NewScriptTools), never by writing files, and any write-path refusal makes the world invalid

LoadScenario (internal/synthesize/scenario_load.go) writes only the world's ontology directly (InitRepo on agent/scenario) and then replays the history through the SAME handlers the MCP server registers, in process, via the repos.ScriptTools the caller passes in (mcp.NewScriptTools(embedder)); it is a parameter because internal/mcp imports synthesize. Every fact therefore passes ValidateFact, ref resolution, dedup and the same-subject gate and has a real git history. A world is never built by writing fact files.

A refusal is final: the loader returns a *ScenarioError naming the step, the fact and the server's own text, and the world is unusable; the spec is regenerated, never patched. Invalid worlds include: an ontology rule or type-mix refusal from knomit_learn; the same-subject gate; the dedup merge folding a world fact into another world fact or into another fact of the same call (the loader reports it; the escape is rewording or distinct_from); a merge note on the response; and knomit_learn subsuming a hypothesis (an incoming observation that settles it retracts it in the same commit) when the step does not list that fact in retracts, because the gold would otherwise treat a retracted hypothesis as live.

MISREADING to avoid: a world that loads without an embedder has NOT passed the dedup and same-subject gates. Without an embedder (ScenarioLoadOptions.Embedder nil) both gates fail open, as knomit does; ValidateFact, ref resolution and the type-mix rule still run. Only the EXPERT_SPEC_DIR run (TestScenarioSpecDir, real embedder from ~/.knomit/models unless EXPERT_SPEC_EMBED=0) proves a world passes them, and it runs CheckGold there too (every cited gold fact live at the head; no fact both required and forbidden). Pass the SAME embedder to Tools and to Embedder.

Consequence: do not add a loader shortcut that writes fact files or skips a handler; it would let worlds contain facts production could not have written.
