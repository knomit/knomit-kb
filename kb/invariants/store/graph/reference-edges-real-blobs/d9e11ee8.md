# A reference (DERIVED_FROM) edge joins two blobs that are BOTH in this store's object table, or it is not written: the write path and the rebuild check it, Verify reports a violation (reference-blobs), and a rebuild drops it

User ruling 2026-10-30: reference edges must match real blobs the store has.

- WRITE: graphAddDerivedFromAtCommitTx (index/derived_from.go) writes nothing for a source blob absent from `objects` (type 3), via an explicit blobExists check. A ref whose resolved target blob is absent is skipped. Both are counted (Index.DanglingRefsSkipped) and logged at debug. Rebuild phase B goes through the same function, so its re-resolve applies the same checks.
- The TARGET half IS the blob read: ReadBlobHashAtCommit loads the blob object through go-git, so a missing target blob ERRORS there, and that skips THAT ref only. A separate existence check after it could never fire; it was measured as an equivalent mutant and removed. CONSEQUENCE: if that read is ever replaced by a tree-entry-only read (e.g. a BlobHashesAtCommits batch), the target check must be added back explicitly. Before this change, the error aborted the rest of the fact's refs. A transient failure is retried by Sync's pass 2 or a rebuild, because claimBlobRefs lets the same (node, commit) fill in again.
- VERIFY: fsck checkReferenceBlobs, category `reference-blobs`, counts edges whose source or target Fact node names a blob missing from `objects` (Index.DanglingRefEdges).
- REBUILD: rebuildGraph runs dropDanglingRefEdges in its transaction.

MEASURED 2026-10-30: there were 0 such edges on a backup of the live knomit-kb store (21,235 edges) and 0 on the round-4 real-size store (520,213 edges); 0 Fact nodes there name a missing blob. No cause was observed on real data. The invariant is preventative, so do not cite it as evidence that dangling edges occur.

What this does NOT mean: a rebuild cannot heal a store whose LIVE tip blob is missing. rebuildFacts lists the tip tree and fails with `object not found`; only historical targets can be lost and still rebuild.
