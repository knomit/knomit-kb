# A refusal quotes the ACTUAL merge base, never experiments.fork_commit — and says NO BASE for a path both sides added, because knomit_explain at a commit where a path is absent answers with a DIFFERENT fact rather than failing

Resolving a conflict means reading three versions of the fact. The refusal therefore carries the three commits to read it at, as FULL hashes — they are passed back verbatim as `knomit_explain`'s `commit`, and a shortened one may not resolve.

THE BASE IS `dst.MergeBase(src)`, NOT THE RECORDED FORK. After a sync the two diverge: sync merges the parent INTO the experiment, moving the merge base forward while `experiments.fork_commit` stays where it was. Quoting the record would hand the reader a base version the merge did not use — authoritative-looking and wrong. A test that pins `fork_commit` passes whenever no sync has happened, which is why the discriminating fixture has to sync first.

A DUAL ADD HAS NO BASE VERSION, and saying so is not a nicety. Both sides created the path independently, so nothing exists at the base. `knomit_explain` for a path absent at a commit does NOT error: it falls back to the nearest earlier version and returns a different fact with nothing to signal the substitution. A reader sent to "read the base version" of a dual add is shown something unrelated and takes it for the original. `MergeConflictError.PathsWithoutBase` carries the set and the refusal prints NO BASE VERSION for those paths instead of a commit.

DISTINCT FROM decisions/experiments/lifecycle, which records WHAT the lifecycle does — that commit refuses and the retry carries resolutions. This fact is only about WHICH COMMITS the refusal may quote, and it is the half that can be wrong while the lifecycle is right: a refusal naming fork_commit still refuses correctly and still lists the paths, and sends the reader to the wrong version of each one.

DISTINCT FROM conventions/store/merge/strategy-refuse, which is about WHEN the merge treats a path as conflicting — in particular that refuse is stricter than the resolving strategies on a dual add. That fact decides membership of the conflict set; this one decides what the resulting error may SAY about each member. A dual add is the path where both apply and they answer different questions: strategy-refuse says it IS a conflict, and this says it has no base to read.
