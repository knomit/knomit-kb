# A commit on an experiment branch is authored AND committed by the experiment's owning agent (its recorded parent), never `exp/<name>` — and when that agent cannot be named (no experiments row, a parent that is not an agent branch, or a parent that is not the database's KNOWN owner) the write or merge is REFUSED before any object is built (#394)

commitAgentID (internal/store/branch_commit.go) resolves the identity for every authored commit through commitSigs. For a branch in the exp/ namespace it reads the experiments row and uses deriveAgentID(parent_branch). The commits it covers: learn/update (writeFileExact), retract (deleteFile), batch writes — learn's atomic move, review answers and review-start dedup, hypothesize (batchWriteLocked) — and SyncExperiment's merge commit on the experiment (mergeIntoBranch with dst = exp/<name>). CommitExperiment's merge commit was already authored by the agent (dst is the parent); its FAST-FORWARD carries the experiment's own commits unchanged, which is why the experiment's commits themselves must carry the agent's name.

Refusals (never a fallback to the experiment's name): no experiments row (an orphan ref; ErrOrphanExperimentRef); a recorded parent that is empty or itself exp/*; a recorded parent that differs from a NON-EMPTY AgentBranchOwner (taken over since the fork; ErrStaleExperimentParent, the same check CommitExperiment/SyncExperiment run). An EMPTY owner is unknown, not a mismatch: the recorded parent names the agent (kb/invariants/store/experiments/parent-vs-owner).

Consequences: (1) the F09 acceptance gate (CheckRange → agentIDOfAuthor) now finds the owning agent's member record for an experiment-written range instead of refusing RuleNoRecord 'no member record for agent exp/...'; (2) per-author measures (`git log --format=%an`) show agent ids, not experiment names; (3) a test fixture that wants content on an orphan exp ref must write it while a row exists and then delete the row (writeOnOrphanRef in experiment_test.go) — a direct write onto an orphan ref is now refused. What this does NOT mean: history written BEFORE the fix still carries `exp/<name>` authors and is not rewritten; changeReader decides a commit is local by its SIGNER, not its author, so such commits stay local. deriveAgentID/AgentIDOf did not change meaning (the fleet identity code reads them).

Tests: TestExperimentCommits_AuthoredByOwningAgent, TestExperimentCommits_EmptyOwnerUsesRecordedParent, TestExperimentCommits_NoOwnerNoWrite, TestCheckRange_ExperimentRangeNamesTheOwningAgent (internal/store/experiment_author_test.go). Sabotage verified: resolving from the branch written turns all four red (the gate refuses `exp/gated`).
