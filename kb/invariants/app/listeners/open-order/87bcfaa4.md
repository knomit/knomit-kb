# app.OpenListeners binds plaintext TCP, then the local socket/pipe, then RequireLocalListener, then mTLS; cmd binds OAuth and diagnostics next; Listeners.Advertise writes server.json after ALL of them — and every failure after the first bind closes EVERY listener, the listener as well as its http.Server

WHAT (knomit#493, merge 9860c726; `knomit serve` boots through internal/app/listeners.go): OpenListeners binds (1) plaintext TCP (skipped when http = false), (2) the local socket/pipe via openLocal -> auth.ListenLocal, (3) auth.RequireLocalListener, (4) the mTLS server through app.OpenTLSServer. It writes NO file. cmd/serve.go then binds the OAuth and diagnostics listeners, and only then calls Listeners.Advertise, which writes server.json (serveraddr.WriteLock) LAST. Close removes the file only when its pid is still in it (RemoveLockIfOwner) and is idempotent; it does not require Advertise to have run.

UNDO-ALL: every fallible step after the first bind returns through Listeners.fail, which closes ALL listeners AND their servers. http.Server.Close/Shutdown close only listeners Serve has already registered, and Serve runs on a goroutine, so a failure right after the bind can leave the port bound unless the listener itself is closed. The rule carries over from the desktop's bootServer (kb/invariants/desktop/boot/listener-order, which describes the old path that PR 5 deletes).

CONSEQUENCES for a change here: (a) a new fallible listener goes BEFORE Advertise and needs a close on every later error path; (b) the proof is a test that RE-BINDS the address after the failure, not one that checks an error was returned; (c) a new listener cmd binds must be called before Advertise in cmd/serve.go; (d) nothing may advertise a port nothing serves (a lockfile is the promise that every listed address answers).

ENFORCED BY: TestOpen_EveryFailureReleasesEveryAddress (internal/app/listeners_test.go: held TLS address, TLS trust failure, require refusal with the socket held, held TCP port, unwritable server.json - each then re-binds TCP, TLS and the socket); TestAdvertise_WritesV2LastAndCloseRemovesOnlyItsOwn; and, for the call order inside cmd, TestServe_AdvertiseIsAfterEveryOtherListener (cmd/serve_supervised_test.go), which parses serve.go with go/ast and asserts OpenListeners < openOAuthServer < Advertise and openDiagServer < Advertise, with a positive control that all four calls are found. Sabotage evidence: dropping the TCP or TLS close in Close turns the undo matrix and the Advertise test red; moving the Advertise block right after OpenListeners turned NOTHING red until the AST pin was added.

NOT MEANT: (1) OpenListeners does not write server.json - Advertise does, so a failed Open leaves no file; (2) http = false removes only the plaintext TCP listener; the mTLS listener has its own address switch ([tls].addr); (3) the AST pin checks SOURCE ORDER, not behaviour - the last-matching call per name wins, so a duplicate earlier Advertise call would slip through; (4) tools/desktop/boot.go does NOT use this set (ephemeral-port fallback, its own TLS state, loopback-only bind) and keeps its own order until PR 5.
