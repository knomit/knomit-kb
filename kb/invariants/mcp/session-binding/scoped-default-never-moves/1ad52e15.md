# A URL-scoped MCP session's DEFAULT binding never moves: a call without `binding` on a --repo/--lens endpoint is always served the URL's own branch (the agent branch, or a lens's default), and an experiment is reached ONLY through a handle

RULE. On a URL-scoped MCP endpoint (`/repos/{repo}/branches/<agent>/mcp`, `/lenses/{lens}/mcp`, i.e. any `kb --repo`/`--lens` bridge) the connection's default binding is FIXED to the branch the URL names. Nothing may move it: not knomit_experiment open, not knomit_bind, not anything else (user ruling, kb/decisions/mcp/experiments/open-returns-handle). No state keyed on the MCP session id, or on (session id, mount uid), may choose the branch a handle-less call is served.

WHY. Subagents share their parent's MCP session and nothing on the wire tells callers on one session apart. A movable default moves EVERY agent sharing it (#685): default reads go stale (an experiment forks before later commits to the agent branch), and default writes land in someone else's experiment and ride its PR.

HOW IT IS ENFORCED (since PR #686, merged into dev as f3965328).
- ScopedMountMiddleware / markScopedMount (internal/edge/web/scoped_mount_middleware.go) only MARKS the mount as handle-steerable (repos.WithMountSession) and never installs a binding. It replaced MountExperimentMiddleware, which read mount_experiments and swapped the binding.
- experimentOpen (internal/edge/mcp/experiment.go) puts a HANDLE in the experiment: the caller's own (unchanged unscoped behaviour), or, when a scoped call passed none, a new one minted on the endpoint (mintEndpointHandle, via scopedBindTarget + MintBindingHandleOnMount + setHandleExperiment) and returned as `binding`.
- commit/rollback/sync with no `name` and no handle are refused (errNoExperimentNamed): the default can never be inside an experiment to stand in for one.
- mount_experiments is neither read nor written; Store.Purge drops every row in it (legacy rows from older servers). The table stays because the control chain only adds.
- Guards: TestScopedDefault_* in internal/edge/web/scoped_default_e2e_test.go (default write/read on the agent branch after open; two opened handles independent; refusals; the #685 repro of an agent-branch commit visible on the default; unscoped unchanged) and TestPurge_DropsLegacyMountExperimentsOfLiveSessions. Sabotaging the middleware to re-pin the default onto the newest experiment fails five of them.

CONSEQUENCE. Callers keep the handle `open` returns and pass it as `binding` on every experiment call, including commit/rollback/sync (or name the experiment). A reviewer must block any change that makes a handle-less scoped call's branch depend on anything but the URL.

WHAT THIS DOES NOT MEAN. Not that handle-less scoped calls are refused: they work, on the URL's branch. Not that a handle cannot be inside an experiment: that is the only way in. Not that URL-addressed experiment mounts changed (`/branches/exp:<name>/mcp`, `/lenses/{l}/experiments/{n}/mcp` serve the experiment their URL names). Not a statement about the unscoped endpoint, where every call already needs a handle.

Also guarded since 37af576f: TestScopedDefault_CommitByNameSaysWhatHappened (commit/rollback by name never claim the default moved; only a passed handle's position is reported) and the open-minted cases of TestScopedBind_ForeignHandlesAreRefused (a handle open mints is a handle of THAT endpoint only).
