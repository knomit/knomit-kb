# An agent's `trace` may carry only Knomit-Trace, Knomit-Cause and Knomit-Run among `Knomit-` names (matched case-insensitively, each in knomit's exact form) — Knomit-Trigger and any other Knomit-* name are refused; own keys are git trailer tokens ≤32 chars with one-line values ≤128 bytes, ≤8 of them; any bad entry refuses the WHOLE call before anything is written

User rulings (2026-10-01, verbatim): "everything prefixed "Knomit-" is ours, reserved, and well known - agents cannot use anything like that. No for trigger entry if it can cause non-deterministic loops. Validation - whatever is "Knomit-*" must be on the list we support, anything else must match git rules - not long names, short values, etc; these are used for stamping and context carrying, not for verbose notes and descrptions." and, on the reading: "2) a indeed, what I meant agents cannot invent new "Knomit-" prefixed names." Enforced by parseTrace/knomitTraceEntry/traceValueRule in internal/mcp/trace.go. Exact rules: a key whose lowercase starts with `knomit-` must be knomit-trace (one line, 1-256 bytes = sessions.MaxFieldLen, TrimSpace-equal), knomit-cause (a FULL commit hash in LOWERCASE hex, 40 or 64 chars — `--grep` is case-sensitive and git prints lowercase) or knomit-run (`run-` + 32 lowercase hex, the minted form); it is written in canonical spelling. knomit-trigger is refused because it switches the trigger loop guard. Every other key: `[A-Za-z0-9][A-Za-z0-9-]*`, ≤32 chars (git-interpret-trailers' key form plus knomit's leading-char rule); value non-empty, ≤128 bytes, equal to its own TrimSpace, valid UTF-8, no unicode.IsControl rune (C0, DEL, C1 incl. U+0085) and no U+2028/U+2029; ≤8 own entries; two keys differing only by case are refused (JSON allows both). git's own well-known trailers (Signed-off-by...) pass. The limits are named constants (MaxTraceKeyLen/MaxTraceValueLen/MaxTraceEntries), sanity bounds, not policy. Refuse, never drop: the error names the entry (e.g. 'trace: Knomit-Trigger is reserved', 'trace.Ticket: value is longer than 128 bytes') and the branch head does not move. Misreading to avoid: Reading A lets ANY agent join ANY story by naming its Knomit-Trace (correlation only, gates nothing); it does NOT let an agent invent Knomit- names or set the loop guard.
