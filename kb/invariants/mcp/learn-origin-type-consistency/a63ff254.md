# origin×type is enforced for EVERY write path, in SerializeFact — not just knomit_learn

fact.SerializeFact validates the (origin, type) pair via Origin.ValidateForType before emitting anything: origin=distilled is accepted only when type=synthesis (the only type the distill pipeline emits); origin=discovered is accepted only when type=synthesis (forward bridge) or type=hypothesis (backward bridge). origin=authored (or omitted) pairs with any type.

BECAUSE THE CHECK LIVES IN SerializeFact, IT COVERS EVERY WRITER — knomit_learn, the synthesize pipeline (ApplyDistillDecisions, applyDiscoveredProposals), and the web write path all funnel through it. There is no way to persist a mismatched pair through any supported route.

THIS IS A CHANGE (P1.6, 2026-07-21). An earlier revision of this fact correctly described the check as running ONLY in LearnHandler, with pipeline writers 'enforcing their own type sanity' — which meant, in practice, that they did not enforce it at all. Origin.ValidateForType had exactly one production caller in the whole repo. The explicit check in learn.go has since been DELETED as redundant; do not re-add it. Error attribution survives because learn.go's SerializeFact call site already wraps failures with the fact index.

**Consequence:** an agent that sets origin=discovered on a source-transcribed observation (the 2026-07-15 newsletter-ingestion incident: 15 facts) gets a hard error steering it to authored, instead of silently polluting the corpus. Since knomit_update cannot change origin, this rejection is the only thing standing between a wrong guess and a retract+re-learn cleanup.

**What this does NOT mean:** it does not make authored+synthesis invalid — that pair is still accepted (and an origin-LESS synthesis fact still parses back as distilled via the type-aware default in ParseFact; the schema's 'omit → authored' prose holds for every type except synthesis). It also does not mean empty origin is rejected: empty means 'unset', and SerializeFact skips the check so the defaults can apply.
