# Committing or rolling back an experiment BY NAME takes the caller out of its own experiment only when the name is the caller's current one (leaveIfCurrent), on both endpoint kinds

experimentCommit and experimentRollback (internal/edge/mcp/experiment.go) call leaveIfCurrent: the caller's handle experiment and mount experiment are cleared ONLY when the named experiment equals the caller's active one (repos.ActiveExperiment of its own binding). Before the fix in PR #664 (review S1) they cleared unconditionally on both the unscoped and scoped endpoints, so a lead landing a subagent's experiment by name (the project's "commit after the PR merges" step) was silently dropped out of its own experiment and its next write went to the agent branch. The result's branch/active and its summary ("this session stays on …" vs "is back on …") report where the caller remains.

Guarded by TestExperimentByName_OthersCommitLeavesTheCallerInPlace for an unscoped handle, a scoped handle and a handle-less scoped caller; sabotaging the guard fails all three.

WHAT THIS DOES NOT MEAN: committing your OWN current experiment still returns you to the agent branch; committing another's does not make it yours or end yours.
