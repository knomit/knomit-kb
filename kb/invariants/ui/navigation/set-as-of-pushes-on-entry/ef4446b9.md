# SET_AS_OF pushes navStack exactly once, on ENTERING a timeline (a fact is open and asOf goes live -> non-live); scrubs, diff exits and return-to-live push nothing — 'every asOf change pushes' is the misreading

In web/src/state.ts the `SET_AS_OF` case pushes `pushNav(s)` iff `s.factPath != null && s.asOf.mode === 'live' && a.asOf.mode !== 'live'`: a fact is open, the current asOf is live, and the new asOf is history or diff. That is the entry into a fact's timeline, and it records the live fact as the departure state, so Back from the timeline returns to the open fact, live, timeline closed (#486, fixed by PR #506; this replaces the earlier gotcha that described the bug). The `at:` filter anchor dispatches the same action and counts as an entry too.

Every other SET_AS_OF leaves navStack untouched: scrubbing history -> history, entering a diff from history, leaving a diff back to history, and any change when no fact is open.

CONSEQUENCE: do not weaken the `asOf.mode === 'live'` clause. Dropping it makes every scrub and every diff exit grow navStack, so Back walks the scrub history one version at a time and the trail (derived from navStack, see kb/architecture/ui/navigation/navstack-is-also-the-trail/1dd158ac.md) fills with duplicate entries. A reviewer's sabotage of exactly that clause turned the scrub test red.

WHAT THIS DOES NOT MEAN: not 'every asOf change is a navigation step' (only the live -> non-live entry is); not 'return-to-live pops' (returning to live goes through APPLY_NAV, which pushes; see the #507 gotcha); and not 'a fact hop inside a timeline is exempt' (APPLY_NAV with hop pushes as before). The no-push on return-to-live follows from the condition (non-live -> live is not an entry); the tests assert scrub and diff entry/exit, not a return-to-live dispatch.

Anchored by three tests in web/src/state_asof.test.ts (describe 'timeline entry is a navigation step (#486)': Back returns to the fact; scrub and diff push nothing; trail is one crumb per fact jumpable by pops) and by the e2e specs 'Backspace from history returns to the open fact' and 'the timeline back arrow returns to the open fact' in e2e/tests/ui/history.spec.ts.
