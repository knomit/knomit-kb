# !isLive(state) MUST disable all mutating endpoints — anchor not live = refuse repo mutations

When state.asOf.mode != 'live', every mutating endpoint in the UI is disabled with tooltip 'Read-only — anchor is not live.': POST/PUT/DELETE /facts (CRUD), POST /synthesis-runs, POST /index-rebuilds, PUT/DELETE /origin, POST /origin-sessions/.../apply, POST .../commit. Origin and jobs flows are gated for the same reason fact CRUD is — they all write to repo state. Any keyboard shortcut that triggers a mutation (e.g. 'r' for retract) checks isReadOnly in the SAME handler that disables the button — same source of truth, no drift. isLive and isReadOnly are equivalent today but exist as distinct named selectors so isReadOnly reads honestly at call sites when mode:'diff' (also read-only) is added.
