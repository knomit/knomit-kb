# fact.Fact.Path is a private field; NewFact() is the sole constructor and lowercases unconditionally

fact.Fact.Path is a PRIVATE field. NewFact(path) is the SOLE constructor and calls strings.ToLower(path) unconditionally. f.Path() getter is the only way to read it. Custom MarshalJSON/UnmarshalJSON expose 'path' in JSON and re-enforce lowercase on decode (critical for hypothesize work-item round-trip where facts are serialized into pipeline_sessions and read back). Compile-time enforcement: there is no way to construct a Fact with a mixed-case path. Anti-pattern: do NOT add a SetPath method or a public Path field. The case-insensitive lookup in ValidatePath is preserved — it's input validation, not a workaround. The previous ad-hoc strings.ToLower patches in synthesize/decision.go (ApplyPruneDecisions, normalizeFactPath) were DELETED — their regression tests deleted alongside the workarounds since the invariant is now in NewFact, not in the synthesize layer. SCOPE: only fact.Fact. store.FactRecord keeps a public Path string — it's a DB projection always populated from an already-correct Fact (or git paths guaranteed lowercase post-fix), no protection needed there.
