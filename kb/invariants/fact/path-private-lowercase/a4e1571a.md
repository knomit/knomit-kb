# fact.Fact.Path is a private field; NewFact() is the sole constructor and lowercases unconditionally

fact.Fact.Path is a PRIVATE field. NewFact(path) is the SOLE constructor and calls strings.ToLower(path) unconditionally (internal/fact/format.go:30). f.Path() getter is the only way to read it (format.go:33). Custom MarshalJSON/UnmarshalJSON expose 'path' in JSON and re-enforce lowercase on decode (format.go:98 — critical for hypothesize work-item round-trip where facts are serialized into pipeline_sessions and read back). Compile-time enforcement: there is no way to construct a Fact with a mixed-case path — no SetPath, no public Path field. The case-insensitive lookup in ValidatePath is preserved — it's input validation, not a workaround.

The invariant lives in NewFact, not in the synthesize layer: synthesize no longer carries ad-hoc path-lowercasing workarounds. NOTE (corrected 2026-07-04): a function named normalizeFactPath STILL EXISTS in synthesize/decision.go:23 and is called (decision.go:228, discovery.go:294) — but it is NOT a case workaround. It swaps the filename component for an 8-char UUID (dedup of LLM-generated filenames) and its own doc comment explicitly defers case handling to fact.NewFact ('Directory case is normalised by fact.NewFact, which lowercases the full path unconditionally'). Do not mistake its presence for a surviving lowercase patch.

WHAT THIS DOES NOT MEAN (documented misreading):
- NOT 'every path string in the system is lowercase.' FALSE — only fact.Fact self-lowercases, via NewFact / UnmarshalJSON. store.FactRecord keeps a PUBLIC Path string with no protection; it is lowercase only because it is always projected from an already-correct Fact (or from git paths guaranteed lowercase post-fix). A path arriving from an EXTERNAL caller (HTTP query, MCP arg) is NOT lowercased until it passes through NewFact — lowercase the incoming side (or compare case-insensitively) before using it as a key against stored paths.

SCOPE: only fact.Fact. store.FactRecord.Path needs no protection because of the projection guarantee above.

Anti-pattern: do NOT add a SetPath method or a public Path field on fact.Fact.
