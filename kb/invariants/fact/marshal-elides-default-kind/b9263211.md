# Fact.MarshalJSON exposes private path as 'path' field AND elides Kind when Epistemic

Fact.MarshalJSON exposes the private 'path' field as the json 'path' key AND elides Kind when it equals DefaultKind (= Epistemic). UnmarshalJSON does the symmetric work: lowercases the path on read and defaults a missing Kind to Epistemic. This is the ONE place private-path-to-JSON translation lives. Anti-pattern: defining a peer 'plain' struct in another package and copying fields by hand — you'd lose the lowercase + elision invariants. The MCP query handler (kb/conventions/mcp/query-elides-default-kind) and the HAL FactView (kb/conventions/web/factview-elides-default-kind) both replicate this elision logic on THEIR OWN output types so wire shapes match what Fact.MarshalJSON emits — keep all three in sync if Fact's elision rules change.
