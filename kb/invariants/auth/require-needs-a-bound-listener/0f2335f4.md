# [auth].require = true needs TWO checks, not one: app.checkLocalListener asks whether a listener is CONFIGURED and auth.RequireLocalListener asks whether one was BOUND — the gap between them is ErrSocketInUse, which both callers treat as benign

`[auth].require = true` with no local listener must FAIL the boot. Enforcing that takes TWO checks, and NEITHER is sufficient alone:

1. **app.checkLocalListener** — at config time, refuses require=true when cfg.Socket == "". It can only see what is CONFIGURED.
2. **auth.RequireLocalListener** — after ListenLocal, refuses when no listener was BOUND. Called by cmd/serve.go (through openLocalListener in cmd/listen.go) and tools/desktop/boot.go.

WHY THE SECOND IS NEEDED: ListenLocal returns ErrSocketInUse when another process holds the path, and both callers treat that as BENIGN — warn, serve TCP only, carry on — because a second instance must not steal the first one's listener. With require=true there is no anonymous path, so carrying on produces exactly the server check 1 exists to prevent: up, healthy-looking, answering every request 403.

PR #251 IS WHAT MADE IT REACHABLE, which is why it was found reviewing that PR and not earlier. Before it, Windows had no socket default, so require=true failed at check 1 and never reached a listen. Giving Windows a default makes cfg.Socket always non-empty there, so check 1 always passes.

NO ATTACKER IS REQUIRED. The Windows pipe namespace is flat and world-creatable, and ERROR_ACCESS_DENIED — which isPipeNameTaken maps to ErrSocketInUse — is what the OS returns for ANY foreign owner. A name collision with an unrelated process is enough.

NAMED MISREADING: "checkLocalListener guards the lockout." It guards HALF of it. Anyone who changes the listen path and consults only that function will reopen this.

VERIFIED ON THE REAL BINARY: with a foreign process holding the pipe, `knomit.exe serve` with require=true exits 1 naming `[auth].require = true` and the path; free the name and the same command boots and serves a real kb.exe over the pipe.
