# The fallback socket is never opened NOR dialled in a directory the current user does not own with mode 0700 — /tmp/knomit-<euid> is checked by Lstat on BOTH the server (ListenLocal) and the bridge (DialLocal), else ErrUnsafeSocketDir

THE RULE. When a socket path's directory is `auth.FallbackSocketDir()` (`/tmp/knomit-<euid>`), `checkSocketDir` must pass before anything touches it, on BOTH sides:
- `ListenLocal` → `prepareSocketDir`: `os.Mkdir(dir, 0700)` (an existing dir is fine), then `checkSocketDir`. On failure it creates NOTHING: no socket, no `.lock`.
- `DialLocal`: `checkSocketDir` before dialling. A MISSING dir returns the Lstat error, which wraps `fs.ErrNotExist`, so the bridge takes its quiet "no server" path. Anything else returns `ErrUnsafeSocketDir`, which the bridge treats as a loud fallback to TCP.

`checkSocketDir(dir)` requires ALL of: `os.Lstat` succeeds; not a symlink (Lstat, so a link is refused rather than followed) and `IsDir()`; `Stat_t.Uid == socketDirOwner()` (the euid); and `Mode().Perm() & 0o077 == 0`.

WHY BOTH SIDES. `/tmp` is world-writable, and the socket name is predictable from the data root. Without the check, another local user could (a) create the dir or the `.lock` first and hold the flock, so our server serves TCP only and loses the verified identity; or (b) LISTEN at the path themselves. The bridge authenticates to the SERVER by kernel peer credentials, but nothing authenticates the server to the bridge, so it would send every request to that process. A 0700 dir we own makes neither possible. Checking only the server side leaves (b) open to a bridge started while no server is running.

SCOPE. The check applies ONLY inside FallbackSocketDir (`inFallbackDir`). A socket under the data root keeps its old behaviour whatever the root's mode; the operator chose that directory. Applied uniformly on darwin and linux, even though darwin's $TMPDIR would be per-user, because the base is the literal `/tmp` (see the fallback decision).

TEST SEAMS: `fallbackBase` and `socketDirOwner` are package variables only so tests avoid the user's real /tmp/knomit-<uid> (a desktop may be listening there) and can stand in for another uid, which no unprivileged test can create by chown.

WHAT THIS DOES NOT MEAN: not that the data-root socket is ownership-checked (it is not), and not that `ErrUnsafeSocketDir` fails the boot. Callers treat it like `ErrSocketInUse` (see the single-site invariant's caller contract).
