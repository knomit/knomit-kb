# EMIT re-explains every support at HEAD before it writes: a support retracted since it was read is dropped and the answer re-decided, one rewritten since is re-judged on its new version (at most 2 rounds, then a gap) — and before reporting the answer as pending, Engine.RunWith checks the run's experiment still exists

Read-set freshness (E02 §7, done with explain instead of knomit_changes as E02 §11 allows): EMIT calls explain(path) for each live support (move `freshness`, ignored by the graders); a missing or deleted root marks the fact deleted, a root commit different from the commit it was read at clears its verdict and queues it for ASSESS. Any moved support records a freshness step and returns to ASSESS/SYNTHESIZE; after MAX_FRESHNESS (2) rounds the run ends on a gap 'the support kept moving'. TestEngineOracle_FreshnessBeforeEmit retracts a support mid-run and checks the answer does not cite it.

Experiment existence (fix-later R2, kb/gotchas/knomit/experiments/commit-ordering): engineHost.experimentExists looks the experiment up (own 5 s ctx, since the run ctx may be expired); when it is gone, ReasonResult.Next says it no longer exists and offers no commit/rollback, and a Warn line is logged (TestEngine_GoneExperimentIsNotPending). A failed lookup counts as existing.

Also landed in PR 3 on the Go side: knomit_reason refuses budget > 3600 s before converting (overflow), Engine clamps to MaxReasonBudget; `reason start` is logged before the slot wait and `reason done` on the slot-timeout path; engModel and engExperiment recover panics into thrown Errors with a Warn line.
