# ri.Verify snapshots svc under RLock then releases before calling — SwapStore-safe pattern

RepoInstance.Verify(ctx, opts) reads ri.svc UNDER the read lock and RELEASES the lock before calling svc.Verify. This is the load-bearing pattern for any operation that needs to call store methods OUTSIDE WithRead: snapshot svc under RLock, release lock, then operate. Releasing before the call lets concurrent reads proceed (they take RLock too) without holding the SwapStore write lock at bay. After Verify returns, the report has report.Repo stamped with this repo's name (which the store doesn't know). Anti-pattern: calling svc.Verify INSIDE WithRead — the operation can be long (seconds to minutes on big repos) and would block SwapStore for that whole window. Same pattern applies to any future RepoInstance method that wraps a long-running store call.
