# A template is refused, by named error and before anything is written, unless: kebab name; source an ACTIVE mounted repo; folder present at the source's consensus tip; only README.md and .knomit/** inside; plain 100644 files only; at most 256 files and 4 MiB; .knomit/ontology.yaml parses as a NEW ontology; no preset id unless it IS that preset; at most one describing fact; a fleet id only with initialize and no fleet already

Each rule and its sentinel (internal/repos/template.go, internal/store/templates.go): name not kebab-case → ErrTemplateName (400); `template.repo` unknown, archived or a lens name → ErrTemplateSourceNotFound (404); source mounted but its store not open (populating, closing) → ErrTemplateSourceUnavailable (503); no folder at the source's consensus tip, no consensus branch yet, or a describing fact with no folder → ErrTemplateNotFound (404); any path other than README.md and .knomit/**, or two paths equal under lowercasing → ErrTemplateLayout; a symlink, submodule or EXECUTABLE (100755) file → ErrTemplateNotRegular; more than 256 files or 4 MiB → ErrTemplateTooLarge; no .knomit/ontology.yaml → ErrTemplateNoOntology; ontology not valid under ParseNewOntology → ErrTemplateOntology; ontology id of an embedded preset while `refreshDivergence(o, preset) != ""` (the boot refresh's own test) → ErrTemplatePresetID; two `part: template` facts for one name → ErrTemplateDescribedTwice; these last six are 422 "Template invalid". A fleet-id ontology in local `template` mode, or while this instance already has a fleet repo or a fleet (un)registration in flight → ErrTemplateFleetLocal (409). Missing `template.repo`/`template.name` or a template on a mode that refuses it → ErrInvalidName (400).

Every refusal happens before any repo file exists; CreatePreflight returns it before the 202 and Create re-checks it, and a create that fails later is rolled back by Create's cleanup (no .db/-wal/-shm, no registry row): TestCreateFromTemplate_Refusals asserts both for every row.

WHY FLEET: a LOCAL repo with ontology id `fleet` becomes this instance's fleet (fleetRepo, fleet.go) and `knomit fleet register <url>` then answers already_registered; initialize on the fleet's git URL sets the origin that register later matches (user ruling 2026-10-07). The preset mode's local `fleet` behaviour is NOT changed.

MISREADING: 'regular files only' here excludes the executable mode too, so a copy never silently changes a file's mode; and a fact WITHOUT a folder is refused, while a folder WITHOUT a fact is creatable by name (it is only not listed).
