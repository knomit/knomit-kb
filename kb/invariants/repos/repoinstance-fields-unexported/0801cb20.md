# ALL RepoInstance fields are unexported; svc accessible ONLY via WithRead

ALL RepoInstance fields are UNEXPORTED (mu, name, dbPath, agentBranch, ontology, embedder, ontologyRoot, methodologyMinScore, onCommit, svc, hub, syncCancel, syncWg, startSync, closeFn). External code reaches svc ONLY via ri.WithRead(func(*store.Service)) — there is no direct accessor and no public RLock/RUnlock. The unexported ri.withWrite(fn) is used only inside the repos package (SwapStore + StartSync closure). Immutable fields (name, agentBranch, ontology, embedder, ontologyRoot, methodologyMinScore, hub) have simple getters that return without locking. Anti-pattern: exposing svc directly — it would let a caller hold a stale pointer past SwapStore. The compile error from `ri.svc` outside the package is the load-bearing enforcement of the SwapStore safety contract.
